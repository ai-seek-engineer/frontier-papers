【Title】When Parallel Drafter Meets Parallel Speculative Decoding (DPara)

- 一句话总结：把并行 drafter 和并行 speculative decoding 真正重叠起来，去掉“猜错接受前缀就整批回退串行”的失败路径。
- 核心贡献（2-3点）：
  - 保证每一轮 backbone 验证与 drafting 重叠，消除 PSD 的 probabilistic fallback。
  - 复用已有效的并行 drafter，而不是再造一套 draft 模型。
  - Qwen3-8B/14B，7 个 math/code/chat bench，相对自回归平均 **3.21× / 3.52×**。
- 工程价值：可直接进 serving 栈的 spec-decode 调度层；批量服务里 fallback 是吞吐杀手，这篇针对的就是生产路径而不是单请求 demo。
- 是否值得读：强烈推荐
- Relevance Score：5
- Link：https://arxiv.org/abs/2609.27396

【Title】Disaggregated Quantization: Specializing LLM Prefill and Decode

- 一句话总结：Prefill 用计算友好低精度，Decode 用带宽友好紧凑权重，两阶段量化不再共用一套格式。
- 核心贡献（2-3点）：
  - Decode 去掉 activation quant，decode-heavy 任务精度升、成本不增。
  - 单独训 NVFP4 prefiller，不解冻 decode checkpoint，1-bit 精度在 MMLU-Pro / MMMU-Pro 大幅回升。
  - SSD offload 的 ODP：27B、8K prompt，TTFT **1.78×**；在 vLLM 上做了 disagg serving 评估，并推到 2.8T 量级 PTQ。
- 工程价值：和现有 P/D 分离架构同构，可立刻试“两套 checkpoint + 一套调度”；对长 prompt 集群 TTFT 比再抠 0.1bit KV 更值钱。
- 是否值得读：强烈推荐
- Relevance Score：5
- Link：https://arxiv.org/abs/2609.26333

【Title】Crossflow: Prefill-Decode Elasticity for Agentic LLM Serving

- 一句话总结：静态 P/D 池在 agent 流量下会闲置或排队；用可撤销 lease 让 decode 节点临时吃 prefill，不改节点角色。
- 核心贡献（2-3点）：
  - 生产/公开 agent trace：uncached in/out token 比日内中位波动 **24.5×**，改 replica 要数十分钟。
  - lease 同时约束 local-prefill compute、KV 容量、传输和 projected output。
  - 相对静态 P/D，token 吞吐几何均值 **+16.2–17.4%**，高压最高 **+43.4%**，各负载点 TTFT 都降。
- 工程价值：这是集群调度问题，不是模型 trick。任何已经做 P/D 分离的团队都该对一下自己的 peak-to-mean。
- 是否值得读：强烈推荐
- Relevance Score：5
- Link：https://arxiv.org/abs/2609.27085

【Title】The KV Cache Working Set: Online Capacity Planning for LLM Inference Systems (KVSET)

- 一句话总结：给 prefix cache 算“工作集”——达到目标命中率所需的最小 KV 容量，在线估。
- 核心贡献（2-3点）：
  - 把 prefix cache 从“越大越好”改成可规划容量。
  - 面向多轮 agent：历史 KV 全留太贵，留少了命中率崩。
  - 在线分析器，服务系统设计直接用。
- 工程价值：容量规划/成本模型缺的就是这个数；和 Crossflow 互补——一个管池弹性，一个管该买多少 KV 内存。
- 是否值得读：可选（短文，但决策价值高）
- Relevance Score：4
- Link：https://arxiv.org/abs/2609.27746

【Title】LayerCheck: Adaptive Layer-wise Checkpointing for LLM Post-training

- 一句话总结：按层更新幅度选择性落盘，把周期性 I/O 尖峰摊开，恢复时拼 mixed-timestamp 模型。
- 核心贡献（2-3点）：
  - 观察：transformer 各层权重更新极不均匀，全量 ckpt 浪费。
  - 有界层 stale + Adam 假设下扰动可控；重启后 loss 偏离 ≤ **0.54%**。
  - 相对 SOTA：ckpt 体积最高 **22.6×** 下降，端到端训练时间 **1.31×**。
- 工程价值：SFT/RLHF/持续训的真实成本项是 I/O 和恢复；可插进现有 ckpt pipeline，不改算法。
- 是否值得读：可选
- Relevance Score：4
- Link：https://arxiv.org/abs/2609.27193

【Title】KITE: KV-Invariant Transformer Expansion for Efficient Agentic LLM Scaling

- 一句话总结：把新参数放在不影响 attention KV 的位置，upcycle 放大模型时 prefill KV 仍走小塔。
- 核心贡献（2-3点）：
  - SST 双塔：一塔产 KV，一塔读 KV。
  - 67B MoE（decode 每 token 2.15B active）在同等累计训练算力下 loss 优于更小/相近 MoE。
  - 估计推理成本相对对比模型降 **6.7% / 31.6%**。
- 工程价值：agent 长会话的成本在 prefill KV；架构级把“变大”和“KV 变贵”解耦，比事后压缩更干净。落地门槛高（要训新结构）。
- 是否值得读：可选（方向重要，短期难插现网）
- Relevance Score：4
- Link：https://arxiv.org/abs/2609.27294

【Title】Verifiable Hidden Dynamics Play (VHD-Play)

- 一句话总结：先采样并求解机制，再渲染成带状态工具的 agent 环境；可验证、便宜、可规模化造 RL 环境。
- 核心贡献（2-3点）：
  - 3300 个环境，单环境成本几美分；dynamics 与打分同源。
  - Qwen3.6-35B-A3B 五族诊断均值 0.204 → **0.815**，并外推到 function calling / 旅行规划 / 电商 bench。
  - 对照显示：可学差距主要在 stateful 交互，不在题面求解。
- 工程价值：agent RL 的瓶颈是环境供给和 verifier，不是又一个 GRPO 变体。可复用“先解机制再渲染工具”流水线。
- 是否值得读：强烈推荐（做 agent post-train 的人）
- Relevance Score：4
- Link：https://arxiv.org/abs/2609.27321

【Title】Train Where the Quantized Model Goes: On-Policy Distillation for Low-Bit Reasoning

- 一句话总结：低比特推理模型在长生成上崩，是因为 QAD 只在固定前缀上蒸馏；改成跟 quantized 自己走的轨迹做 on-policy 蒸馏。
- 核心贡献（2-3点）：
  - 定位：量化放大 exposure bias → 长 CoT 循环耗尽 budget。
  - 2.79 / 1.88 bit，四模型：MATH-500 相对 BF16 保留率 35%→**70%**，HumanEval 66%→**91%**。
  - 短题性能不掉；同等 budget 优于继续 teacher-forced QAD。
- 工程价值：要上 2–3bit 推理模型又要保 reasoning，这是对齐侧而不是 kernel 侧；可接现有 QAT/QAD pipeline。
- 是否值得读：可选
- Relevance Score：4
- Link：https://arxiv.org/abs/2609.26708

【Title】Reinforcement Learning with Decomposed Subtasks (RLDS)

- 一句话总结：别把整条 multi-turn trajectory 压成一个标量再进 GRPO；按子任务拆 advantage 再按 token 加权。
- 核心贡献（2-3点）：
  - SDAE：固定 taxonomy 拆 reward → 每子任务 group-relative advantage → 在 reflection 步附近集中 credit。
  - 收益与子任务异质性成正比：ScienceWorld **+11.5**，FrozenLake **+9.8**；异质性低的任务基本打平。
  - 训练中输出 heterogeneity 诊断，可决定值不值得开分解。
- 工程价值：agent RL 训练循环几乎不用改环境，只换 advantage 估计；有诊断比盲目换算法靠谱。
- 是否值得读：可选
- Relevance Score：3
- Link：https://arxiv.org/abs/2609.27035

**【额外输出】**

**1. 今日最值得读 Top 3**
1. **Crossflow** — agent 流量把静态 P/D 打穿是正在发生的生产问题；lease 机制不改角色就能吃 16–43% 吞吐。
2. **DPara** — spec decode 在 batch 上掉速是已知痛点，这篇把并行 draft + 并行 verify 的回退路径砍掉，数字干净。
3. **Disaggregated Quantization** — 和 P/D 分离同构，vLLM 路径、SSD offload、大模型 PTQ 都齐，比又一篇均匀 KV quant 更接近可上线。

**2. 今日趋势观察**
Inference / serving 明显占主导，且从“压 KV bit”转向 **调度与阶段特化**：P/D 弹性、prefix 工作集、prefill/decode 分格式、并行 spec 去回退。Agent 论文也在从 prompt 编排转向 **环境生成 + 长会话 KV 架构**。纯 RLHF 算法新变体很少。

**3. 值得跟进的潜在方向**
- **弹性 P/D + KV 工作集联合控制**：Crossflow 管瞬时错配，KVSET 管稳态容量，二者合在一起才是完整容量规划。
- **阶段特化量化（DQ）**：两套权重、一套 serving，比全链路同一量化更符合现有 disagg 硬件。
- **可验证合成 agent 环境**：VHD-Play 说明环境工厂可能比再堆轨迹数据更杠杆。
- **结构级 KV 不变扩容（KITE）**：长期比 eviction/quant 更干净，但需要模型团队配合，短期跟论文、中期看有没有开源 SST 权重。
