### 1. Inference / KV

**【Title】** ActKV: Efficient LLM Agents through Action-Guided KV Cache Management  
- 一句话总结：面向 agent 多轮 observe-reason-act 的 KV 压缩框架，按“对下一步 action 是否关键”做 eviction + 动态预算。  
- 核心贡献：  
  1. Action-oriented eviction：保留未来动作会反复访问的 cache 条目。  
  2. 用模型自身 confidence 自适应分配压缩预算。  
  3. 把压缩落到 page-aware 三个原语 + 定制 kernel，能接 paged attention。  
- 工程价值：直接打 agent serving 的长 trace KV 爆炸。报告 FullKV 准确率 98.53%、峰值 KV 仅 25.98%，token/task throughput 约 3.97× / 3.58×。可进生产级 agent runtime。  
- 是否值得读：强烈推荐  
- Relevance Score：5  
- Link：https://arxiv.org/abs/2609.31395

**【Title】** The KV Cache Is the New Memory Wall  
- 一句话总结：把 KV 优化文献统一到同一套 128k 协议和 roofline，给出“权重主导 / 交叉 / KV 主导”三段式。  
- 核心贡献：  
  1. 闭式算术强度随 context 衰减，并标定 H100 / B200 / MI300X 交叉点。  
  2. 量化、eviction、paging、prefix cache、异构分层五类各评一个代表方法。  
  3. 结论：paging/prefix 解容量不解带宽；量化/eviction 解带宽但质量悬崖清晰。  
- 工程价值：做 serving 选型的决策框架，避免被各论文不可比数字带偏。不直接给代码，但能立刻改容量规划。  
- 是否值得读：强烈推荐  
- Relevance Score：5  
- Link：https://arxiv.org/abs/2609.30854

### 2. AI Infra / Serving

**【Title】** Disaggregated Quantization: Specializing LLM Prefill and Decode  
- 一句话总结：prefill 与 decode 用不同精度/权重/放置，而不是一套量化打全程。  
- 核心贡献：  
  1. Decode 去掉 activation 量化，decode-heavy 任务精度回升且不增成本。  
  2. 单独训 compute-native prefill 权重；27B 上 NVFP4 prefiller 把 1-bit decode 的 MMLU-Pro +32.5。  
  3. Offloaded Disaggregated Prefill：SSD 流式加载 prefill 权重，8K prompt TTFT 1.78×。  
- 工程价值：和 PD 拆分天然对齐，可落 vLLM 类栈；单卡多 checkpoint 用 SSD 摊销。  
- 是否值得读：强烈推荐  
- Relevance Score：5  
- Link：https://arxiv.org/abs/2609.26333

**【Title】** Cross-Model Autoscaling for Shared LLM Serving (TRE)  
- 一句话总结：多模型共享集群的控制面，用可跨模型比较的 Token Service Share 做容量仲裁。  
- 核心贡献：  
  1. TSS：按需求归一化的有效 token 服务量，跨异构模型和 SLO 可比较。  
  2. 热切换栈上实现，不改推理 scheduler。  
  3. 相对 KV-cache 反应式 autoscaler：P95 降 11.9–79.0%，生产 conversation/code trace 上 P95/P99 降 50.8%/63.7%。  
- 工程价值：MaaS 多租户真正缺的是控制面信号，不是又一个 kernel。可直接对照 K8s + vLLM/Dynamo。  
- 是否值得读：强烈推荐  
- Relevance Score：4  
- Link：https://arxiv.org/abs/2609.29160

### 3. LLM Agents（系统设计）

**【Title】** Hot-Cold Tiering of HBM and High Bandwidth Flash for Agentic LLM Serving  
- 一句话总结：agent session 空闲时 KV 很大但不热；HBM 放热集、片上高带宽 Flash 放冷池。  
- 核心贡献：  
  1. 量化 agent KV：每步必读的小热集 vs resume 才读的大冷池。  
  2. 不把全部流量打到 HBF（写寿命/读能耗不行）。  
  3. Qwen3-Coder-30B-A3B：TBT 14ms，resume 只比 prefill 多 ~0.1ms，同卡 concurrent session 24×。  
- 工程价值：agent 并发的真实瓶颈是“暂停会话的 KV 驻留”，不是再压 2-bit。硬件路线清晰（HBF 开始可跟）。  
- 是否值得读：强烈推荐  
- Relevance Score：5  
- Link：https://arxiv.org/abs/2609.25782

**【Title】** KITE: KV-Invariant Transformer Expansion for Efficient Agentic LLM Scaling  
- 一句话总结：放大模型时新参数不进 attention KV，prefill KV 仍由小塔产生，训练可 upcycle、推理更便宜。  
- 核心贡献：  
  1. KV-invariant 扩参：新参数不影响 KV。  
  2. SST 双塔：一塔产 KV，一塔读 KV。  
  3. 67B MoE（decode 每 token 2.15B active）训练 loss 优于更小 MoE，估计推理成本降 6.7–31.6%。  
- 工程价值：agent 要更大模型但不想 prefill/KV 同比例涨；偏架构，落地周期长于 cache 系统文。  
- 是否值得读：可选  
- Relevance Score：3  
- Link：https://arxiv.org/abs/2609.27294

### 4. 量化 / 长上下文推理（补充，不占满额）

**【Title】** CompKV: Compensation-Aware KV Selection for Long-Context LLM Inference  
- 一句话总结：稀疏注意力的 token 选择应针对“漏掉后补偿误差最大”的块，而不是和补偿模块解耦。  
- 核心贡献：选择目标与下游补偿对齐；异步实现；RULER / LongBench-Pro 上优于对比稀疏基线，self-attention 最高 6.85×。  
- 工程价值：可进长上下文 serving 的 sparse attn 路径；比纯 eviction 更可落地。  
- 是否值得读：可选  
- Relevance Score：4  
- Link：https://arxiv.org/abs/2609.26300

**【Title】** Risk-Controlled KV-Cache Eviction  
- 一句话总结：eviction 从“平均质量-显存”改成“部署风险合同”：超过容忍的请求比例要有有限样本保证，否则回退 FullKV。  
- 核心贡献：同一合同下 Llama+LongBench 可证 SnapKV 75% retention，RULER-32K 则全部压缩策略都不达标。  
- 工程价值：给 SLO/合规团队用的验收层，不是新压缩算法。上线 eviction 前值得看。  
- 是否值得读：可选  
- Relevance Score：4  
- Link：https://arxiv.org/abs/2609.27981

## 额外输出

### 1. 今日最值得读 Top 3
1. **The KV Cache Is the New Memory Wall** — 先建立共同坐标系，再读其它 KV 文，否则数字不可比。  
2. **ActKV** — agent 工作负载下 KV 不再是“长文本压缩”问题，而是 action-critical 工作集问题，吞吐数字扎实。  
3. **Disaggregated Quantization** 或 **Hot-Cold HBM/HBF**（二选一都读也行）— 前者改 PD 精度契约，后者改 agent 驻留介质；都是能进机房的设计。

### 2. 今日趋势观察
- **Inference / KV 明显过热**：压缩、eviction、page、分层、工作集估计、风险控制同一周扎堆。  
- **Agent 不再只写 planner**：真正的增量在“长生命周期 KV 怎么住、怎么热/冷、怎么按 action 保真”。  
- **Serving 控制面回潮**：跨模型 autoscaling、EPD 拆分（EAServe，同日还有多模态 encode 阶段）说明单引擎优化不够，集群调度在补课。  
- Alignment / RLHF 本窗口工程信号弱。

### 3. 值得跟进的潜在方向
- **Agentic KV 工作集 + 分层介质**：KVSET 估 working set + ActKV 的 action 语义 + HBF 冷池，三条线会汇合。  
- **Phase-specialized 量化（prefill ≠ decode）**：和 PD/EPD 拆分绑定后，比全局 INT4/INT2 更接近生产。  
- **Eviction 的风险合同而非平均分数**：上线压缩必须有 fallback 与有限样本保证，否则长尾请求会炸 SLO。  
- **跨模型 token-service 信号**：共享 GPU 池的 autoscaler 会从“看 KV 占用”升级到“看有效 token 服务赤字”。
