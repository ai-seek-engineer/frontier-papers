### 1. Model Inference / 推理优化

**【Title】** Windowed-MTP: Removing the Full-Context Draft-KV Tax at Million-Token Context  
- 一句话总结：给原生 MTP 草稿头加 StreamingLLM 式滑动窗口 + sink，彻底砍掉百万 token 上下文下草稿侧全量 KV 读取税，训练无关、无损。  
- 核心贡献（2-3点）：  
  - 仅窗口化草稿 attention，验证侧仍全 attention，保证输出分布不变。  
  - 1M 上下文下草稿 KV 工作集降到常数，丢弃 ~99% 条目；单 GPU SGLang 实测 decode 步成本降 28–44%。  
  - 未读草稿 KV 用环形缓冲回收（占总量 7.7–11%），无精度损失。  
- 工程价值：直接可插现有 MTP/NEXTN 推理栈（Qwen GDN-MoE、Mamba2-hybrid 等）。长上下文 speculative decoding 从“可能净负收益”变成稳定加速，对百万 token 服务关键。  
- 是否值得读：强烈推荐  
- Relevance Score：5  
- Link：https://arxiv.org/abs/2607.21535

**【Title】** Error Certificates for KV-Cache Eviction via Randomized Design  
- 一句话总结：证明确定性 top-k KV 淘汰无法给出一致误差估计，改用 Poisson 采样尾部 + Hájek 校正，获得可证明的 per-step 误差证书。  
- 核心贡献（2-3点）：  
  - 理论：确定性淘汰不可辨识；随机化后用 survey-sampling 方差估计器给出覆盖率 ~0.97 的证书。  
  - 实证：证书能区分 cache 诱导 vs 固有失败（AUC 0.73–0.75），优于 output confidence；可驱动重计算调度。  
  - 预注册 7 个 claim，部分失败，结论更扎实。  
- 工程价值：给生产 KV 淘汰策略加可观测性与自适应预算控制。question-aware 淘汰在 25–50% 预算几乎免费，适合长上下文服务。  
- 是否值得读：强烈推荐  
- Relevance Score：4.5  
- Link：https://arxiv.org/abs/2607.21475

### 2. AI Infra / 分布式训练 / 系统优化

**【Title】** Fine-grained Computation-Communication Overlap via Tile-level Signaling and Scheduling for Mixture-of-Experts  
- 一句话总结：用 tile 级 signaling + 持久化 producer/consumer kernel，把 MoE 第二段 all-to-all 与 expert compute 细粒度重叠。  
- 核心贡献（2-3点）：  
  - 持久 producer（覆盖本 rank 所有 expert）+ 小 SM 分区持久 consumer，按 tile ready 发 segment 传输。  
  - 无需改底层算子/通信原语。  
  - 4×A100 上相对 SOTA 最高 2.64× e2e、2.74× MoE-layer 加速。  
- 工程价值：直接提升大规模 MoE 训练/推理吞吐，通信隐藏效果明显，实用性强。  
- 是否值得读：强烈推荐  
- Relevance Score：5  
- Link：https://arxiv.org/abs/2607.19539

**【Title】** Controlled Periodic Synchronization for Efficient Data-Parallel Training  
- 一句话总结：把同步频率当系统参数，用 CPDP（local update + gradient AllReduce + SlowMo 参数平均）在通信受限（跨站 WAN）环境改善 accuracy-time 权衡。  
- 核心贡献（2-3点）：  
  - PyTorch-DDP 兼容，K=4 时相对标准 DDP 精度 +2.44pp、墙钟时间 -13.8%。  
  - 直接 profile 显示暴露同步时间约减半。  
  - 在 Grid’5000 跨站点（16.6 ms RTT）验证有效。  
- 工程价值：地理分布式/高延迟训练场景可落地，同步频率成为可调旋钮。  
- 是否值得读：可选  
- Relevance Score：3.5  
- Link：https://arxiv.org/abs/2607.21224

### 4. SFT / Alignment / RLHF & Reinforcement Learning

**【Title】** The Dark Room in the Reward Channel: Dense Prediction Rewards Collapse GRPO-Trained LLM Agents -- and What Actually Works  
- 一句话总结：密集 prediction reward + GRPO 的 std 归一化会把 LLM agent 推进“暗室”坍缩（预测准但任务成功率为 0）；改用 auxiliary-loss 通道有效。  
- 核心贡献（2-3点）：  
  - 单因素消融定位：去掉 GRPO std 归一化即可避免灾难。  
  - 理论解释：all-fail group 下 z-score 使有界 reward 变无界压力。  
  - 控制实验显示 reward channel 最多中性，auxiliary-loss 通道可 +20 点，且 shuffled-gold 也能工作。  
- 工程价值：给 GRPO/类 RL 训练 agent 的 reward 设计踩坑指南，避免“看起来合理却彻底塌”的失败模式。  
- 是否值得读：强烈推荐  
- Relevance Score：4.5  
- Link：https://arxiv.org/abs/2607.21273
