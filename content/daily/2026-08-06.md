### Model Inference / 推理优化

**【Title】** Practical Online KV Cache Compaction for LLM Agents: An Empirical Study  
- 一句话总结：针对agent长轨迹的在线KV compaction，系统比较token eviction与attention matching，并强调proxy query选择的关键性。  
- 核心贡献（2-3点）：  
  - 将compaction从静态/离线假设转为agent在线场景（未来query未知）。  
  - 发现immediate compaction常伤性能，延迟到用agent自身future query可大幅恢复；TE在imperfect proxy下更稳健。  
  - 80% KV缩减同时保留多数准确率，并可提升吞吐。  
- 工程价值：直接可落地于agent serving（BrowseComp-Plus / WideSearch等），与vLLM类引擎兼容性强，解决真实长轨迹内存瓶颈。  
- 是否值得读：强烈推荐  
- Relevance Score：5  
- Link：https://arxiv.org/abs/2608.00902  

**【Title】** RestoreKV: Recovering Full-Cache Behavior Under Aggressive Query-Agnostic KV Cache Eviction  
- 一句话总结：在query-agnostic eviction的固定预算下，用轻量learned restoration恢复被丢弃token的贡献。  
- 核心贡献（2-3点）：  
  - 把eviction损失建模为可共享的compact residual，而非单纯改进selection。  
  - PEFT self-distillation（仅0.4%参数），无task-specific调优。  
  - 在多种backbone + 预算下显著缩小压缩导致的性能gap（例：KVzip 5%预算从38.2→73.2 on RULER-4K）。  
- 工程价值：可叠加在现有eviction方法上，几乎不增加cache construction开销，适合长期serving。  
- 是否值得读：强烈推荐  
- Relevance Score：5  
- Link：https://arxiv.org/abs/2608.01247  

### AI Infra / 分布式训练 / 系统优化

**【Title】** Energy-Efficient LLM Serving via Disaggregated Attention--FFN and Flexible Frequency Scaling  
- 一句话总结：AFlex框架联合做A/F资源分配 + GPU DVFS，针对disaggregated serving的能量优化。  
- 核心贡献（2-3点）：  
  - 全局scheduler + 本地operator-level DVFS。  
  - interleaved A/F pipeline + 动态microbatch / adaptive batching减少bubble。  
  - 在SGLang + A800上，相对SOTA disagg与frequency-scaling系统，能量/token降最多49%/48%，同时满足TTFT/TPOT SLO。  
- 工程价值：生产级能量与成本优化，直接针对Conversation/Coding traces，可落地到现有disagg serving栈。  
- 是否值得读：强烈推荐  
- Relevance Score：5  
- Link：https://arxiv.org/abs/2608.01891  

### LLM Agents（有系统设计）

**【Title】** InferScale: GPU-Native KV Injection for Personalized LLM Serving  
- 一句话总结：用GPU-native可复用KV state替代重复prefill，解决个性化/memory-augmented serving的TTFT膨胀。  
- 核心贡献（2-3点）：  
  - 预计算memory fact的KV + semantic embedding，serving时直接注入vLLM paged cache。  
  - Context-Window Encoding缓解上下文依赖。  
  - 无需引擎改动或模型微调；k=50时TTFT降72-79%（3.6-4.8×），吞吐3.7-4.5×。  
- 工程价值：与现有vLLM KV-connector无缝集成，直接降低memory-conditioned agent/服务的延迟与成本。  
- 是否值得读：强烈推荐  
- Relevance Score：4  
- Link：https://arxiv.org/abs/2607.27090
