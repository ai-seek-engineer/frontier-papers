### Model Inference / 推理优化

**【Title】**  
FlashRT: Agent Harness for Guiding Agents to Deploy Real-Time Multimodal Applications (arXiv:2607.18171)

- **一句话总结**：用coding agent自动探索IR转换+验证循环，将简单参考实现优化成多GPU实时多模态pipeline（disaggregation、streaming、parallelism）。
- **核心贡献**（2-3点）：
  - Agent-driven multi-pass transformation：IR捕获数据/状态依赖，自验证+测量门控优化。
  - 在NVIDIA B200和AMD MI355X上实现~70x latency减、3.6x throughput提升，优于专家vLLM实现。
  - 适用于voice agents、interactive video gen等异构pipeline。
- **工程价值**：直接可用于生产推理serving，解决多模态agent部署的手工调优痛点；KV cache/state依赖处理明确，跨硬件可扩展。
- **是否值得读**：**强烈推荐**（agent+infra结合，实验数据扎实）。
- **Relevance Score**：5/5
- **Link**：https://arxiv.org/abs/2607.18171

**【Title】**  
QuickSilver -- Speeding up LLM Inference through Dynamic Token Halting, KV Skipping... (arXiv:2506.22396，近期活跃讨论)

- **一句话总结**：无需重训的token-level框架，结合Dynamic Halting、KV Skipping、Token Fusion和自适应量化，实现~40% FLOP减且perplexity几乎不变。
- **核心贡献**：模块化、可组合机制，作用于frozen dense模型；兼容现有decoding。
- **工程价值**：推理加速即插即用，特别适合长序列/高吞吐部署，降低energy和latency。
- **是否值得读**：**强烈推荐**。
- **Relevance Score**：5/5
- **Link**：https://arxiv.org/abs/2506.22396

### LLM Agents（有落地/系统设计）

**【Title】**  
Towards Efficient Agents: A Co-Design of Inference Architecture and System (AgentInfer, arXiv:2512.18337v2)

- **一句话总结**：Agent专用co-design框架（AgentCollab双模型、cache-aware调度、SAM speculative decoding、semantic compression），端到端减少无效token 50%+，1.8-2.5x speedup。
- **核心贡献**：
  - 层次化reasoning + hybrid scheduler + suffix-automaton speculative。
  - 长horizon任务下维持认知稳定和效率。
- **工程价值**：直接针对agent serving痛点（multi-turn、context growth、tool interaction），KV cache和scheduler优化可集成现有系统。
- **是否值得读**：**强烈推荐**。
- **Relevance Score**：5/5
- **Link**：https://arxiv.org/abs/2512.18337

### SFT / Alignment / RLHF & Reinforcement Learning

**【Title】**  
ISO: An RLVR-Native Optimization Stack (arXiv:2607.19331)

- **一句话总结**：基于singular value谱分析的RLVR优化栈（ISO-Merger离线merge + ISO-Optimizer在线帧优化），继承base谱优化帧，实现更少steps达同/更好性能。
- **核心贡献**：揭示RLVR主要改singular frames而非spectrum；data-free merging和加速训练。
- **工程价值**：RL post-training加速（2.7x fewer steps），易集成现有optimizer（AdamW/Muon），适用于1.5B-8B规模reasoning/coding任务。
- **是否值得读**：**强烈推荐**（填补优化层空白）。
- **Relevance Score**：4.5/5
- **Link**：https://arxiv.org/abs/2607.19331

**【Title】**  
Distilled Reinforcement Learning for LLM Post-training (arXiv:2607.17247)

- **一句话总结**：融合teacher细粒度token-level指导的Distilled RL，解决标准RL credit assignment和OPD unconditional imitation问题，实现跨家族蒸馏有效性提升。
- **核心贡献**：Reverse importance sampling等组件；数学/ reasoning benchmarks上pass@1显著优于RL/OPD。
- **工程价值**：提升post-training效率和知识转移，适用于SFT+RLHF pipeline，code公开。
- **是否值得读**：**强烈推荐**。
- **Relevance Score**：4.5/5
- **Link**：https://arxiv.org/abs/2607.17247

**【Title】**  
When Does Muon Help Agentic Reinforcement Learning? (arXiv:2607.16169，近期)

- **一句话总结**：Muon在sparse-reward agentic RL中的条件优势分析，与AdamW对比显示特定advantage estimator+LR下显著提升成功率/收敛速度。
- **核心贡献**：单seed匹配实验 + ALFWorld等验证。
- **工程价值**：RL优化器选型指导，agentic long-horizon训练实用。
- **是否值得读**：**可选**（探索性但有洞见）。
- **Relevance Score**：4/5
- **Link**：相关HF讨论。
