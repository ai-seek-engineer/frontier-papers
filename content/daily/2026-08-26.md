**【Title】** OasisKV: Scaling In-Decode KV Cache Beyond HBM with Lookahead Sparse Prefetching  
- 一句话总结：基于vLLM的系统，利用speculative decoding的lookahead预测未来重要token，只把相关KV块prefetch进HBM，把稀疏性转成吞吐。  
- 核心贡献（2-3点）：  
  - 解耦完整KV与HBM，decode时只保留最相关token的KV；  
  - 用SD draft token做准确lookahead + 异步attention pipeline隐藏传输；  
  - PD disaggregation下显著降低per-request KV与decode-node host memory。  
- 工程价值：直接可落地于现有vLLM serving；1.69×（reasoning，几乎无损）~2.1×吞吐，内存压力大幅缓解，对长上下文/大batch极实用。  
- 是否值得读：强烈推荐  
- Relevance Score：5  
- Link：https://arxiv.org/abs/2608.08097  

**【Title】** OSCAR: Offline Spectral Covariance-Aware Rotation for 2-bit KV Cache Quantization  
- 一句话总结：离线估计attention-aware协方差，推导固定rotation + clipping，实现可部署的INT2 KV量化 + 自定义kernel。  
- 核心贡献（2-3点）：  
  - 旋转对齐真实attention消费的方向，而非简单Hadamard；  
  - 保留小BF16 sink/recent window，effective ~2.28 bit；  
  - 兼容paged KV、SGLang/vLLM的fused kernel。  
- 工程价值：~8×内存、大batch最高7×吞吐、BS=1最高3×；大模型（32B/358B）与128K长上下文仍接近BF16，生产级可集成。  
- 是否值得读：强烈推荐  
- Relevance Score：5  
- Link：https://arxiv.org/abs/2605.17757  

**【Title】** Self-Pruned Key-Value Attention: Learning When to Write by Predicting Future Utility  
- 一句话总结：端到端学习轻量utility predictor，动态决定哪些KV写入持久cache，实现3-10×压缩且几乎无损。  
- 核心贡献（2-3点）：  
  - 联合训练LLM + predictor（仅next-token loss），从预训练checkpoint适配；

  - 暴露层/头级稀疏模式，指导hybrid local-global架构。  
- 工程价值：训练时暴露稀疏可减少train-test mismatch；对长序列/RL rollout内存与速度提升明显，架构设计有启发。  
- 是否值得读：强烈推荐  
- Relevance Score：4  
- Link：https://arxiv.org/abs/2605.14037

### 1. 今日最值得读 Top 3
1. **OasisKV** — 真正系统级KV超越HBM方案，直接基于vLLM + SD协同，吞吐与内存收益清晰可复现，立刻可指导长上下文serving改造。  
2. **OSCAR** — 2-bit KV从“理论可行”到“可部署kernel + 框架兼容”，大模型与长上下文数据扎实，生产量化路线首选参考。  
3. **AIConfigurator** — 解决真实serving最大痛点（配置爆炸），无profile快速出Pareto配置，对infra团队ROI极高。  

### 2. 今日趋势观察
Inference/KV相关明显占主导（稀疏prefetch、超低bit量化、动态write、配置搜索），几乎全是系统+方法结合。RL/post-training加速也集中在rollout侧（异步框架 + speculative decoding集成），agent方向相对平淡，更多是训练系统而非新agent架构。  

### 3. 值得跟进的潜在方向
- **KV + Speculative Decoding协同设计**：OasisKV把lookahead直接用于prefetch，后续可扩展到更激进的稀疏/分层内存（CXL/host/remote）。  
- **Attention-aware超低bit KV的系统落地**：OSCAR已证明2-bit可用，下一步看与paged attention、disagg、多框架的深度融合与硬件kernel优化。  
- **RL rollout的系统级加速**：异步框架 + SD无损集成正在成为标配，值得跟进workload-aware调度与drafter在线更新。
