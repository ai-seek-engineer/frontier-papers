### 1. Inference / KV Cache 优化

**【Title】**  
ArborKV: Structure-Aware KV Cache Management for Scaling Tree-based LLM Reasoning

- **一句话总结**：针对Tree-of-Thoughts等树状推理的结构感知KV eviction框架，通过token-extractive策略+lazy rehydration实现内存高效扩展。
- **核心贡献**（2-3点）：
  1. 轻量value estimator结合tree-aware分配策略，优先保留高价值分支路径。
  2. 纯token抽取eviction + lazy rehydration，支持树状回溯而无需全量重算。
  3. 在ToT-style基准上实现~4x峰值KV内存降低，同时近乎保留完整准确率。
- **工程价值**：直接可用于长链条/分支推理serving（如agent planning、code reasoning），显著提升固定GPU内存下的并发/搜索深度；eviction策略有代码线索，易集成到vLLM/PagedAttention类系统。
- **是否值得读**：**强烈推荐**
- **Relevance Score**：5/5
- **Link**：https://arxiv.org/abs/2605.22106

**【Title】**  
Meta-Soft: Leveraging Composable Meta-Tokens for Context-Preserving KV Cache Compression

- **一句话总结**：输入自适应probe + semantic consolidation的动态KV压缩框架，使用composable meta-tokens保留关键上下文。
- **核心贡献**（2-3点）：
  1. Probe-driven动态压缩，适应不同输入的语义重要性。
  2. Meta-token机制实现上下文保持压缩，避免传统eviction/quantization的显著质量损失。
  3. 实验验证在长上下文下的有效性（具体benchmark数据支撑）。
- **工程价值**：适用于高吞吐long-context inference serving，可降低KV内存占用同时控制质量退化；动态性适合生产中变长请求场景。
- **是否值得读**：**强烈推荐**
- **Relevance Score**：4.5/5
- **Link**：https://arxiv.org/abs/2605.22337

### 2. LLM Agents（系统设计）

**【Title】**  
Claw AI Lab: An Autonomous Multi-Agent Research Team

- **一句话总结**：可交互的实验室级多代理研究平台，支持角色自定义、工作流、实时监控与代码执行harness，实现从idea到paper的闭环。
- **核心贡献**（2-3点）：
  1. Claw-Code Harness连接本地代码/数据集/checkpoint，支持真实实验执行与artifact反馈。
  2. Dashboard提供可视化监控、rollback/resume，显著提升agent系统可控性与可靠性。
  3. 内部评估显示在idea novelty、实验完整性、paper质量上优于baseline。
- **工程价值**：对构建生产级可复现Agent团队极有参考价值（代码开源），harness设计可迁移到企业内部RAG/研究pipeline；解决agent系统中常见“执行不可靠”痛点。
- **是否值得读**：**强烈推荐**
- **Relevance Score**：5/5（落地系统设计）
- **Link**：https://arxiv.org/abs/2605.22662 + GitHub

**【Title】**  
LCGuard: Latent Communication Guard for Safe KV Sharing in Multi-Agent Systems

- **一句话总结**：针对多代理latent KV通信的安全框架，通过轻量learnable transformation控制agent间敏感信息流。
- **核心贡献**（2-3点）：
  1. 在KV latent空间实现sanitization，防止敏感上下文泄露。
  2. 保留latent通信的效率优势（对比纯文本通信显著提速），仅引入适中overhead。
  3. 实验验证安全性和推理效率平衡。
- **工程价值**：直接解决multi-agent系统中KV sharing的安全风险；适用于需要隐私/隔离的agent orchestration系统，可集成到现有latent MAS框架。
- **是否值得读**：**强烈推荐**
- **Relevance Score**：4.5/5
- **Link**：https://arxiv.org/abs/2605.22786
