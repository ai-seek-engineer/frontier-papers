### 【Title】Windowed-MTP: Removing the Full-Context Draft-KV Tax at Million-Token Context
- **一句话总结**：针对百万 token 上下文下原生 MTP（Multi-Token Prediction） draft head 的全上下文 KV 读取开销问题，提出仅对 draft attention 应用 sliding window + sink 的无损优化，大幅降低 draft 成本。
- **核心贡献（2-3点）**：
  1. StreamingLLM-style windowing 仅限于 draft head（target 保持 full attention），训练-free、drop-in。
  2. 在 1M 上下文下将 draft KV working set 压缩至常量（回收 7.7-11% KV），端到端 decode latency 改善 28-44%。
  3. 跨 Qwen MoE、Mamba2-hybrid 等架构验证，接受率不降甚至提升。
- **工程价值**：**高**。直接解决长上下文 speculative decoding 的 KV 瓶颈，可集成到 SGLang/vLLM 等 serving 系统；对 fp8 KV 趋势友好，推理吞吐提升显著，尤其百万上下文场景。
- **是否值得读**：**强烈推荐**
- **Relevance Score**：5/5
- **Link**：https://arxiv.org/abs/2607.21535

### 【Title】Error Certificates for KV-Cache Eviction via Randomized Design
- **一句话总结**：证明确定性 KV eviction 无法可靠估计误差，提出 Poisson 采样 + Hájek 校正的随机 eviction + variance estimator，提供 per-step error certificate，用于区分 cache-induced 失败。
- **核心贡献（2-3点）**：
  1. 理论证明 deterministic top-k eviction 的不可辨识性问题。
  2. 随机设计实现 0.97 经验覆盖率的 error certificate，无 accuracy 损失。
  3. 实验显示 certificate 优于 output confidence 用于 gating recompute 和 attribution（AUC 提升）。
- **工程价值**：**高**。长上下文 serving 中 KV eviction 的可控性和可解释性关键；可直接用于生产 scheduler，实现 budget 动态调整和故障隔离。
- **是否值得读**：**强烈推荐**
- **Relevance Score**：5/5
- **Link**：https://arxiv.org/abs/2607.21475

### 【Title】Beyond Independent Optimization: Compression, MoE Routing, and Quantization Interactions in Multimodal Edge Intelligence
- **一句话总结**：系统性梳理多模态边缘推理中 token compression、MoE routing、quantization 的相互作用（而非独立优化），并引入 Temporal Routing Consistency 等诊断工具。
- **核心贡献（2-3点）**：
  1. 揭示 routing 决策受 compression 分布影响、quantization 敏感性随 routing 变化等交互效应，并给出 trade-off 分析。
  2. 针对 VLM/MoE 的具体 failure modes 和联合设计建议（如 routing-aware PTQ）。
  3. 实验/文献支撑多种场景下的性能恢复（e.g., W4A4 下恢复 1-2%）。
- **工程价值**：**高**。边缘/多模态部署的核心痛点，提供 co-design 框架而非孤立调优；对 MoE + Quant + KV 流水线优化有直接指导。
- **是否值得读**：**强烈推荐**
- **Relevance Score**：4.5/5
- **Link**：https://arxiv.org/abs/2607.20981

### 【Title】KroQuant: Kronecker-Structured Block Transforms for Efficient Post-Training Quantization of Diffusion Transformers
- **一句话总结**：针对 DiT W4A4 量化中 activation outliers，提出 Kronecker 结构 block transform（32-element）[118;1:3u，结合 offline weight calibration，实现更好质量且 inference 更快。
- **核心贡献（2-3点）**：
  1. 参数量 < per-channel scaling，计算用小 GEMM，kernel 比 SmoothQuant 快至 14%。
  2. 在 PixArt、SANA、FLUX 等模型上优于 SVDQuant/LoRaQ，接近 FP 参考。
  3. PTQ 无需重训，工程友好。
- **工程价值**：**高**。扩散模型（尤其是生成任务）推理优化直接可用；DiT 部署的关键加速技术。
- **是否值得读**：**强烈推荐**
- **Relevance Score**：4.5/5
- **Link**：https://arxiv.org/abs/2607.21446

### 【Title】OpenForgeRL: Train Harness-native Agents in Any Environment
- **一句话总结**：开源框架通过 proxy + Kubernetes orchestrator 解耦训练/推理，支持在任意真实 harness（如 tool/claw、GUI browser）中端到端 RL 训练 agent。
- **核心贡献（2-3点）**：
  1. 轻量 proxy 记录数据 + 容器化 rollout，实现 scale 训练。
  2. 在 ClawEval、OSWorld 等 benchmark 上以少量任务数据超越同规模 baseline，甚至匹配更大模型。
  3. 分析 harness 差异和 RL 对 agent 可靠性（self-verification、多步规划）的提升。
- **工程价值**：**中高**。LLM Agents 落地关键：便于在生产 harness 上 fine-tune/RL，提升 agentic 可靠性；代码开源易复现。
- **是否值得读**：**推荐**
- **Relevance Score**：4/5
- **Link**：https://arxiv.org/abs/2607.21557
