**Inference / 推理优化方向（优先，工程价值最高）**

【Title】SmartGen: Seamless Disaggregated LLM Inference with Selective KV Cache Transfer  
- 一句话总结：针对 prefill-decode 解耦部署中的 KV 传输带宽瓶颈，设计选择性 KV 传输引擎，用三条路径（proactive / on-demand / speculative）显著降低 TTST。  
- 核心贡献（2-3点）：  
  1. Profile-based proactive 推送关键 KV 到 decode 节点；  
  2. Parallel on-demand 同时拉本地+远程 KV；  
  3. Speculative 路径最终补齐完整缓存。  
- 工程价值：直接可落地于自建/租云 disaggregated serving（尤其带宽受限场景）。实测 TTST 最高 4.3×，后续 decode 性能与精度基本无损。对 vLLM/SGLang 类系统、云上多节点推理有明确系统级优化价值。  
- 是否值得读：强烈推荐  
- Relevance Score：5  
- Link：https://arxiv.org/abs/2607.28150  

【Title】A Sparse Glimpse of the Whole: Train-Free Self-Speculative Decoding (SparseSpec-L)  
- 一句话总结：训练无关的自投机解码框架，用动态稀疏可召回 KV cache + 在线熵控制器，专攻长上下文加速。  
- 核心贡献：  
  1. 复用 verification 阶段的 per-head attention 统计做重要性信号，无需额外 forward；  
  2. 动态稀疏 draft + 可召回 dense KV；  
  3. 基于期望步效率的 speculation length 在线控制。  
- 工程价值：纯 inference-time、无额外模型、无训练，长上下文场景可直接插。端到端加速显著且保持输出分布。适合现有 serving 框架快速集成。  
- 是否值得读：强烈推荐  
- Relevance Score：5  
- Link：https://arxiv.org/abs/2607.27735  

【Title】WIDE: Boosting Adaptive LLM Inference via Token-level Dynamic Width Pruning  
- 一句话总结：首个端到端可微的 token 级动态 width pruning（attention-head group + FFN-channel group），覆盖 prefill + decode。  
- 核心贡献：  
  1. Token 级细粒度动态选择；  
  2. 两阶段训练学出有效稀疏模式；  
  3. Pruning-kernel 协同设计（mask 重排 + block/intra-block skipping）。  
- 工程价值：50% sparsity 下相对 SOTA 动态 depth pruning 质量提升 55.1%；kernel 级加速接近理论（prefill 1.98×、decode 4.95×），e2e 1.55–1.68×。有代码，硬件友好方向明确。  
- 是否值得读：强烈推荐  
- Relevance Score：5  
- Link：https://arxiv.org/abs/2607.28418  

【Title】Back from the Future: Key-Value Cache Management by Counter-Causal Surprise  
- 一句话总结：用 counter-causal attention（让过去 token 只看未来）打分冗余度，做无训练 KV eviction。  
- 核心贡献：  
  1. 复用已有 KV 做 in-distribution 的 counter-causal 前向；  
  2. 单层近似大幅降低 refresh 开销。  
- 工程价值：长上下文 KV 管理实用方案，有参考代码，可与现有 eviction 策略对比/组合。  
- 是否值得读：可选  
- Relevance Score：4  
- Link：https://arxiv.org/abs/2607.27600  

**LLM Agents 方向**

【Title】Rethinking Inference-Time Scaling in Local Computer-Use Agents: Failure Modes and Compute Tradeoffs  
- 一句话总结：系统研究本地 CUA 的 inference-time scaling（context / temporal / structural / parallel）在资源受限下的失效模式与收益边界。  
- 核心贡献：  
  1. 多维度 scaling 的实证对比（OSWorld + 多个本地 VL 模型）；  
  2. 揭示收益饱和、失败模式迁移（重复/停滞 → 过早假成功）；  
  3. 对 local model 能力边界下的 selective compute 与 failure-aware 控制提出建议。  
- 工程价值：本地部署 agent（隐私/成本敏感）的实际系统设计指南，避免盲目堆 inference compute。  
- 是否值得读：强烈推荐（做 local agent 的必读）  
- Relevance Score：4  
- Link：https://arxiv.org/abs/2607.28573  

**（其他方向：SFT/Alignment/RLHF、纯 RL、分布式训练在过去 24-48h 内无明显高工程价值新作，按宁缺毋滥原则不凑数）**

### 今日最值得读 Top 3
1. **SmartGen** — 直接解决当前 disaggregated LLM serving 的核心网络瓶颈，4.3× TTST 提升 + 系统实现完整，工程落地价值最高。  
2. **SparseSpec-L** — 训练无关、长上下文自投机，分析+方法+控制器闭环，可快速验证与集成。  
3. **WIDE** — Token 级动态 width + kernel 协同，质量与加速兼顾，有代码，代表细粒度自适应推理的新方向。

### 今日趋势观察
Inference 优化（尤其 KV cache 管理、选择性传输、自投机、动态稀疏）明显占主导，过去 24-48h 相关论文密度远高于其他方向。Agent 相关以 local/推理时 scaling 的实证研究为主，而非新架构爆发。分布式训练与 alignment 本窗口相对安静。

### 值得跟进的潜在方向
- **Disaggregated inference 的 KV 选择性传输与多路径调度**（SmartGen 类）：云上带宽受限场景会持续重要，后续可关注与现有 scheduler/调度器的深度结合。  
- **Train-free self-speculative + 动态稀疏 KV**（SparseSpec-L 类）：长上下文 + 无额外模型的组合仍有优化空间，尤其与 kernel/硬件协同。  
- **Local agent 的 failure-aware inference-time compute 分配**：本地部署约束下“怎么花算力”比“花更多算力”更关键。
