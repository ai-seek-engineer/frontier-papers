**【Title】** UltraQuant: 4-bit KV Caching for Context-Heavy Agents (arXiv:2606.20474)

- **一句话总结**：针对多轮上下文密集型Agent场景，提出4-bit KV cache量化方案，在AMD GPU上实现显著吞吐和TTFT提升，同时保持任务质量。
- **核心贡献（2-3点）**：
  1. 围绕Agent多轮工作负载联合评估任务质量、cache驻留和serving吞吐，设计robust的4-bit路径（asymmetric K/V、非均匀旋转、block-scale等）。
  2. AMD GPU特定serving优化：优化decode-attention kernel + FP4近似路径（FP8 query + FP4 KV + UE8M0 scales + native scaled-MFMA）。
  3. 在长上下文多轮Agent负载上，P50 TTFT在cache压力大的后期rounds提升3.47x（整体2.3x），输出吞吐提升1.63x vs FP8 baseline。
- **工程价值（重点分析：是否能用于推理/infra优化）**：**极高**。直接针对Agent长前缀复用+并发场景的KV内存瓶颈，提供生产级4-bit实现路径（与vLLM FP8对齐），易集成到现有serving栈，尤其AMD硬件；量化+kernel优化可直接降低内存占用、提升batch size和throughput，是推理优化的实用落地。
- **是否值得读**：**强烈推荐**。
- **Relevance Score**：5。
- **Link**：https://arxiv.org/abs/2606.20474

**【Title】** SAC: Disaggregated KV Cache System for Sparse Attention LLMs with CXL (arXiv:2606.19746)

- **一句话总结**：针对稀疏注意力LLM，提出基于CXL的disaggregated KV cache系统，按需细粒度fetch top-k条目，解决传统RDMA全量fetch的低效问题。
- **核心贡献（2-3点）**：
  1. 利用CXL低延迟cache-line粒度load/store，仅传输活跃KV条目，避免稀疏模型下的内存浪费和传输开销。
  2. 在DeepSeek-V3.2 + SGLang上的全面评估，显著优于RDMA baseline。
  3. 为新兴稀疏注意力模型提供专用disagg infra设计。
- **工程价值（重点分析：是否能用于推理/infra优化）**：**极高**。直接解决长上下文/稀疏注意力下的内存和通信瓶颈，CXL硬件趋势下可扩展到多节点serving；2.1x throughput、9.7x TTFT降低等数据支撑生产部署，是AI Infra/分布式推理优化的强系统工作。
- **是否值得读**：**强烈推荐**。
- **Relevance Score**：5。
- **Link**：https://arxiv.org/abs/2606.19746

**【Title】** Execution-State Capsules: Graph-Bound Execution-State Checkpoint and Restore for Low-Latency, Small-Batch, On-Device Physical-AI Serving (arXiv:2606.20537)

- **一句话总结**：为低延迟、小batch on-device Physical-AI（如交互Agent、机器人）提出execution-state capsules，实现完整执行状态（含KV、recurrent等）的graph-bound快照/恢复/分支。
- **核心贡献（2-3点）**：
  1. 超越传统KV paged cache，处理完整可恢复状态，支持分支、重置、中断等交互场景。
  2. FlashRT内核运行时实现高效graph计划执行；GPU-resident snapshot/restore亚毫秒级，TTFT在长上下文下提升高达27x。
  3. 在NVIDIA/Jetson等硬件验证正确性和结构优势。
- **工程价值（重点分析：是否能用于推理/infra优化）**：**高**。针对on-device/低延迟serving的特定场景（与高吞吐KV cache互补），提供状态管理新原语，可显著加速交互式Agent推理；对边缘/物理AI infra优化价值大，代码/内核线索支持复现。
- **是否值得读**：**强烈推荐**（若关注on-device/Agent）。
- **Relevance Score**：4。
- **Link**：https://arxiv.org/abs/2606.20537
