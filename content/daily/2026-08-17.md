### 1. Model Inference / 推理优化

**【Title】** DARTree: Speculative Diffusion Decoding with Autoregressive Draft Trees  
- 一句话总结：把 Diffusion drafter 的并行提案能力与 AR 树式修正结合，训练-free 大幅提升 speculative decoding 的接受长度与无损加速。  
- 核心贡献：  
  1. 固定宽度候选树 + 批量扩展打分，再 best-first 剪枝得到验证树。  
  2. 将已有 AR correction head 从 chain 扩展到 tree，解耦 AR-head 推理与堆操作。  
  3. 在 7 个 math/code/chat benchmark 上最高平均接受长度，最高可达 12.97 tokens/round（比 DFlash 高 98.6%）。  
- 工程价值：直接可插现有 speculative decoding 流水线，无损加速最高 9.73×（相对本地 AR），对长生成与高吞吐 serving 立即可用。  
- 是否值得读：强烈推荐  
- Relevance Score：5  
- Link：https://arxiv.org/abs/2608.13524

**【Title】** vToken: Token-Level Virtualization for Reclaimable KV Caches  
- 一句话总结：在 PagedAttention 之上加轻量 token 级虚拟化层，解决 eviction 算法与 block 粒度不匹配导致的碎片与不可回收内存。  
- 核心贡献：  
  1. Token-table 间接寻址 + 异步 live-token repacking，逻辑 token 视图稳定。  
  2. 完全兼容现有 PagedAttention kernel 与 CUDA Graph。  
  3. 在 vLLM 实现，配合 H2O/Random/Scissorhands，KV block 减少 27–72%，SLA 吞吐最高 +1.37×，并发能力最高 2×。  
- 工程价值：极高。几乎所有生产 KV eviction 系统都受碎片困扰，集成成本极低（策略集成从 500+ 行降到 <50 行），直接提升内存利用率与吞吐。  
- 是否值得读：强烈推荐  
- Relevance Score：5  
- Link：https://arxiv.org/abs/2608.13263

### 2. AI Infra / 分布式训练 / 系统优化

**【Title】** OpScale: Operator-level Provisioning and Autoscaling for LLM Serving  
- 一句话总结：把 LLM serving 的扩缩容粒度从“整模型”下沉到“operator 级”，用 profiling + 放置 + 运行时编排解决 burst 下的 SLO 与 GPU 浪费。  
- 核心贡献：  
  1. 量化 operator 异构性，证明 operator-level 弹性可行。  
  2. 完整框架覆盖 profiling、provisioning、placement、runtime。  
  3. 生产 trace 上最高用 36.3% 更少 GPU / 28% 更低功耗达到相同 SLO，或固定成本下吞吐 +44%。  
- 工程价值：云端 LLM serving 的核心痛点（成本 vs SLO）。比整模型扩缩容精细得多，对多租户/burst 场景有直接落地价值。  
- 是否值得读：强烈推荐  
- Relevance Score：5  
- Link：https://arxiv.org/abs/2608.13499

**【Title】** TEMPO: Makespan-Aware Expert-Parallel Load Balancing Across Memory- and Compute-Bound Regimes  
- 一句话总结：针对 MoE expert-parallel 在不同 batch 规模下同时出现 memory-bound 与 compute-bound 的问题，提出 makespan-aware 调度，精确建模双 regime。  
- 核心贡献：  
  1. 实测发现 expert 时间不是简单线性于 token 数，存在明确 crossover 点（≈156–168 tokens）。  
  2. 用 max-affine 模型 + 固定 charge makespan 问题形式化，毫秒级求解。  
  3. SGLang 集成，Qwen3-235B 吞吐 +4–6%，p99 延迟 -15.6%。  
- 工程价值：MoE 推理/服务中 EP 负载均衡的精细化，尤其对 decode 阶段冷热专家混杂的场景。有代码。  
- 是否值得读：强烈推荐  
- Relevance Score：4  
- Link：https://arxiv.org/abs/2608.13057

**【Title】** RoutePack: Expert Placement and Attention-Aware Data Packing for MoE Reinforcement Learning  
- 一句话总结：在 MoE RL 训练中同时优化 expert 放置与 attention-aware packing，利用 rollout 时已暴露的路由信息做联合规划。  
- 核心贡献：  
  1. 分层 planner：先按层做 state-consistent expert rerouting，再做 attention + expert 感知的 data packing。  
  2. 在 optimizer-step 窗口上最小化最慢 EDP shard 的累积成本。  
  3. Ling 系列模型上吞吐提升 8.85–14.89%。  
- 工程价值：直接针对当前最贵的 MoE RL 训练阶段（rollout + train 耦合），能显著降低训练墙钟时间。  
- 是否值得读：可选  
- Relevance Score：4  
- Link：https://arxiv.org/abs/2608.12146

### 3. LLM Agents（系统设计）

**【Title】** Ready Cohorts: Bounding GPU Opportunity and Avoiding Host Round Trips in LLM-Agent Control  
- 一句话总结：形式化 agent 控制路径中“ready cohort”边界，量化 GPU 可并行的机会，并证明把路由决策留在 GPU 上可显著减少 host round-trip。  
- 核心贡献：  
  1. 用 fixed-partition share / exact offline share / local upper bound 精确刻画并发机会。  
  2. 设备端保留 GPU 计算的二进制路由决策，避免 4-byte 回传 + 再调度，加速 1.19–2.39×。  
  3. 大规模 trace 验证所有 batched 调用与 host oracle 完全一致。  
- 工程价值：agent serving 中控制面延迟与 GPU 利用率的核心问题。给出可测量的“什么时候值得把控制逻辑下沉到 GPU”的边界条件。有代码与数据。  
- 是否值得读：强烈推荐  
- Relevance Score：4  
- Link：https://arxiv.org/abs/2608.12123

### 【额外输出】

**1. 今日最值得读 Top 3**
1. **vToken** — 解决了生产环境中几乎所有人都会碰到的 KV 碎片问题，改动小、收益大、直接可合入 vLLM。  
2. **OpScale** — 把 serving 扩缩容从粗粒度模型级推进到 operator 级，对云成本与 SLO 有立竿见影的影响。  
3. **DARTree** — speculative decoding 的又一次明显接受长度突破，训练-free 且加速幅度大，工程落地路径清晰。

**2. 今日趋势观察**  
Inference 侧（尤其 KV 管理 + speculative decoding）与 MoE 相关的系统优化明显集中。Agent 控制面的 GPU 下沉与并发机会量化也开始出现系统级论文，说明社区从“agent 能不能做”转向“agent 控制路径怎么高效跑”。

**3. 值得跟进的潜在方向**  
- **Token-level virtualization + 异步 repacking**：可与更多 eviction / quantization 策略组合，进一步压低有效 KV 占用。  
- **Operator-level / stage-level autoscaling**：在 prefill-decode 分离与 PD-disaggregation 场景下有更大空间。  
- **Agent control path 的 GPU-resident 决策**：减少 host round-trip 是低延迟 agent serving 的关键瓶颈，值得系统化。
