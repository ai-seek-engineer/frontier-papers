### Inference / KV Cache 优化

**【Title】**  
Sparse Attention as a Range Searching Problem: Towards an Inference-Efficient Index for KV Cache (Louver)

- **一句话总结**：将稀疏注意力重构为半空间范围搜索问题，提出 Louver 索引实现带召回保证（zero false negatives）的 KV 检索，硬件友好且优于 FlashAttention。
- **核心贡献**（2-3点）：
  1. 理论上保证关键 KV 不漏检（query/step 依赖场景下尤其重要）。
  2. 轻量索引 + CPU/GPU 优化，实际 runtime 快于高优化 dense attention。
  3. 长推理任务中显著降低错误尖峰。
- **工程价值**：直接可集成到现有 serving 栈（vLLM/SGLang 等），解决稀疏注意力的可靠性痛点，内存/延迟双赢，生产推理必看。
- **是否值得读**：**强烈推荐**
- **Relevance Score**：5/5
- **Link**：https://arxiv.org/abs/2605.06763

**【Title】**  
Training Transformers for KV Cache Compressibility (KV-CAT)

- **一句话总结**：通过 continued pretraining（训练时 KV 稀疏掩码）让模型学到“天生可压缩”的表示，提升下游 post-hoc 压缩方法的 quality-budget tradeoff。
- **核心贡献**（2-3点）：
  1. 形式化 KV compressibility 为模型表示属性，而非仅上下文。
  2. KV-CAT 训练策略简单有效，覆盖 retrieval / long-context QA / perplexity。
  3. 证明几乎任意 seq-to-vec 函数都有 compressible vs non-compressible 实现。
- **工程价值**：从源头优化 KV 压缩潜力，适用于长期模型迭代/蒸馏 pipeline，能系统性降低长上下文部署成本。
- **是否值得读**：**强烈推荐**
- **Relevance Score**：5/5
- **Link**：https://arxiv.org/abs/2605.05971

### LLM Agents（系统设计）

**【Title】**  
APWA: A Distributed Architecture for Parallelizable Agentic Workflows

- **一句话总结**：针对高度可并行 agentic 任务的分布式架构，通过分解为非干扰子问题实现独立资源并行执行，解决 scaling bottleneck。
- **核心贡献**（2-3点）：
  1. 动态分解复杂查询为并行 workflow，支持异构数据/处理模式。
  2. 在先前系统完全失败的大任务上有效 scaling。
  3. 广泛 domain 适用 + 详细 eval（25页，14 tables）。
- **工程价值**：直接指导多 agent serving / orchestration 系统的 infra 设计，尤其适合高吞吐并行场景（如批量工具调用、模拟）。
- **是否值得读**：**强烈推荐**
- **Relevance Score**：4.5/5
- **Link**：https://arxiv.org/abs/2605.15132

### SFT / Alignment / RLHF

**【Title】**  
How to Compress KV Cache in RL Post-Training? Shadow Mask Distillation for Memory-Efficient Alignment

- **一句话总结**：针对在线 RL（RLHF/GRPO 等） rollout 的长上下文内存墙，提出 Shadow Mask Distillation 缓解 KV 压缩引入的 off-policy bias。
- **核心贡献**（2-3点）：
  1. 诊断压缩误差在 RL 不稳定优化中被显著放大的问题。
  2. 蒸馏方案纠正 sampler（sparse） vs learner（dense）不匹配。
  3. 显著提升长上下文 RL 训练 throughput。
- **工程价值**：直接解决 RL post-training 的内存/效率瓶颈，对 reasoning-heavy alignment 落地至关重要。
- **是否值得读**：**强烈推荐**
- **Relevance Score**：5/5
- **Link**：https://arxiv.org/abs/2605.06850

**【Title】**  
Reformulating KV Cache Eviction Problem for Long-Context LLM Inference

- **一句话总结**：重新形式化 KV eviction 问题，提供更优的长上下文处理框架与 benchmark 结果。
- **核心贡献**：系统性改进 eviction 策略，实验显示在 MATH/长序列任务上的显著提升。
- **工程价值**：Eviction 是 KV 管理核心，适用于生产长上下文 serving。
- **是否值得读**：**可选**（方法创新较 incremental 但数据扎实）
- **Relevance Score**：4/5
- **Link**：https://arxiv.org/abs/2605.07234

### 今日最值得读 Top 3（理由）

1. **Louver (Sparse Attention Index)**：召回保证 + 硬件优化 + 优于 FlashAttention，工程落地即战力最高。
2. **KV-CAT**：从训练源头解决 compressibility，长期高杠杆，对 infra/部署影响深远。
3. **Shadow Mask Distillation (RL KV)**：精准击中 RL 长上下文 rollout 内存墙，Alignment 工程师必读。

### 今日趋势观察

Inference/KV 优化持续高热（索引、训练时可压缩性、eviction），Agent 系统向分布式/并行架构演进明显（APWA 等），RL post-training 内存优化开始爆发。无明显新爆炸方向，但“KV + RL/Agent 交叉”热度上升，反映生产落地压力。

### 值得跟进的潜在方向

**训练时 KV compressibility + RL rollout 联合优化**：KV-CAT 类方法若扩展到 RL 训练循环，可系统性解决长上下文 alignment 的 scaling 问题，值得持续跟踪后续工作。整体趋势是把“压缩”从 inference-time 提前到 training-time + 系统 co-design。
