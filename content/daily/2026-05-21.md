### **Inference / 推理优化**

**【Title】**  
SpecSA: Bridging Speculative Decoding and Sparse Attention for Efficient LLM Inference (arXiv:2605.19893, 19 May 2026)

- **一句话总结**：将动态稀疏注意力与 speculative decoding 融合，通过稀疏验证框架显著降低长上下文推理的 KV cache 访问压力。
- **核心贡献**（2-3点）：
  1. 稀疏 speculative-verification 框架，把动态稀疏注意力转为验证导向 workload。
  2. 结合 speculative decoding 的多 token 验证与 sparse attention 的 KV 缩减。
  3. 系统级 co-design，支持高效 GPU 实现。
- **工程价值**：直接针对长上下文 inference 瓶颈（KV cache bandwidth/memory），可与现有 speculative（如 EAGLE）或 sparse attn 框架集成，提升 throughput，尤其适合生产长上下文 serving。实验支撑明确，有 benchmark 数据。
- **是否值得读**：**强烈推荐**
- **Relevance Score**：5/5
- **Link**：https://arxiv.org/abs/2605.19893

**【Title】**  
KVDrive: A Holistic Multi-Tier KV Cache Management System for Long-Context LLM Inference (arXiv:2605.18071, 18 May 2026)

- **一句话总结**：跨 GPU HBM、host DRAM、SSD 的多层 KV cache 管理系统，实现长上下文下高效 tiered 存储与管理。
- **核心贡献**（2-3点）：
  1.  holistic multi-tier 设计，超越单一 sparsity/eviction。
  2. 智能 tiering 与 eviction 策略，平衡 latency/memory/throughput。
  3. 系统实现细节支撑实际部署。
- **工程价值**：极高，解决生产环境中长上下文 GPU 显存不足问题，可直接用于 serving 系统（如 vLLM/TensorRT-LLM 扩展），多 tier 管理是 infra 标配方向，有复现潜力。
- **是否值得读**：**强烈推荐**
- **Relevance Score**：5/5
- **Link**：https://arxiv.org/abs/2605.18071

### **LLM Agents（系统设计/落地）**

**【Title】**  
PEEK: Context Map as an Orientation Cache for Long-Context LLM Agents (arXiv:2605.19932, ~20 May 2026)

- **一句话总结**：为 recurring 长上下文 Agent 设计“context map”作为 orientation cache，缓存上下文结构/实体/历史有用信息，减少重复探索。
- **核心贡献**（2-3点）：
  1. Distiller + Cartographer + priority Evictor 的可编程 cache policy，固定 token budget。
  2. 在 long-context reasoning/info aggregation 上大幅提升 accuracy 并降低 cost/iterations。
  3. 跨 LM 和 agent 架构泛化（含 production coding agent）。
- **工程价值**：Agent 实际落地关键—— recurring 外部上下文（文档/代码库）场景下，降低 token 消耗和 latency，可集成到 Agent 框架中作为 memory/orientation 层。强实验支撑。
- **是否值得读**：**强烈推荐**
- **Relevance Score**：4.5/5
- **Link**：https://arxiv.org/abs/2605.19932

**【Title】**  
A Methodology for Selecting and Composing Runtime Architecture Patterns for Production LLM Agents (arXiv:2605.20173, 20 May 2026)

- **一句话总结**：生产级 LLM Agent 的 runtime architecture patterns 选择与组合方法论，关注 hybrid classification、GPU/CPU 分离等工程决策。
- **核心贡献**：系统化 patterns 库 + 选择框架，强调异步 orchestration 等 infra 考量。
- **工程价值**：偏系统设计与部署，可帮助构建可靠生产 Agent pipeline，有代码 repo 线索。
- **是否值得读**：**可选**（更偏架构而非核心算法创新）
- **Relevance Score**：3.5/5
- **Link**：https://arxiv.org/abs/2605.20173
