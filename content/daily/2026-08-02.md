**【Title】** SmartGen: Seamless Disaggregated LLM Inference with Selective KV Cache Transfer  
- 一句话总结：针对disaggregated prefill/decode架构，通过选择性KV cache传输解决云上有限带宽瓶颈。  
- 核心贡献：  
  1. 三路径KV传输引擎（profile-based proactive + parallel on-demand + speculative）。  
  2. prefill阶段准确选择关键KV，decode阶段高效fetch。  
  3. 实测TTST降低最高4.3×，后续decode性能与精度基本持平。  
- 工程价值：直接可落地到自托管/云租用场景的disaggregated serving（vLLM/llm-d类系统）。选择性传输是当前KV transfer的核心痛点，带宽敏感环境立刻可用。  
- 是否值得读：强烈推荐  
- Relevance Score：5  
- Link：https://arxiv.org/abs/2607.28150

**【Title】** WIDE: Boosting Adaptive LLM Inference via Token-level Dynamic Width Pruning  
- 一句话总结：首个端到端可微的token-level动态宽度剪枝框架，同时覆盖prefill与decode。  
- 核心贡献：  
  1. token可动态选择attention-head groups与FFN-channel groups（细粒度到neuron-block）。  
  2. 两阶段训练 + pruning-kernel co-design（mask reordering + block/intra-block skipping）。  
  3. 50%稀疏下性能优于SOTA动态深度剪枝55.1%；kernel级加速最高1.98×（prefill）/4.95×（decode），e2e 1.68×/1.55×。有代码。  
- 工程价值：动态稀疏推理的实用加速方案，kernel co-design使细粒度动态剪枝真正可部署，比静态结构化剪枝精度保留更好。  
- 是否值得读：强烈推荐  
- Relevance Score：5  
- Link：https://arxiv.org/abs/2607.28418

**【Title】** DualDecoder: Accelerate Long Context LLM Inference by Predictive Prefetch  
- 一句话总结：用双token解码管道预测关键KV，实现host memory sparse KV的高效prefetch，消除辅助状态GPU内存开销。  
- 核心贡献：  
  1. 关键洞察：下一token的关键KV可从前一speculated token准确预测。  
  2. dual-token pipeline + layer-aware transfer schedule + layer-scoped memory manager。  
  3. 解码吞吐最高提升2.62×，同时保持延迟与模型质量。  
- 工程价值：长上下文+高并发场景的sparse KV offload系统级优化，直接解决现有方法的auxiliary state瓶颈。适合agentic长上下文serving。  
- 是否值得读：强烈推荐  
- Relevance Score：5  
- Link：https://arxiv.org/abs/2607.26475

**【Title】** InferScale: GPU-Native KV Injection for Personalized LLM Serving  
- 一句话总结：用可复用KV state替代反复prefill个性化memory，实现GPU-native注入。  
- 核心贡献：  
  1. 预计算memory fact的KV，存GPU并语义检索后直接注入vLLM paged cache。  
  2. Chunked RoPE + Context-Window Encoding解决动态组装与位置编码问题。  
  3. TTFT随retrieval budget几乎不变（k=50时降72-79%，3.6-4.8×），吞吐提升3.7-4.5×，精度接近。无修改引擎。  
- 工程价值：个性化/长期记忆serving的直接加速（Mem0/MemGPT类系统）。KV injection接口干净，生产可落地。  
- 是否值得读：强烈推荐  
- Relevance Score：4.5  
- Link：https://arxiv.org/abs/2607.27090

**【Title】** Stage-Replay Divergence Follows the KV Cache: Fixed-Prefix Precision Controls and Bidirectional Cache Transplantation  
- 一句话总结：实验证明stage-replay的分歧主要由KV cache状态决定，精度与cache transplantation可精确控制行为。  
- 核心贡献：  
  1. 系统审计显示BF16下exact-token replay仍会产生分歧，FP32则消除。  
  2. 双向KV transplantation实验证明cache是分歧的充分载体。  
  3. 提供可复现artifacts。  
- 工程价值：对推理系统调试、确定性、cache一致性有直接参考价值（尤其是多阶段/重放场景）。不是新优化算法，但系统级理解深刻。  
- 是否值得读：可选  
- Relevance Score：3.5  
- Link：https://arxiv.org/abs/2607.28495

**【额外输出】**

1. **今日最值得读 Top 3**  
   - **SmartGen**：disaggregated架构的KV传输是当前生产serving的真实瓶颈，4.3× TTST提升直接可验证。  
   - **WIDE**：细粒度动态宽度剪枝 + kernel co-design，兼顾精度与实际加速，有代码，工程闭环完整。  
   - **DualDecoder**：长上下文sparse KV的系统级prefetch优化，解决了auxiliary state这个常被忽视的痛点，agentic场景相关性高。

2. **今日趋势观察**  
   Inference侧（尤其KV cache管理与disaggregated serving）明显占主导。过去48小时cs.DC与cs.AI新提交中，KV transfer/injection/prefetch、动态剪枝、长上下文offload相关工作密度较高。Agent相关有零星（如MANTA、ClawTrack），但系统级落地不足。分布式训练/并行策略本窗口几乎无新增高质量工程论文。

3. **值得跟进的潜在方向**  
   - **Selective / Predictive KV Transfer in Disaggregated Systems**：SmartGen与DualDecoder共同指向“不是传全部KV，而是精准预测+重叠传输”。带宽与并发双重约束下，这可能成为下一代serving标准组件。  
   - **Token-level Dynamic Width + Kernel Co-design**：WIDE证明细粒度动态稀疏可以落地，后续可与量化、speculative decoding进一步组合。  
   - **Reusable KV State for Personalized/Memory-augmented Serving**：InferScale展示了“precompute once, inject many”的路径，对agent memory系统有直接扩展价值。
