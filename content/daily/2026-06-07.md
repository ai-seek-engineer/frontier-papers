### **Inference Optimization**
**【Title】** Tangram: Unlocking Non-Uniform KV Cache for Efficient Multi-turn LLM Serving (arXiv:2606.06302)  
- **一句话总结**：针对多轮对话中非均匀KV cache的系统性挑战（碎片、调度、kernel利用率），提出完整serving系统Tangram，实现实际部署可行性。  
- **核心贡献**：(1) Deterministic Budget Allocation（静态head预算，消除动态调度和prefill stall）；(2) Head Group Page（相似head聚类+独立vectorized page table，最大化内存回收）；(3) AOT Load Balancing（基于静态profile的均衡，无运行时开销）。  
- **工程价值**：直接针对生产多轮serving的KV cache痛点，提升throughput高达2.6x，精度无损；适用于vLLM/SGLang等框架扩展，代码公开，强可复现。  
- **是否值得读**：**强烈推荐**  
- **Relevance Score**：5/5  
- **Link**：https://arxiv.org/abs/2606.06302

**【Title】** (相关补充) 部分自speculative/quantization工作（如QuantSpec类hierarchical quantized KV），但本次新提交中Tangram系统性最强。

### **AI Infra / Distributed / System Optimization**
**【Title】** Libra: Efficient Resource Management for Agentic RL Post-Training (arXiv:2606.03077)  
- **一句话总结**：针对agentic RL rollout（长尾、非平稳、tool-invoking轨迹）的资源不对称与漂移问题，提出跨rollout-training的动态规划与调度系统。  
- **核心贡献**：(1) 周期性全局资源planner + elastic hybrid pool（轻量非阻塞reallocation）；(2) Causality-driven MLFQ调度器（基于tool-return因果信号路由，而非脆弱长度预测）。  
- **工程价值**：在48 A800 GPU上，throughput +3.0x，reward收敛 +2.5x更快；直接解决agentic RL infra瓶颈（异构workload、动态漂移），高度可落地于大规模post-training集群。  
- **是否值得读**：**强烈推荐**  
- **Relevance Score**：5/5  
- **Link**：https://arxiv.org/abs/2606.03077

### **LLM Agents / RL**
**【Title】** RREDCoT: Segment-Level Reward Redistribution for Reasoning Models (arXiv:2606.06475)  
- **一句话总结**：通过段级reward重分布改进reasoning模型的RL fine-tuning，提升长链条agentic/推理稳定性。  
- **核心贡献**：段级（而非token/whole）reward设计，缓解credit assignment在长序列中的稀疏/延迟问题；实验验证reasoning benchmark提升。  
- **工程价值**：RL post-training（尤其是agentic/多步）常用，优化reward shaping可直接集成到GRPO/RLVR pipeline；有实验支撑，但代码线索较弱。  
- **是否值得读**：**可选**（若专注RL agents）  
- **Relevance Score**：4/5  
- **Link**：https://arxiv.org/abs/2606.06475

**其他方向**（SFT/Alignment/纯RL）：PC Layer（arXiv:2606.06470，polynomial preconditioning改善pre-training稳定性，无inference overhead，代码公开）有一定infra预训练价值，但更偏训练前端，工程落地稍间接，暂不展开。
