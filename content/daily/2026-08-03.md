### 1. Model Inference / 推理优化

**【Title】** SmartGen: Seamless Disaggregated LLM Inference with Selective KV Cache Transfer  
- 一句话总结：针对 prefill/decode 分离架构的跨节点 KV 全量传输瓶颈，设计选择性 KV 传输引擎，显著降低 TTST。  
- 核心贡献：  
  1. Profile-based proactive + parallel on-demand + speculative 三条传输路径。  
  2. Prefill 阶段精准选 essential KV，decode 阶段并行拉取本地/远程。  
  3. 实测 TTST 最高 4.3× 降低，后续 decode 性能与精度基本持平。  
- 工程价值：直接可落地到自托管云实例的 disaggregated serving（带宽受限场景）；选择性传输是当前 KV 传输优化的高价值方向。  
- 是否值得读：强烈推荐  
- Relevance Score：5  
- Link：https://arxiv.org/abs/2607.28150

**【Title】** WIDE: Boosting Adaptive LLM Inference via Token-level Dynamic Width Pruning  
- 一句话总结：首个端到端可微 token-level 动态宽度剪枝框架，覆盖 prefill+decode，细粒度到 head-group/FFN-channel。  
- 核心贡献：  
  1. Token-wise 动态选择 attention-head groups 与 FFN-channel groups。  
  2. Pruning-kernel co-design（mask reordering + block-level skipping）。  
  3. 50% sparsity 下相对 SOTA dynamic depth 提升 55.1%；kernel 级加速最高 1.98×（prefill）/4.95×（decode），端到端 1.55–1.68×；有代码。  
- 工程价值：动态稀疏从粗粒度走向 token 级，且有实际 kernel 加速，适合推理引擎集成。  
- 是否值得读：强烈推荐  
- Relevance Score：5  
- Link：https://arxiv.org/abs/2607.28418

### 2. AI Infra / 分布式 / 系统优化

**【Title】** InferScale: GPU-Native KV Injection for Personalized LLM Serving  
- 一句话总结：把持久化个性化 memory 的 KV 预计算并直接注入 vLLM paged cache，彻底消除重复 prefill。  
- 核心贡献：  
  1. GPU-native 存储 memory fact 的 KV + embedding。  
  2. Chunked RoPE + Context-Window Encoding 解决位置与跨 fact 上下文问题。  
  3. 通过 vLLM KV-connector 实现，无需改引擎/微调；k=50 时 TTFT 降 72–79%（3.6–4.8×），吞吐 3.7–4.5×。  
- 工程价值：生产级 memory 系统（Mem0/MemGPT 类）的直接加速方案，TTFT 与 retrieval budget 解耦。  
- 是否值得读：强烈推荐  
- Relevance Score：5  
- Link：https://arxiv.org/abs/2607.27090

**【Title】** DualDecoder: Accelerate Long Context LLM Inference by Predictive Prefetch  
- 一句话总结：长上下文 sparse KV 从 host 拉取时，用 dual-token 预测关键性 KV 并预取，消除 GPU 辅助状态开销。  
- 核心贡献：  
  1. 前一个 speculated token 可准确预测下一 token 所需 critical KV。  
  2. Dual-token decoding pipeline + layer-aware transfer schedule + layer-scoped memory manager。  
  3. 吞吐最高 2.62×，延迟与质量保持。  
- 工程价值：长上下文 + 高并发下的 memory wall 解决方案，适合 agentic 长轨迹场景。  
- 是否值得读：强烈推荐  
- Relevance Score：4  
- Link：https://arxiv.org/abs/2607.26475

**【Title】** Queue-Theoretic Admission Control for Multi-Tenant GPU Clusters  
- 一句话总结：把多租户 GPU 集群 admission 形式化为 multi-class multi-resource 排队网络，给出 wait-time 可引用边界。  
- 核心贡献：  
  1. 结构性分解：quotable vs unfeasible workloads。  
  2. 向量打包降维得到有效 server 数 k，证明 O(1/(1-ρ)) wait 缩放。  
  3. 在 Kueue + DRA 上验证，Little’s Law 精确成立。  
- 工程价值：多租户调度从启发式走向可证明 wait-time 保证，对 GPU 集群运营有直接参考。  
- 是否值得读：可选  
- Relevance Score：3  
- Link：https://arxiv.org/abs/2607.28223

### 3. LLM Agents

**【Title】** Rethinking Inference-Time Scaling in Local Computer-Use Agents: Failure Modes and Compute Tradeoffs  
- 一句话总结：系统评估本地 CUA 在 contextual/temporal/structural/parallel 四维 inference-time scaling 的真实收益与失败模式转移。  
- 核心贡献：  
  1. 在 OSWorld 上测试多款本地模型（Qwen3-VL、UI-TARS、OpenCUA）。  
  2. 额外算力常带来 diminishing returns，失败模式从 stall/repeat 转向 premature false success。  
  3. 强调 selective compute + failure-aware control 对本地 agent 更关键。  
- 工程价值：本地部署 CUA 的实践指南，避免盲目加 compute。  
- 是否值得读：可选  
- Relevance Score：3  
- Link：https://arxiv.org/abs/2607.28573

### 4. SFT / Alignment / RLHF + RL

**【Title】** HARGO: Heterogeneity-Aware Reward-Guided Optimization for RL Post-Training of LLMs on HPC Tasks  
- 一句话总结：针对 HPC 任务（race detection / QA / generation）极端异质（长度差 58×、奖励分布差异大），提出无任务标签的 per-response 重要性加权 RL。  
- 核心贡献：  
  1. Confidence-modulated advantage（group-level discrimination + reference logprob confidence）。  
  2. 无需 task-type label 的 per-response weight。  
  3. 四任务九方法中三项主指标全最佳（WinRate 54.62%、Data Race F1 91.30%、PLP Similarity 0.8558）。  
- 工程价值：异构任务混合 RL 后训练的实用方法，尤其适合领域专属 post-training。  
- 是否值得读：可选  
- Relevance Score：3  
- Link：https://arxiv.org/abs/2607.28301

### 额外输出

**1. 今日最值得读 Top 3**  
1. **SmartGen** — 直接解决生产 disaggregated serving 的网络瓶颈，4.3× TTST 提升，方法可立即落地。  
2. **WIDE** — token-level 动态宽度剪枝 + 真实 kernel 加速，是当前动态稀疏推理的最强工程落地候选（有代码）。  
3. **InferScale** — 个性化 memory 场景的 KV 复用范式，彻底解耦 TTFT 与 retrieval size，对 memory-augmented serving 极具价值。

**2. 今日趋势观察**  
Inference 优化（尤其 KV cache 管理、选择性传输、动态稀疏、长上下文 prefetch）明显占主导。Disaggregated serving 与 personalized memory 成为高频主题；Agent 相关仍以评估/失败模式分析为主，落地系统设计相对较少；分布式训练/通信优化本窗口几乎空白。

**3. 值得跟进的潜在方向**  
- **选择性 / 预测式 KV 传输与注入**（SmartGen + InferScale + DualDecoder 共同指向）：带宽受限 + 长上下文 + 个性化 memory 的交叉点，预计会快速涌现更多系统实现。  
- **Token-level 动态稀疏的 kernel co-design**：从 layer/depth 走向更细粒度且真正可加速的方向，值得持续跟踪硬件友好实现。
