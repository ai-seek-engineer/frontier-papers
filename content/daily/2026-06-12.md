### 【Inference / KV Cache 优化】
**【Title】** INFRAMIND: Infrastructure-Aware Multi-Agent Orchestration (arXiv:2606.11440)

- **一句话总结**：将基础设施实时状态（队列、KV-cache压力、延迟）融入多Agent编排的规划、路由和调度，实现负载下的高SLO和低延迟。
- **核心贡献（2-3点）**：
  1. Infra-aware planner/executor/scheduler，基于实时负载动态调整拓扑和推理深度。
  2. 建模为分层约束MDP，用RL端到端优化质量-延迟 tradeoff。
  3. 在5个benchmark上，高负载下SLO compliance达99.9%（基线<50%），低负载准确率+7.6pp、延迟低至7x。
- **工程价值**：**高度相关**，直接针对多Agent/长上下文推理中的KV-cache和队列瓶颈，可集成到vLLM/SGLang类serving系统中，提升共享集群利用率和agentic workload throughput。动态决策有实际部署潜力。
- **是否值得读**：**强烈推荐**（系统+实验扎实）。
- **Relevance Score**：5/5
- **Link**：https://arxiv.org/abs/2606.11440

**【Title】** TileFuse: A Fused Mixed-Precision Kernel Library for Efficient Quantized LLM Inference on AMD NPUs (arXiv:2606.11357)

- **一句话总结**：为AMD XDNA2 NPU设计融合mixed-precision kernel，支持AWQ等量化格式，实现边缘LLM高效推理。
- **核心贡献（2-3点）**：
  1. 融合unpacking/dequant/GEMM/GEMV，优化weight layout和dataflow。
  2. GEMM/GEMV性能大幅提升（vs full-precision 121-281%），端到端prefill latency低至2x、能耗低64.6%。
  3. 针对NPU限制的close-to-metal实现，支持off-the-shelf量化。
- **工程价值**：**高度相关**，针对边缘/客户端推理的KV cache和量化优化，提供可移植kernel库，降低部署门槛，尤其适用于混合精度长上下文场景。
- **是否值得读**：**强烈推荐**（硬件特定但工程细节丰富，有复现潜力）。
- **Relevance Score**：4/5
- **Link**：https://arxiv.org/abs/2606.11357

### 【LLM Agents】
**【Title】** Knowing When to Ask: Self-Gated Clarification for Hierarchical Language Agents (arXiv:2606.11349)

- **一句话总结**：在分层Agent中将clarification作为action space的一部分，通过self-gated机制在中间决策点主动求助，提升导航准确性。
- **核心贡献（2-3点）**：
  1. ACTION-RATING将clarification与navigation置于同一ordinal scale，实现mandatory/opportunistic两种模式。
  2. 在Harmonized Tariff Schedule（30k节点taxonomy）上，ISE指标显著提升，准确率+16.2%。
  3. 诊断显示信息寻求与最终质量分离，支持更好localization。
- **工程价值**：**高**，适用于生产级hierarchical agents（e.g. coding/web navigation），减少错误分支，降低重试成本；易集成到现有框架中。
- **是否值得读**：**强烈推荐**。
- **Relevance Score**：4/5
- **Link**：https://arxiv.org/abs/2606.11349

**【Title】** Can AI Agents Synthesize Scientific Conclusions? (arXiv:2606.11337, SciConBench)

- **一句话总结**：引入SciConBench基准评估Agent在科学结论合成上的事实质量，暴露clean-room下低F1性能和泄漏问题。
- **核心贡献（2-3点）**：
  1. 大规模基准（9k+问题+专家结论）和自动fact分解评估。
  2. Clean-room harness防止泄漏，显示前沿Agent F1仅0.337。
  3. 审计消费级Agent，揭示不完整/矛盾输出。
- **工程价值**：**中高**，为Agent系统提供可靠评估框架，推动robust scientific agents开发；工程上强调clean evaluation pipeline。
- **是否值得读**：**可选**（benchmark为主，方法创新次之，但对Agent落地关键）。
- **Relevance Score**：3/5
- **Link**：https://arxiv.org/abs/2606.11337

### 【RL / Alignment】
**【Title】** To Intervene or Not: Guiding Inference-time Alignment with Probabilistic Model Blending (arXiv:2606.11201)

- **一句话总结**：BlendIn框架通过quality-aware probabilistic blending实现inference-time alignment，避免无效guidance导致的过度干预。
- **核心贡献（2-3点）**：
  1. 从binary干预转向hybrid分布，基于可靠性加权。
  2. 提供diagnostic和mitigation，性能提升高达50%。
  3. 在challenging model pairs上稳定优于现有方法。
- **工程价值**：**高**，低成本inference-time对齐，适用于SFT/RLHF后部署；易集成，无需重训。
- **是否值得读**：**强烈推荐**。
- **Relevance Score**：4/5
- **Link**：https://arxiv.org/abs/2606.11201

   - **INFRAMIND**：直接解决多Agent/KV压力下的infra瓶颈，RL驱动的动态优化有生产价值。
