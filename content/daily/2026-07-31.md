### 【Title】AngelSpec: Towards Real-World High Performance Inference with Speculative Decoding  
**arXiv:2607.25852**（28-29 Jul 2026）

- **一句话总结**：统一 MTP 与 block-parallel 的投机解码训练/推理框架，针对真实异构 workload 做结构-数据共特化 + 在线自适应验证。
- **核心贡献**：
  1. 训练层：按域特化 drafter（对话用 MTP，代码/数学用 block-diffusion）。
  2. 架构层：DFly 混合目标条件 backbone + 前驱条件 AR head。
  3. 推理层：把 verification 当 batch 级共享资源，在线自适应深度与分配。
- **工程价值**：直接面向高并发真实服务（Hy3 系列），吞吐提升显著（1.98-2.40× AR，相对 DFlash 再高 10%+），且释放框架，适合现有推理引擎集成。
- **是否值得读**：强烈推荐  
- **Relevance Score**：5  
- **Link**：https://arxiv.org/abs/2607.25852

### 【Title】DualDecoder: Accelerate Long Context LLM Inference by Predictive Prefetch  
**arXiv:2607.26475**（29 Jul 2026）

- **一句话总结**：通过“前一 speculative token 预测关键 KV”实现零额外 GPU 辅助状态的 sparse KV 预取，解决高并发长上下文内存墙。
- **核心贡献**：
  1. 关键洞察：下一 token 关键 KV 可从 preceding speculated token 准确预测。
  2. Dual-token decoding pipeline + layer-aware transfer schedule。
  3. Layer-scoped memory manager，消除现有 sparse 方法的 GPU 辅助状态开销。
- **工程价值**：长上下文 + agentic 场景的硬痛点；吞吐最高 2.62×，保持延迟与质量，纯系统优化，落地门槛低。
- **是否值得读**：强烈推荐  
- **Relevance Score**：5  
- **Link**：https://arxiv.org/abs/2607.26475

### 【Title】CoSA: Accelerating Long-Context Inference via Proxy-Kernel Co-Designed Sparse Attention  
**arXiv:2607.25291**（28 Jul 2026）

- **一句话总结**：训练无关的 proxy-kernel 协同设计 sparse attention，在低 budget 下同时保精度与加速。
- **核心贡献**：
  1. Kernel-Aware Proxy（KAP）生成有序 mask。
  2. Ordered-Skipping Kernel（OSK）在线 Softmax 统计下进一步跳过。
  3. 两阶段协同，避免 proxy 漏掉 salient blocks。
- **工程价值**：128K 上下文下 attention 加速 4.93×、TTFT 降 2.53×，几乎无损，适合直接替换现有 sparse kernel。
- **是否值得读**：强烈推荐  
- **Relevance Score**：5  
- **Link**：https://arxiv.org/abs/2607.25291

### 【Title】A Photonic-CXL Memory Appliance for Scalable KV Cache Management in LLM Inference  
**arXiv:2607.27187**（29 Jul 2026）

- **一句话总结**：用光子-CXL 混合架构构建无电开关全交叉连接的 32TB 共享 KV 内存池，突破现有 CXL 延迟与规模限制。
- **核心贡献**：
  1. 被动光纤 shuffle 替代电气 switch。
  2. 16-host 全交叉拓扑，仿真延迟降低 >50%。
  3. 多轮对话 TTFT 提升 6.6×，消除 eviction cliff。
- **工程价值**：硬件级 KV 扩展方案，对超大规模 inference 集群有长期参考价值（当前多为仿真/emulation，短期落地需硬件支持）。
- **是否值得读**：可选（硬件向）  
- **Relevance Score**：4  
- **Link**：https://arxiv.org/abs/2607.27187

### 【Title】Revisiting Lossy Verification in Speculative Decoding: Mechanisms, Trade-offs, and Failure Modes  
**arXiv:2607.26627**（29 Jul 2026）

- **一句话总结**：系统分析 lossy verification 的分布扭曲机制，给出分类与失败模式诊断，防止质量 silently 崩塌。
