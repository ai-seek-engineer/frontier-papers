### 【Title】Windowed-MTP: Removing the Full-Context Draft-KV Tax at Million-Token Context  
**arXiv:2607.21535**  
- **一句话总结**：对 native MTP draft head 只做 StreamingLLM 式 window + sink，彻底砍掉百万 token 下的 full-context KV 读取税。  
- **核心贡献**：  
  1. 仅对 draft 注意力做 window，verification 保持 full-attention，训练免费、分布无损。  
  2. 1M 上下文下 draft KV 工作集恒定，丢弃 ~99% 条目；端到端 decode 成本降 28–44%。  
  3. 未读 draft KV 用 ring buffer 回收（占总 KV 7.7–11%），零质量损失。  
- **工程价值**：直接可插 SGLang / vLLM 类 serving 栈，解决当前 native MTP 在长上下文下“越推越慢”的痛点，对 hybrid/linear-attention 模型尤其关键。  
- **是否值得读**：强烈推荐  
- **Relevance Score**：5  
- **Link**：https://arxiv.org/abs/2607.21535

### 【Title】Error Certificates for KV-Cache Eviction via Randomized Design  
**arXiv:2607.21475**  
- **一句话总结**：证明确定性 top-k eviction 无法给出一致误差估计，改用 Poisson 随机采样 + Hájek 校正即可在 serving 时给出可证明的 per-step 误差证书。  
- **核心贡献**：  
  1. 理论证明确定性 eviction 误差不可识别。  
  2. 随机化 + 方差估计器，经验覆盖率 0.97，几乎零精度损失。  
  3. 证书比 output confidence 更能区分 cache-induced 失败（AUC 0.73–0.75）。  
- **工程价值**：为生产 KV eviction / paging 系统提供可观测误差边界，可直接用于动态预算调整与故障归因。  
- **是否值得读**：强烈推荐  
- **Relevance Score**：4  
- **Link**：https://arxiv.org/abs/2607.21475

### 【Title】Fine-grained Computation-Communication Overlap via Tile-level Signaling and Scheduling for Mixture-of-Experts  
**arXiv:2607.19539**  
- **一句话总结**：用 tile-level 信号 + 持久化 producer-consumer kernel 实现 MoE 专家计算与 return all-to-all 的细粒度重叠。  
- **核心贡献**：  
  1. 持久计算 kernel 优先处理 remote-critical tiles；通信 kernel 占用少量 SM 做 segment 级传输。  
  2. 无需改底层算子/通信原语。  
  3. 4×A100 上最高 2.64× 端到端、2.74× MoE-layer 加速。  
- **工程价值**：直接可落地到现有 MoE serving/training 框架，显著提升多卡 MoE 利用率。  
- **是否值得读**：强烈推荐  
- **Relevance Score**：5  
- **Link**：https://arxiv.org/abs/2607.19539

### 【Title】Controlled Periodic Synchronization for Efficient Data-Parallel Training  
**arXiv:2607.21224**  
- **一句话总结**：把同步频率做成可控系统参数（CPDP），在 WAN 场景下同时提升精度与吞吐。  
- **核心贡献**：  
  1. Local update + 梯度 AllReduce + SlowMo 参数平均的混合和解步骤。  
  2. Grid’5000 跨站点（16.6 ms RTT）实测。  
  3. K=4 时相对 DDP 精度 +2.44 pp，墙钟时间 -13.8%。  
- **工程价值**：对跨机房/跨区域训练有直接实用价值，PyTorch-DDP 兼容。  
- **是否值得读**：可选

### 【Title】OpenForgeRL: Train Harness-native Agents in Any Environment  
**arXiv:2607.21557**  
- **一句话总结**：用轻量 proxy + K8s 容器编排，让任意真实 harness（Claude Code / Codex / OpenClaw 等）能端到端做 SFT/RL。  
- **核心贡献**：  
  1. 解耦训练与推理，proxy 记录 harness 调用作为训练数据。  
  2. 支持工具/GUI/computer-use 多模态 agent。  
  3. 小数据量即超同尺寸开源基线，部分任务追平更大模型。  
- **工程价值**：填补了“真实 harness 无法用现有 RL 框架训练”的关键空白，开源，可直接复用。  
- **是否值得读**：强烈推荐

### 【Title】The Dark Room in the Reward Channel: Dense Prediction Rewards Collapse GRPO-Trained LLM Agents  
**arXiv:2607.21273**  
- **一句话总结**：在 GRPO 下，稠密 prediction reward 会把 agent 推入“暗室”退化状态（预测精度→1，任务成功率→0）。  
- **核心贡献**：  
  1. 单因素消融定位根因：GRPO 的 std 归一化。  
  2. 提出 variance-profile 判据，可预测哪些 dense signal 会崩溃。  
  3. 对比显示 reward 通道最多中性，auxiliary-loss 通道可+20 分。  
- **工程价值**：对所有做 agentic RL / GRPO 的工程师是避坑必读，直接改变 reward 设计决策。  
- **是否值得读**：强烈推荐  
- **Relevance Score**：4  
- **Link**：https://arxiv.org/abs/2607.21273
