### 【Model Inference / 推理优化】
**【Title】** Towards Efficient Large Language Model Serving: A Survey on System-Aware KV Cache Optimization (arXiv:2607.08057, Jul 9)

- **一句话总结**：系统视角系统化KV cache在LLM serving中的优化，从执行调度、放置迁移、表示保留三维组织现有工作。
- **核心贡献（2-3点）**：1) 引入sKis框架，按temporal/spatial/structural维度梳理KV行为；2) 分析cross-behavior co-design和behavior-objective关联；3) 指出未来基础设施创新方向。
- **工程价值（重点分析）**：极高。直接服务于生产推理serving，KV cache是内存/吞吐瓶颈，此survey提供可落地框架（如调度+量化+eviction结合），便于工程师诊断/优化现有vLLM/SGLang等系统。
- **是否值得读**：强烈推荐
- **Relevance Score**：5
- **Link**：https://arxiv.org/abs/2607.08057

**【Title】** Think Before You Grid-Search: Floor-First Triage for LLM Serving (arXiv:2607.05876, Jul 7-8)

- **一句话总结**：提出Floor-First残差驱动工作流，通过5维资源向量（HBM/FLOPs/network/KV）建模decode step，快速triage配置而非盲目grid-search或profiler。
- **核心贡献**：1) 乐观/悲观floor估计方法；2) 模块化支持新attention/SSM变体；3) DeepSeek-V3.2-style MoE案例分析（TP vs EP布局的capacity/latency tradeoff）。
- **工程价值**：高。直接解决serving优化中的试错成本，提供零依赖计算器+agent skill，可集成到优化循环中，特别适合MoE/长上下文decode。
- **是否值得读**：强烈推荐
- **Relevance Score**：5
- **Link**：https://arxiv.org/abs/2607.05876

### 【AI Infra / 分布式训练 / 系统优化】
**【Title】** SMetric: Rethink LLM Scheduling for Serving Agents with Balanced Session-centric Scheduling (arXiv:2607.08565, Jul 9)

- **一句话总结**：针对agentic serving（高KV reuse、低per-token latency要求），提出session-turn-based SMetric调度，提升TPS并平衡负载。
- **核心贡献**：1) 真实trace分析agent workload特性（>80% KV reuse）；2) session-centric metric设计（stateless高效）；3) 10-16% TPS提升（prefill-decode colocation）和2-34% prefill TPS。
- **工程价值**：高。直接改进多agent serving infra，解决现有scheduler因KV affinity导致的负载不均，适用于生产disaggregated/preemption场景。
- **是否值得读**：强烈推荐
- **Relevance Score**：4
- **Link**：https://arxiv.org/abs/2607.08565

### 【LLM Agents / RL】
**【Title】** Single-Rollout Asynchronous Optimization for Agentic Reinforcement Learning (arXiv:2607.07508, Jul 8)

- **一句话总结**：提出SAO解决异步agentic RL中的stability/off-policy问题，支持single-rollout训练，部署于GLM-5.2 (750B-A40B)。
- **核心贡献**：1) 适应GRPO不匹配的异步设置；2) 在SWE-Bench/BeyondAIME等benchmark稳定优于GRPO；3) online learning适应性强。
- **工程价值**：高。agentic RL post-training的核心系统挑战（异步、stability），提供可部署pipeline，工程落地价值显著（大规模模型验证）。
- **是否值得读**：强烈推荐
- **Relevance Score**：4
- **Link**：https://arxiv.org/abs/2607.07508

### 1. 今日最值得读 Top 3（理由）
1. **KV Cache Survey (2607.08057)**：全面系统化当前最痛的serving瓶颈，提供可操作框架，几乎所有inference工程师必看。
2. **Floor-First Triage (2607.05876)**：实用triage方法，终结盲目grid-search，直接降低优化迭代成本，有具体MoE案例。
3. **SAO for Agentic RL (2607.07508)**：异步RL系统创新+真实大规模部署，解决agent post-training工程痛点。

### 2. 今日趋势观察
Inference serving优化（尤其是**KV cache系统设计**和**agentic scheduling**）明显增加，反映生产部署压力（高KV reuse、多session agent workload）。RL/agentic post-training也有实用异步/优化进展，但数量仍少于inference。

### 3. 是否出现“值得跟进的潜在方向”
是：**Agentic serving的session/KV-aware调度 + inference-time triage/estimation**。这些结合能显著提升高负载、多turn agent系统的TPS和效率，未来可能演变为标准serving stack组件（类似vLLM paging的演进）。同时，asynchronous single-rollout RL值得关注，作为agent scaling的系统基石。 

整体今日论文质量高，工程导向强，推荐优先实现/测试KV相关优化。
