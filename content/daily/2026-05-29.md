### 1. Model Inference / 推理优化
**【Title】** Agent Memory Below the Prompt: Persistent Q4 KV Cache for Multi-Agent LLM Inference on Edge Devices

- **一句话总结**：针对边缘设备多Agent场景，通过持久化Q4量化KV Cache + 直接Attention层reload，彻底消除eviction后的re-prefill开销。
- **核心贡献**（2-3点）：
  - Block pool + BatchQuantizedKVCache实现per-agent隔离Q4持久化，支持safetensors磁盘存取。
  - Cross-phase context injection实现无重计算的Attention状态累积；多Agent interleaving下reload latency（~500ms）被decode阶段隐藏。
  - 在Gemma3-12B、DeepSeek-Coder-V2-Lite、Llama3.1-8B上实测TTFT降低22-136x，Q4比FP16多容纳4x上下文；PPL退化可控（Gemma -0.7%，其余+2-3%）。
- **工程价值**：直接可用于边缘多Agent serving（Apple M4 Pro等），解决内存墙；OpenAI-compatible API + 开源实现（github），可集成到vLLM-mlx类框架；对长上下文/多轮Agent交互的inference throughput提升显著，尤其KV-bound场景。
- **是否值得读**：**强烈推荐**
- **Relevance Score**：5/5
- **Link**：https://arxiv.org/abs/2603.04428 (代码开源)

**【Title】** TurboQuant: Online Vector Quantization with Near-optimal Distortion Rate（近期讨论活跃，工程落地相关）

- **一句话总结**：提出在线向量量化方法，通过随机旋转+标量量化实现接近信息论最优的KV Cache压缩，支持极低比特（3.5bit near-zero loss）。
- **核心贡献**：
  - 数据无关在线算法，适用于KV Cache动态场景；MSE+inner product distortion双优化。
  - 理论证明接近下界，实验在KV Cache上3.5bit绝对中性，2.5bit轻微退化；NNS任务也优于传统PQ。
- **工程价值**：KV Cache量化核心痛点（内存/带宽）的强力工具，可与PagedAttention结合；加速器友好，适合生产inference stack，尤其长上下文或高batch场景。讨论中已有MLX/llama.cpp集成探索。
- **是否值得读**：**强烈推荐**
- **Relevance Score**：4.5/5
- **Link**：https://arxiv.org/abs/2504.19874
