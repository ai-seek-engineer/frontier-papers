### 【LLM Agents（实际落地或系统设计）】
**【Title】** Agent Memory Below the Prompt: Persistent Q4 KV Cache for Multi-Agent LLM Inference on Edge Devices (arXiv:2603.04428, Feb 2026，但近期讨论活跃且代码开源，工程相关性高)

- **一句话总结**：针对边缘设备多 Agent 场景的 KV cache 内存瓶颈，提出持久化 Q4 量化 KV cache 到磁盘，直接 reload 到 attention 层，避免重复 prefill。
- **核心贡献（2-3点）**：
  1. Block pool + BatchQuantizedKVCache + cross-phase injection，实现 per-agent isolated Q4 cache 管理，支持并发 inference。
  2. 在 Apple M4 Pro 等设备上，TTFT 降低高达 136x（4K-32K 上下文），Q4 比 FP16 多容纳 ~4x agent 上下文。
  3. 跨 Gemma/DeepSeek/Llama 架构验证，perplexity 退化可控（Gemma 近 0），并提供 OpenAI-compatible API + 开源代码。
- **工程价值**：**高**。直接解决多 Agent 切换时的 re-prefill 痛点，I/O-bound reload 隐藏在 decode 阶段，适用于边缘/低内存部署；量化 + 持久化技术可迁移到服务器端 disaggregated inference 或 agent 框架（vLLM/SGLang 扩展）。
- **是否值得读**：**强烈推荐**（尤其是做边缘/多 Agent 系统的工程师）。
- **Relevance Score**：5/5
- **Link**：https://arxiv.org/abs/2603.04428 （GitHub 开源实现可用）

**【Title】** RunAgent: Interpreting Natural-Language Plans with Constraint-Guided Execution (arXiv:2605.00798，新提交)

- **一句话总结**：提出约束引导的执行框架，让 LLM Agent 更好地解读自然语言计划并可靠执行。
- **核心贡献（2-3点）**：
  1. 约束引导机制处理计划中的模糊/冲突，减少 hallucination 执行错误。
  2. 系统设计支持 multi-agent 或长 horizon 任务。
  3. 实验验证在实际任务中的执行成功率提升。
- **工程价值**：**中高**。提升 Agent 可靠性与可落地性，可集成到现有 agent 框架（如 LangChain/AutoGen）中，减少重试 overhead；约束模块轻量，适合生产调度。
- **是否值得读**：**强烈推荐**（Agent 落地工程师）。
- **Relevance Score**：4/5
- **Link**：https://arxiv.org/abs/2605.00798

### 【Reinforcement Learning】
**【Title】** AEM: Adaptive Entropy Modulation for Multi-Turn Agentic Reinforcement Learning (arXiv:2605.00425)

- **一句话总结**：针对多轮 Agentic RL 的自适应熵调制，提升探索-利用平衡。
- **核心贡献（2-3点）**：
  1. 自适应 entropy 机制根据 turn 动态调整，避免 early collapse 或 late stagnation。
  2. 在 multi-turn agent 任务中显著提升长期性能。
  3. 与标准 PPO 等兼容，便于集成。
- **工程价值**：**中**。Agent 训练系统可直接采用，提升多轮对话/决策任务的 RL 稳定性；计算 overhead 低，适合大规模训练 infra。
- **是否值得读**：**可选**（专注 Agent RL 的团队）。
- **Relevance Score**：3/5
- **Link**：https://arxiv.org/abs/2605.00425
