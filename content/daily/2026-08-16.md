**【Title】** vToken: Token-Level Virtualization for Reclaimable KV Caches  
- 一句话总结：在PagedAttention基础上引入token级虚拟化层，解决KV eviction与block管理粒度不匹配导致的碎片，实现更高效的内存回收。  
- 核心贡献：  
  1. token-table indirection + 异步repaking，解耦逻辑token存活与物理block布局。  
  2. 保持PagedAttention kernel与CUDA Graph兼容，集成到vLLM。  
  3. 与H2O/Random/Scissorhands等eviction配合，显著降低保留block数。  
- 工程价值：直接可落地于推理serving（尤其长context + 高并发），减少KV内存占用、提升SLA吞吐量与最大并发；集成成本低（policy集成从500+行降到<50行）。适合生产KV管理升级。  
- 是否值得读：强烈推荐  
- Relevance Score：5  
- Link：https://arxiv.org/abs/2608.13263  

**【Title】** OpScale: Operator-level Provisioning and Autoscaling for LLM Serving  
- 一句话总结：将LLM serving的autoscaling粒度从整个模型下沉到operator级别，实现更细粒度的资源弹性。  
- 核心贡献：  
  1. 刻画operator异构性，暴露operator级弹性作为scaling primitive。  
  2. 完整框架覆盖profiling、provisioning、placement与runtime serving，解决细粒度带来的组合爆炸。  
  3. 生产trace评估（最多40 A100 / 24 GB200）。  
- 工程价值：云GPU集群成本与SLO权衡的核心痛点；可显著降低GPU/功耗或同等成本下提升吞吐。对大规模serving系统调度与成本优化有直接参考价值。  
- 是否值得读：强烈推荐  
- Relevance Score：5  
- Link：https://arxiv.org/abs/2608.13499  

**【Title】** TEMPO: Makespan-Aware Expert-Parallel Load Balancing Across Memory- and Compute-Bound Regimes  
- 一句话总结：针对MoE expert-parallel，提出感知memory/compute双regime的makespan-aware dispatcher，替代简单token/expert count平衡。  
- 核心贡献：  
  1. 实测发现专家时间既非纯线性于token也非纯线性于activated expert（存在HBM streaming与tile padding临界点）。  
  2. max-affine profile建模，形式化为fixed-charge makespan问题，毫秒级求解。  
  3. SGLang集成，out-of-process + in-graph kernel。  
- 工程价值：MoE serving的EP负载均衡实用改进；有code，phase diagram可预测收益区间。对DeepSeek类大MoE推理吞吐与尾延迟有明确价值。  
- 是否值得读：强烈推荐  
- Relevance Score：4.5  
- Link：https://arxiv.org/abs/2608.13057（code: https://github.com/jeshxxx/TEMPO）  

**【Title】** DARTree: Speculative Diffusion Decoding with Autoregressive Draft Trees  
- 一句话总结：训练-free speculative decoding，将AR correction head从chain扩展到tree，结合diffusion draft的并行优势。  
- 核心贡献：  
  1. fixed-width candidate tree批量扩展 + best-first pruning。  
  2. 解耦AR-head推理与heap操作。  
  3. 多benchmark、多配置下acceptance length与speedup领先。  
- 工程价值：推理加速直接可用（最高~9.7× lossless），尤其math/code/chat场景；对现有speculative pipeline有增量改进空间。  
- 是否值得读：可选（如果团队在做SD）  
- Relevance Score：4  
- Link：https://arxiv.org/abs/2608.13524  

**【Title】** RoutePack: Expert Placement and Attention-Aware Data Packing for MoE Reinforcement Learning  
- 一句话总结：MoE RL训练中同时优化expert placement与attention-aware packing，解决sequence composition与token routing的耦合瓶颈。  
- 核心贡献：  
  1. 利用rollout-time routing replay预知序列长度与layer-wise expert demand。  
  2. 层级planner：先layer-wise expert rerouting，再joint attention+expert packing。  
  3. 在Ling系列模型上吞吐提升约9–15%。  
- 工程价值：MoE + RL后训练系统优化；对大规模MoE RL pipeline的数据布局与通信有实用参考。  
- 是否值得读：可选  
- Relevance Score：4  
- Link：https://arxiv.org/abs/2608.12146  

**【Title】** Ready Cohorts: Bounding GPU Opportunity and Avoiding Host Round Trips in LLM-Agent Control  
- 一句话总结：形式化分析LLM-agent控制路径中GPU可利用的并发机会，并研究device-resident决策减少host round-trip。  
- 核心贡献：  
  1. ready-cohort边界形式化（F / P* / U / A），精确动态规划计算机会上界。  
  2. 机制研究：GPU上保留route决策 vs 返回host再dispatch。  
  3. 大规模trace + 大量配置验证正确性与加速比。  
- 工程价值：agent serving中控制面与GPU协作的系统级思考；对高并发agent系统调度与延迟有启发，但当前更偏分析+机制验证。  
- 是否值得读：可选（agent infra团队）  
- Relevance Score：3.5  
- Link：https://arxiv.org/abs/2608.12123（有code/artifacts）

**1. 今日最值得读 Top 3**  
1. **vToken**：直接打中KV cache生产痛点（eviction + PagedAttention碎片），与vLLM集成路径清晰，量化收益明确，工程落地门槛低。  
2. **OpScale**：autoscaling从“模型级”到“operator级”是serving系统演进的自然下一步，生产trace + 多卡评估扎实，对成本/SLO优化团队价值高。  
3. **TEMPO**：MoE EP负载均衡从启发式到regime-aware makespan建模，有实测临界点与code，对当前大MoE推理系统有立即可试的改进点。  

**2. 今日趋势观察**  
- **Inference / KV / Speculative** 与 **MoE系统优化** 持续高热：token-level memory management、operator/regime-aware调度、diffusion+AR hybrid SD 出现多篇。  
- **Agent control / RL rollout 系统** 有明显增加（Ready Cohorts、RoutePack等），从“算法”转向“控制面与GPU/host协作、数据packing”。  
- 纯SFT/Alignment新方法较少进入工程高优先级筛选。

**3. 值得跟进的潜在方向**  
- **Token-level / fine-grained KV virtualization + eviction 协同**：vToken这类“逻辑-物理解耦”思路可能成为PagedAttention后续标准层。  
- **Regime-aware / makespan-aware MoE dispatch**：memory-bound vs compute-bound 临界点建模可扩展到更多并行策略。  
- **Agent control path 的 device-resident 决策与cohort scheduling**：随着agent并发上升，host round-trip与GPU机会边界会成为新瓶颈。  

以上均为工程师视角筛选，优先可落地系统/推理优化。
