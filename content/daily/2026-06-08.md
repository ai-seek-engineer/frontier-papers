### Inference / 推理优化（KV cache, eviction, serving 等）
**【Title】** Vortex: Efficient and Programmable Sparse Attention Serving for AI Agents (arXiv:2606.06453)

- **一句话总结**：构建了支持快速原型和部署稀疏注意力算法的系统（Python 前端 + page-centric 后端），针对 AI Agents 长生成场景显著提升 throughput。
- **核心贡献**（2-3点）：
  - 前端语言 + 后端集成现代 serving stack，实现稀疏注意力算法的快速迭代与生产部署。
  - AI agents 自动生成/优化算法，最高达 3.46× throughput（保持 accuracy）；扩展到大模型（如 229B MiniMax）达 1.37-4.7× 提升。
  - 解决稀疏注意力在实际 serving 中的工程落地难题。
- **工程价值**：高度实用，直接提升推理 serving 效率，尤其适合 agent 长上下文/动态生成场景；与现有 vLLM 等 stack 集成潜力大，可用于生产优化。
- **是否值得读**：**强烈推荐**（系统 + 性能数据 + agent 场景）。
- **Relevance Score**：5/5
- **Link**：https://arxiv.org/abs/2606.06453

**【Title】** Tangram: Unlocking Non-Uniform KV Cache for Efficient Multi-turn LLM Serving (arXiv:2606.06302)

- **一句话总结**：针对 multi-turn serving 中 non-uniform KV cache 的系统挑战，提出预算分配、head group paging 和 AOT 负载均衡等技术，实现高效内存/throughput 优化。
- **核心贡献**（2-3点）：
  - Deterministic Budget Allocation 消除动态调度开销；Head Group Page 处理异质性；AOT Load Balancing 确保 GPU 利用率。
  - 最高 2.6× throughput 提升，同时完全保持模型 accuracy。
  - 公开实现，支持实际 multi-turn 部署。
- **工程价值**：直接解决 multi-turn 服务中 KV 异质性导致的碎片/调度/内核利用问题，适用于生产 inference serving 系统优化。
- **是否值得读**：**强烈推荐**（系统级解决方案 + 量化收益）。
- **Relevance Score**：5/5
- **Link**：https://arxiv.org/abs/2606.06302

**【Title】** MomentKV: Closing the Directional Gap in KV Cache Eviction for Long-Context Inference (arXiv:2606.01563)

- **一句话总结**：分析现有 eviction 的方向性失配问题（evicted tokens 与 retained 正交），提出维护 evicted token 的 moment statistics（mean/covariance 等），实现选择性 eviction + 闭式近似修正。
- **核心贡献**（2-3点）：
  - 引入 moment statistics 保持 evicted set 几何正则性，并用于 inference 时的一阶注意力近似。
  - 在 LongBench/RULER 等基准上，全 cache budget 下优于 baselines，尤其 aggressive compression 时增益显著。
- **工程价值**：适用于长上下文推理的 KV 内存压缩，降低内存压力同时控制 quality 下降；易集成到现有 serving pipeline。
- **是否值得读**：**强烈推荐**（创新分析 + 实验强）。
- **Relevance Score**：4.5/5
- **Link**：https://arxiv.org/abs/2606.01563

**【Title】** Value-Aware Stochastic KV Cache Eviction for Reasoning Models (arXiv:2606.03928)

- **一句话总结**：针对 reasoning models 长 CoT 输出，提出保护大 magnitude value states + 随机 eviction 的 VaSE 方法，提升压缩下 accuracy。
- **核心贡献**（2-3点）：
  - 识别大 value states 导致循环失效的问题，并通过 stochasticity 提升 cache 多样性。
  - 4× 压缩下，在多个 reasoning 任务上优于 SOTA selection 方法和 eviction baselines（+4%+）。
  - 支持 FlashAttention2，静态内存 footprint。
- **工程价值**：直接适用于 reasoning 模型的 inference 优化，训练-free，代码公开；解决长输出内存瓶颈。
- **是否值得读**：**强烈推荐**。
- **Relevance Score**：4.5/5
- **Link**：https://arxiv.org/abs/2606.03928 （代码可用）

### LLM Agents（系统设计/落地）
**【Title】** Leyline: KV Cache Directives for Agentic Inference (arXiv:2606.01065)

- **一句话总结**：针对 agentic workloads 的动态 KV 编辑（retry、pivot 等），提出 declarative directives（splice/trim 等），支持 policy-driven cache 操作而无需全 re-prefill。
- **核心贡献**（2-3点）：
  - 4-tuple directive + architecture-agnostic 接口 + RoPE 修正 kernel，实现位置正确性维护。
  - Replay cache-hit +11.2pp，latency 降低至 241ms；agent solve rate +14.3pp。
- **工程价值**：填补 agent serving 中 KV 动态管理空白，显著降低 agent 多轮/纠错开销；适用于生产 agent 系统。
- **是否值得读**：**强烈推荐**（系统 primitive + agent 场景）。
- **Relevance Score**：5/5
- **Link**：https://arxiv.org/abs/2606.01065
