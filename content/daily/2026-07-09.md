### 1. DepthWeave-KV: Token-Adaptive Cross-Layer Residual Factorization for Long-Context KV Cache Compression
- **一句话总结**：通过token自适应跨层残差因子化（共享低秩基+token-specific残差），实现长上下文KV cache高效压缩，支持在线自适应而无需重训。
- **核心贡献**（2-3点）：
  - Token-conditional depth router + calibration-free attention-output probe，实现动态rank分配（优先保护instruction/retrieval-critical tokens）。
  - Fused CUDA kernel（basis lookup + dequant + attention projection），显著降低decode内存流量。
  - LongBench/Needle/L-Eval等基准上，近full-cache质量下达8.3x KV内存压缩 + 72.8 tok/s（64K上下文）。
- **工程价值**：直接适用于生产长上下文推理serving，降低HBM压力，可与现有intra-layer压缩组合；fused kernel提供可落地的性能提升。
- **是否值得读**：**强烈推荐**（工程细节丰富）。
- **Relevance Score**：5/5
- **Link**：https://arxiv.org/abs/2607.06523

### 2. FreqDepthKV: Frequency-Guided Depth Sharing for Robust KV Cache Compression in Long-Context LLM Inference
- **一句话总结**：频率引导的相邻层KV共享（低频共享组件+高频残差），结合在线probe适应prompt结构，实现鲁棒长上下文压缩。
- **核心贡献**（2-3点）：
  - 轻量probe按attention head贡献分配shared/residual/exact模式，无需重训。
  - 32K prefill下，多基准接近full KV性能（e.g., 58.3 EM, 70.4 tok/s），3.9x有效压缩 + 显著TTFT降低。
  - 适应prompt结构，减少检索/多步推理退化。
- **工程价值**：inference优化首选，内存/带宽节省明显，可集成到vLLM/SGLang等serving框架；在线适应性强，适合变长/动态负载。
- **是否值得读**：**强烈推荐**。
- **Relevance Score**：5/5
- **Link**：https://arxiv.org/abs/2607.06519

### 3. Doomed from the Start: Early Abort of LLM Agent Episodes via a Recall-Controlled Probe Cascade
- **一句话总结**：利用hidden states早期probe预测agent trajectory失败，构建recall-controlled多轮abort cascade，大幅节省多步agent推理compute。
- **核心贡献**（2-3点）：
  - 首轮内部表示即可高置信预测失败，优于behavior-only scorer。
  - 分布无关calibrated gates + 全局recall搜索，保证成功episode存活率（90-97% target下节省37-47% compute）。
  - 样例复杂度分析支持实际部署certification；code即将开源。
- **工程价值**：LLM agent落地关键优化，减少浪费inference budget，尤其长horizon/tool-use场景；probe轻量，易集成到agent框架。
- **是否值得读**：**强烈推荐**（系统+实验扎实）。
- **Relevance Score**：4.5/5
- **Link**：https://arxiv.org/abs/2607.06503

### 4. Think Before You Grid-Search: Floor-First Triage for LLM Serving
- **一句话总结**：提出“Floor-First”残差驱动triage workflow，用资源向量（HBM/FLOPs/net/KV）建模decode步骤，提供optimistic/pessimistic floor，指导配置选择而非盲目grid-search。
- **核心贡献**（2-3点）：
  - 资源wall ordering分析（而非点benchmark），解释同硬件不同parallelism选择。
  - DeepSeek-V3.2-style 671B MoE案例：TP vs EP+DP权衡、KV capacity wall量化。
  - 零依赖计算器 + agent skill，支持compositional新attention/SSM变体。
- **工程价值**：AI infra/servings优化核心方法论，加速配置探索，减少profiler开销；直接指导分布式部署决策。
