### 1. Model Inference / 推理优化

**【Title】** FlashQuant: Sparse-Dense Fusion for Memory-Efficient Outlier-Aware LLM Inference  
- **一句话总结**：把 outlier-aware W4A16 的 dense GEMM + sparse SpMM 融合成单 kernel，减少解码阶段冗余显存访问。  
- **核心贡献**：  
  1. Sparse-dense tiling + Tile-COO 编码，实现 activation/output 的 on-chip 复用。  
  2. Pipelined scheduling 重叠计算与数据搬运。  
  3. 在 memory-bound 解码场景下显著降低 outlier 处理开销。  
- **工程价值**：直接可插到现有 outlier-aware 量化栈（W4A16 解码）； quant 推理路径的 kernel 融合是当前生产部署的高 ROI 点，尤其 batch=1 / 长上下文。实测相对 cuBLAS BF16 有 2.74–4.18×，相对未融合 baseline 最高 1.53×。  
- **是否值得读**：强烈推荐  
- **Relevance Score**：5  
- **Link**：https://arxiv.org/abs/2608.15531  

**【Title】** Pallas: A Proactive KV Cache Migration Framework for LLM Inference in AI-RAN  
- **一句话总结**：在蜂窝 handover 场景下，主动在预测目标 gNB 预构建 KV cache（prefix prefill + suffix stream），大幅降低服务中断时间。  
- **核心贡献**：  
  1. 将序列拆成稳定 prefix（目标本地 prefill）与演化 suffix（源侧 stream KV blocks）。  
  2. Online scheduler 根据移动性预测与 telemetry 选择 prefetch window。  
  3. vLLM 原型实现，覆盖 100–500 Mbps 链路。  
- **工程价值**：边缘/RAN 推理与移动场景的 KV 状态迁移是新兴瓶颈；思路可迁移到任何 stateful 迁移（prefill-decode disaggregation、多节点 serving）。SIT 降低 2.28–89.68×，ITL 改善 16–50%。  
- **是否值得读**：强烈推荐（若做边缘/多节点 serving）  
- **Relevance Score**：4  
- **Link**：https://arxiv.org/abs/2608.16477

### 2. AI Infra / 分布式训练 / 系统优化

**【Title】** P-PAS: Prefill-Pressure Adaptive Scheduling for Long-Context LLM Serving  
- **一句话总结**：动态调整 vLLM 的 max batched tokens（MBT），根据 prefill/decode 压力自适应调度，解决长上下文下固定 token budget 的延迟波动。  
- **核心贡献**：  
  1. 发现 MBT 对延迟的影响是调度压力依赖的（低压力大 budget 好，高压力小 budget 更好）。  
  2. 轻量策略实时观察 concurrent prefill/decode 状态并约束 prefill work。  
  3. Kernel-level 解释：大 chunk 在低压力下更高效，高压力时干扰 decode。  
- **工程价值**：直接针对 vLLM 生产路径的调度参数；RAG / agent 长 prompt 短输出场景的端到端延迟优化，无需改模型。代码与 artifacts 已公开。  
- **是否值得读**：强烈推荐  
- **Relevance Score**：5  
- **Link**：https://arxiv.org/abs/2608.15171  

**【Title】** KV-Pipe: On the Relation Between KV Sharing and Pipeline Parallel Efficiency in LLMs  
- **一句话总结**：把 cross-layer KV sharing 作为 pipeline 并行的负载均衡控制旋钮（tail-first 转换 + FLOPs Imbalance Ratio 驱动），同时惠及训练与长上下文推理。  
- **核心贡献**：  
  1. Offline 阶段感知的 KV-sharing 策略，将 FIR 推向 1。  
  2. 几乎零 runtime overhead，仅需 partition + 层 FLOPs 估计。  
  3. 训练 MFU 最高 +9.2%，iteration time 最高 -9.8%；推理侧同时降低 KV 增长。  
- **工程价值**：把 inference 常用的 KV-sharing 反哺到 PP 训练，系统-架构联合优化点清晰；适合已经做 PP 的大模型训练团队。  
- **是否值得读**：可选（若正在调 PP）  
- **Relevance Score**：4  
- **Link**：https://arxiv.org/abs/2608.15943

### 3. LLM Agents（系统设计）

**【Title】** Belayer: Efficient Fault Tolerance for LLM Agentic RL Training  
- **一句话总结**：针对 agentic RL（GPU rollout + stateful sandbox 环境）的高效容错系统，同时处理 worker 失败与环境状态不一致。  
- **核心贡献**：  
  1. Shadow worker + selective GPU-state reuse（保留权重与 KV-arena，重建 request-specific KV）。  
  2. 环境 full checkpoint/restore（文件系统 + runtime），并与 LLM context 协调保持 prefix 一致性。  
  3. Adaptive policy 在推理 bubble 中重叠 checkpoint。  
- **工程价值**：Agentic RL 训练的生产痛点（长轨迹、side-effect、状态一致性）；故障恢复速度提升显著（worker 最高 42×，环境 1.5–3.5×），失败-free 开销低。直接相关于当前 agent 训练基建。  
- **是否值得读**：强烈推荐  
- **Relevance Score**：5  
- **Link**：https://arxiv.org/abs/2608.14635
