### 【Title】Unified Static-Dynamic Pruning for Efficient LLM Inference (SPDP)
- **一句话总结**：统一静态剪枝 + 输入自适应动态剪枝，并配套新稀疏格式与GPU kernel，显著提升LLM推理吞吐。
- **核心贡献**：
  1. 提出Tiled-CBC稀疏格式 + Hybrid Activation-aware动态共享内存解码kernel，解决静态/动态稀疏并存时的不规则访问问题。
  2. 同时覆盖prefill（Tensor-Core SpMM）与decode（CUDA-core spMspV）两阶段。
  3. 在推理优化GPU上达到1.24–1.37×平均加速（峰值2.51×），同时允许更高稀疏度且perplexity几乎无损。
- **工程价值**：直接可落地的推理引擎优化（格式+kernel co-design），对vLLM/SGLang类serving系统有明确参考价值；有开源代码。
- **是否值得读**：强烈推荐
- **Relevance Score**：5
- **Link**：https://arxiv.org/abs/2607.21985

### 【Title】A JoLT for the KV Cache: Near-Lossless KV Cache Compression via Joint Tucker and JL-Residual Allocation
- **一句话总结**：把KV cache视为三阶张量，用部分Tucker分解 + 旋转低比特残差实现近无损2–3×压缩。
- **核心贡献**：
  1. 只压缩token与feature轴，保留head/layer轴，再用Lagrangian统一分配rank与残差bit-width。
  2. 在Mistral-7B与LLaMA-2-13B上实现近无损（相对Frobenius误差≈0.006–0.009），GSM8K与needle-in-haystack基本保持基线。
  3. FlashJoLT变体加速压缩本身5–13×。
- **工程价值**：直接针对长上下文推理内存瓶颈，可插入现有serving系统的KV管理层；比单纯量化/低秩更精细。
- **是否值得读**：强烈推荐
- **Relevance Score**：5
- **Link**：https://arxiv.org/abs/2607.12550

### 【Title】Molt: A Scalable PyTorch-Native Training Framework for Agentic Reinforcement Learning
- **一句话总结**：面向Agentic RL的轻量、可端到端修改的PyTorch原生训练框架，性能对标Megatron级系统。
- **核心贡献**：
  1. 代码极简，算法流可完整追踪，便于研究者与AI coding助手快速迭代新estimator/pipeline。
  2. 异步训练循环保证“只训练自己生成的token”，支持多模态与MoE。
  3. 匹配全异步协议下与SOTA Megatron栈统计可比，并开源recipes与container。
- **工程价值**：Agent训练infra痛点（glue层过重）的直接解法，降低从算法到分布式落地的摩擦。
- **是否值得读**：强烈推荐

### 【Title】TileSight: A First-Principles Tile-Centric Analytical GPU Performance Model from Cores to Clusters
- **一句话总结**：以tile为统一抽象的一阶解析GPU性能模型，覆盖单核到多GPU通信。
- **核心贡献**：
  1. 统一建模compute-memory pipeline overlap、多级cache命中率、跨设备通信。
  2. 在A100/H200/B200上单卡kernel预测MAPE 12.35%，32卡分布式与vLLM端到端wMAPE≈13–16%。

- **工程价值**：kernel与分布式推理优化的“白盒”分析工具，比黑盒profiler或粗粒度roofline更可操作；计划开源。
- **是否值得读**：强烈推荐
- **Relevance Score**：4
- **Link**：https://arxiv.org/abs/2607.22432

### 【Title】TRACE-ROUTER: Task-Consistent and Adaptive Online Routing for Agentic AI
- **一句话总结**：把路由决策从“每次LLM调用”提升到“整个任务”，用延迟任务级奖励做contextual bandit。
- **核心贡献**：
  1. 任务admission时一次性选模型并pin后续所有调用，避免per-call路由的信用分配问题。
  2. 联合优化准确率与延迟，。
  3. 在agentic benchmark上显著改善Pareto前沿（tau2-Bench +7–8点，Terminal-Bench +7.1点且延迟降36%）。
- **工程价值**：企业多模型路由的实用系统设计，直接降低agent成本同时保质量。
- **是否值得读**：强烈推荐
- **Relevance Score**：5
- **Link**：https://arxiv.org/abs/2607.22465

### 【Title】The Regression Tax: Decomposing Why Skills Help and Hurt LLM Agents
- **一句话总结**：系统性量化“给agent加skill”带来的回归（原本能做的任务变坏），并拆解三种失败模式。
- **核心贡献**：
  1. 近6000次运行对比，证明最好的skill主要靠“少回归”而非“多增益”。
  2. 识别三类回归机制：skill描述渗透、grounding位移、verification位移。
  3. 发现现有skill过度强调procedure，却忽视真正导致失败的grounding与verification。
- **工程价值**：对agent系统设计与skill库工程有直接指导意义——评估必须分解gain/regression，而不是只看平均成功率。
- **是否值得读**：强烈推荐
- **Relevance Score**：4
- **Link**：https://arxiv.org/abs/2607.22520

### 2. 今日趋势观察
- **Inference优化（尤其KV cache与稀疏）** 明显活跃，多篇工作从“单纯压缩”走向“格式+kernel+调度”的系统共设计。
- **Agent系统与技能管理** 持续高产，重点从“能不能做”转向“如何可靠、可路由、可评估回归”。
- **分布式训练通信与调度** 有少量高质量工作，但整体热度低于推理与agent。

- **Task-level / workflow-level 资源管理**（路由、调度、KV管理都开始从per-request走向per-task/per-trajectory），预计会成为下一代agent serving的核心抽象。
