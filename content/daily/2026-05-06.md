### 【Title】SpecKV: Adaptive Speculative Decoding with Compression-Aware Gamma Selection
- **一句话总结**：针对量化/压缩模型的自适应 speculative decoding，通过 draft 模型信号动态调整 speculation length γ，实现 tokens-per-step 最大化。
- **核心贡献**（2-3点）：
  1. 构建大规模 profiling 数据集（4任务类 × 4γ × 3压缩级别，5112 步记录），揭示最优 γ 随压缩级别（FP16/INT8/NF4）显著变化。
  2. 轻量 MLP 控制器（draft entropy/confidence 输入），每步决策开销 <0.5% step time，tokens 提升 56%（统计显著）。
  3. 开源代码、数据、notebook。
- **工程价值**：**极高**。直接适用于生产推理服务，尤其量化部署场景（KV cache 压缩常见）。可无缝集成 vLLM/HF 等框架，提升 throughput，无需重训。压缩感知是实际痛点解决。
- **是否值得读**：**强烈推荐**。
- **Relevance Score**：5/5。
- **Link**：https://arxiv.org/abs/2605.02888 (代码：GitHub Amorfati123/SpecKV)。

### 【Title】WindowQuant: Mixed-Precision KV Cache Quantization based on Window-Level Similarity for VLMs Inference Optimization
- **一句话总结**：针对 VLM 长视觉 token 序列的 window-level 混合精度 KV cache 量化，通过相似性搜索 + 重排序实现精度保持与硬件高效推理。
- **核心贡献**（2-3点）：
  1. Window-level（而非 token-level）量化搜索，快速确定 bit-width 配置，降低搜索开销。
  2. 重排序机制避免混合精度计算的硬件低效。
  3. 多数据集/模型实验优于 SOTA KV 量化方法。
- **工程价值**：**高**（VLM 专用）。VLM inference 内存/延迟瓶颈突出，此方法直接降低 KV cache 占用并加速 decode，适合多模态生产部署。window 重排序对 GPU kernel 友好。
- **是否值得读**：**强烈推荐**（VLM 团队必看）。
- **Relevance Score**：5/5。
- **Link**：https://arxiv.org/abs/2605.02262。

### 【Title】Taming Request Imbalance: SLO-Aware Scheduling for Disaggregated LLM Inference (Kairos)
- **一句话总结**：针对 disaggregated（prefill/decode 分离）serving 中的请求长尾与 imbalance，提出 urgency-based prefill 优先调度 + slack-guided decode 自适应 batching，提升 SLO 达成率和 throughput。
- **核心贡献**（2-3点）：
  1. Prefill 侧：预测完成时间，动态 urgency 优先，最大化 TTFT SLO。
  2. Decode 侧：利用 TPOT slack 贪心 pack 短请求，提升 batch 效率。
  3. 真实 serving 数据集 + SOTA LLM 实验：TTFT/TPOT/end-to-end SLO 提升显著（最高 23.9%/27.1%/33.8%），decode throughput +19.3%。
- **工程价值**：**极高**。生产 LLM serving 核心痛点（长尾请求、SLO 冲突），直接可用于 disagg 架构优化（如 vLLM/SGLang 扩展）。无重训，开箱即用系统优化。
- **是否值得读**：**强烈推荐**。
- **Relevance Score**：5/5。
- **Link**：https://arxiv.org/abs/2605.02329。
