### Model Inference / 推理优化

**【Title】** KVEraser: Learning to Steer KV Cache for Efficient Localized Context Erasing (arXiv:2606.17034, ~2026-06-15)

- **一句话总结**：提出可学习的 KV cache 编辑方法，实现对特定上下文 span 的高效局部擦除，支持 agentic 场景下的动态上下文管理。
- **核心贡献**（2-3点）：
  1. 学习引导的 KV steering 机制，精确针对性擦除而非全局 eviction。
  2. 显著降低 memory footprint 和 inference latency，同时保持生成质量。
  3. 适用于 agent 工作流中频繁的上下文编辑（如失败重试、trajectory pivot）。
- **工程价值**：直接解决 agentic inference 中 KV cache 管理痛点（传统 prefix caching 不支持编辑），可集成到 vLLM/SGLang 等 serving 系统，提升长上下文/多轮 agent 效率，降低 GPU memory 压力。
- **是否值得读**：**强烈推荐**（系统优化强，实用）。
- **Relevance Score**：5/5
- **Link**：https://arxiv.org/abs/2606.17034

**【Title】** RKSC: Reasoning-Aware KV Cache Sharing and Confident Early Exit for Multi-Step LLM Inference (arXiv:2606.09937)

- **一句话总结**：训练-free 多分支推理优化，通过 attention-similarity 共享 KV prefix + confidence-gated early exit，大幅加速 multi-step 生成。
- **核心贡献**（2-3点）：
  1. ASKS 机制基于 hidden-state 相似性广播 prefix KV，泛化 token-exact caching。
  2. CGEE 结合 confidence 和 per-layer entropy 实现 early exit。
  3. 实验覆盖多模型/基准，mean 3x+ speedup，error 极低，有代码。
- **工程价值**：推理 serving 直接可用，提升 reasoning/agent multi-branch 吞吐，无需 retrain，易部署。
- **是否值得读**：**强烈推荐**。
- **Relevance Score**：5/5
- **Link**：https://arxiv.org/abs/2606.09937

**【Title】** Can I Buy Your KV Cache? (arXiv:2606.13361)

- **一句话总结**：提出预计算 + 商用 KV cache 共享机制，解决 agent 重复 prefill 浪费，经济模型清晰。
- **核心贡献**（2-3点）：
  1. Token-exact KV reuse，compute 节省 9-50x。
  2. 分析 provider-side hosting 的经济可行性（egress vs compute）。
  3. 量化大规模场景节省（百万美元级）。
- **工程价值**：agent-heavy 部署的潜在 infra 创新，类似 prompt caching 的下一阶，可构建 prefill CDN，降低大规模 agent 成本。
- **是否值得读**：**强烈推荐**（idea 新颖，工程思考深入）。
- **Relevance Score**：4.5/5
- **Link**：https://arxiv.org/abs/2606.13361

### LLM Agents（系统设计/落地）

**【Title】** GIST-CMTF: Goal-State Inference for Causal Minimal Tool Filtering in LLM Agents (arXiv:2606.16813, 2026-06-15)

- **一句话总结**：在 causal tool filtering 基础上增加 goal-state inference 层，减少 wrong-goal 执行，提升 tool-use 可靠性。
- **核心贡献**（2-3点）：
  1. Goal ambiguity 检测 + clarification 作为 causal action。
  2. 多 backend/任务实验：success 97% vs baseline ~80%，wrong-goal 大幅下降。
  3. 保持 minimal tool exposure，token 高效。
- **工程价值**：直接提升 production LLM agent 工具调用准确性和效率，减少 hallucinated/无效 tool calls，可集成到现有 agent 框架。
- **是否值得读**：**强烈推荐**。
- **Relevance Score**：4.5/5
- **Link**：https://arxiv.org/abs/2606.16813

2. **今日趋势观察**：**Inference 优化（尤其是 KV cache 管理）** 热度明显，多个工作针对 agentic workload 的动态性（编辑、共享、多分支），反映 agent 部署规模化后的系统瓶颈凸显。Agents 方向偏向 tool filtering/goal inference 的可靠性提升，而非纯 scaling。

3. **值得跟进的潜在方向**：**Agent-native KV cache 管理与经济模型**（预计算、共享、编辑一体化）。随着 agent 部署增多，prefill 重复和 context 动态编辑将成为主要成本/延迟来源，结合 provider-side hosting 或 CDN-like 机制可能催生新 infra 范式。
