### 1. Inference / 推理优化
**【Title】** RTP-LLM: High-Performance Alibaba LLM Inference Engine

- **一句话总结**：阿里巴巴生产级LLM推理引擎，支持Prefill-Decode解耦、层次化KV cache、多算法speculative decoding和自适应量化。
- **核心贡献**：1) Prefill-Decode解耦 + 多层KV cache管理，实现高cache重用；2) 模块化speculative decoding与量化支持；3) 生产流量下显著优于vLLM/SGLang。
- **工程价值**：直接可用于生产推理部署，TTFT降低35-37%、吞吐提升1.12-2.52x，支持多模态与量化，代码开源，极高落地价值。
- **是否值得读**：**强烈推荐**
- **Relevance Score**：5
- **Link**：https://arxiv.org/abs/2605.29639

**【Title】** EvoSpec: Evolving Speculative Decoding via Real-Time Vocabulary and Parameter Adaptation

- **一句话总结**：针对领域/话题漂移场景下speculative decoding接受率下降的问题，通过实时词汇和参数自适应演化draft模型。
- **核心贡献**：动态词汇剪枝 + 参数适应机制，缓解静态方法在分布偏移下的性能退化。
- **工程价值**：提升speculative decoding在实际变分布服务中的鲁棒性与加速比，适合在线推理场景。
- **是否值得读**：**强烈推荐**
- **Relevance Score**：5
- **Link**：https://arxiv.org/abs/2605.27390

**【Title】** Domino: Decoupling Causal Modeling from Autoregressive Drafting in Speculative Decoding

- **一句话总结**：将因果依赖建模从昂贵的自回归draft执行中解耦，实现并行draft同时保留因果信息。
- **核心贡献**：轻量correction branch + 并行draft框架，在保持高质量draft的同时大幅降低draft阶段开销。
- **工程价值**：直接优化speculative decoding的bottleneck，提升整体加速比，有代码线索。
- **是否值得读**：**强烈推荐**
- **Relevance Score**：4.5
- **Link**：https://arxiv.org/abs/2605.29707

### 2. AI Infra / 分布式训练 / 系统优化
**【Title】** DistFlow: A Fully Distributed RL Framework for Scalable and Efficient LLM Post-Training

- **一句话总结**：全分布式RL框架，采用multi-controller消除中心节点，实现近线性扩展至数千GPU。
- **核心贡献**：数据传输与执行任务全分发到worker，灵活execution flow，吞吐提升最高7x。
- **工程价值**：解决大规模RL post-training的scaling bottleneck，直接提升分布式训练效率，代码开源。
- **是否值得读**：**强烈推荐**
- **Relevance Score**：5
- **Link**：https://arxiv.org/abs/2507.13833 (最新版本)
