### Inference / KV Cache / Serving 优化

**【Title】** Tangram: Unlocking Non-Uniform KV Cache for Efficient Multi-turn LLM Serving (arXiv:2606.06302)  
- **一句话总结**：针对多轮对话中 heads 重要性差异大的问题，提出系统级非均匀 KV cache 管理框架，消除动态调度开销。  
- **核心贡献**：(1) Deterministic Budget Allocation（静态 per-head 预算，无 prefill stall）；(2) Head Group Page + 独立 vectorized page tables 最大化内存回收；(3) AOT Load Balancing 保证 GPU 利用率。  
- **工程价值**：直接用于生产多轮 serving，提升 throughput 和 memory efficiency，尤其适合 agentic/multi-turn workloads；非均匀压缩实用化，无需 retraining。  
- **是否值得读**：**强烈推荐**（系统实现细节丰富）。  
- **Relevance Score**：5/5  
- **Link**：https://arxiv.org/abs/2606.06302

**【Title】** RedKnot: Efficient Long-Context LLM Serving with Head-Aware KV Reuse and SegPagedAttention (arXiv:2606.06256)  
- **一句话总结**：将 KV cache 按 heads 分解为结构化对象，支持位置无关复用、prefix 压缩、hot/cold 分离等。  
- **核心贡献**：Head-level decomposition + SegPagedAttention；统一支持多种 KV 优化场景，保留输出 fidelity。  
- **工程价值**：长上下文 serving 和 agent 场景的核心 infra 优化，显著降低内存/带宽压力，可直接集成到 serving 系统（如 vLLM 扩展）。  
- **是否值得读**：**强烈推荐**。  
- **Relevance Score**：5/5  
- **Link**：https://arxiv.org/abs/2606.06256

**【Title】** Vortex: Efficient and Programmable Sparse Attention Serving for AI Agents (arXiv:2606.06453)  
- **一句话总结**：为 AI Agents 设计可编程 sparse attention serving 系统，桥接理论稀疏算法与实际部署。  
- **核心贡献**：高效原型/部署/评估 pipeline，支持快速迭代 sparse attention 变体。  
- **工程价值**：直接加速 agent 长序列 inference，降低 attention 计算成本，适合生产 agent 系统。  
- **是否值得读**：**强烈推荐**（工程落地导向）。  
- **Relevance Score**：4.5/5  
- **Link**：https://arxiv.org/abs/2606.06453

### LLM Agents

**【Title】** What Should Agents Say? Action-state Communication for Efficient Multi-Agent Systems (arXiv:2606.05304)  
- **一句话总结**：提出 PACT 协议，将 agent 间自由形式通信压缩为紧凑 action-state record，显著降低 token 开销。  
- **核心贡献**：分析多种通信策略；PACT 在不同 MAS topology 上提升 performance-cost trade-off；在 OpenHands/SWE-agent 等生产 harness 上验证（resolve rate 提升或持平，tokens 大幅减少）。代码开源。  
- **工程价值**：直接优化 multi-agent 系统 inference 成本和上下文管理，落地价值高（生产 coding agents）。  
- **是否值得读**：**强烈推荐**。  
- **Relevance Score**：5/5  
- **Link**：https://arxiv.org/abs/2606.05304

**【Title】** SentinelBench: A Benchmark for Long-Running Monitoring Agents (arXiv:2606.05342)  
- **一句话总结**：引入长时监控 agent 基准，评估 sustained attention 而非 continuous action 的能力。  
- **核心贡献**：100 tasks 跨 10 个动态 web 环境；度量 completion、reaction time、resource use；多模型/ harness 基线。  
- **工程价值**：为 long-horizon agent 系统设计和优化提供可靠评测框架，尤其适用于真实监控/等待型 workloads。  
- **是否值得读**：**强烈推荐**（工程评测导向）。  
- **Relevance Score**：4/5  
- **Link**：https://arxiv.org/abs/2606.05342

### 1. 今日最值得读 Top 3
1. **Tangram / RedKnot**（并列）：KV cache 是当前 inference 最大瓶颈，这两篇提供实用系统方案（非均匀 + head-aware），可立即提升 serving 效率，实验支撑强。  
2. **PACT (What Should Agents Say?)**：multi-agent token 爆炸的直接解法，生产 harness 验证 + 开源代码，工程落地最快。  
理由：均有清晰系统创新、benchmark/生产数据支撑，且直接映射到优先方向。

### 2. 今日趋势观察
Inference serving / KV cache 优化明显增加（多篇 head-aware、非均匀、sparse attention），反映 long-context + multi-turn/agent workloads 的生产压力持续上升。Agents 方向聚焦 communication efficiency 和 long-running monitoring，实用系统设计增多。

### 3. 值得跟进的潜在方向
**Head-level / non-uniform KV management** 成为 infra 新范式：从 monolithic KV 转向结构化、可编程对象，能统一解决 reuse、compression、distribution 等问题。建议工程师关注后续 kernel 集成和与 PagedAttention/vLLM 的结合，可能在 2026 下半年成为主流 serving 优化路径。
