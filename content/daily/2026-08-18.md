### 【Title】vToken: Token-Level Virtualization for Reclaimable KV Caches  
**arXiv:2608.13263**（约 Aug 13）

- **一句话总结**：在 PagedAttention 之上加轻量 token 级虚拟化层，解决 eviction 算法与 block 粒度不匹配导致的碎片问题，让 KV 内存真正可回收。
- **核心贡献**：
  1. 通过 token-table indirection 解耦逻辑 token 存活与物理 block 放置，异步 repacking 实现物理回收。
  2. 保持 PagedAttention kernel 与 CUDA Graph 兼容，集成成本极低（策略集成从 500+ 行降到 <50 行）。
  3. 实测减少 retained KV blocks 27–72%，SLA 约束吞吐最高 +1.37×，并发能力最高翻倍。
- **工程价值**：直接可插 vLLM，解决实际 serving 中 eviction 后内存无法有效释放的痛点，对长上下文 + 动态 eviction 场景立即可用。
- **是否值得读**：强烈推荐  
- **Relevance Score**：5  
- **Link**：https://arxiv.org/abs/2608.13263

### 【Title】DeaMoE: Efficient MoE Structure for Fast Small-Batch Decoding  
**arXiv:2608.14385**（约 Aug 14）

- **一句话总结**：针对实时交互场景小 batch MoE 推理的 expert weight 加载瓶颈，设计“部门共享参数 + 少量私有参数”结构 + 两阶段 routing，显著降低每步加载量。
- **核心贡献**：
  1. 同部门 expert 共享大部分参数，仅保留少量私有参数区分独特性。
  2. 定制两阶段 routing 避免冗余加载。
  3. 7B 预训练模型 A40 上 TPOT 最高 1.33×，DeepSeek-V3 微基准最高 2.0×（A40）/1.97×（H100）。
- **工程价值**：直接针对小 batch 低延迟场景（coding assistant、实时交互），减少内存带宽压力，适合生产 MoE serving。
- **是否值得读**：强烈推荐  
- **Relevance Score**：5  
- **Link**：https://arxiv.org/abs/2608.14385

### 【Title】KV Cache Compression Through the Lens of Transform Coding（AATC）  
**arXiv:2608.14191**（约 Aug 14）

- **一句话总结**：从注意力感知失真 + 变换编码/反向注水理论出发，做 attention-aware 的 bit 分配，实现约 5.8× KV 压缩且近无损。
- **核心贡献**：
  1. 证明白噪声量化模型下 attention 失真可分解为 key/value 可加贡献。
  2. 基于 transform coding + reverse water-filling 在校准集上分配 bit。
  3. Llama-3.1-8B / Qwen-2.5-7B 上 LongBench、RULER、GSM8K 等多项 benchmark 近无损。
- **工程价值**：量化方向有理论支撑 + 强实验，比单纯 MSE 最小化更贴合下游注意力，适合长上下文 serving 落地。
- **是否值得读**：强烈推荐  
- **Relevance Score**：4.5  
- **Link**：https://arxiv.org/abs/2608.14191

### 【Title】OpScale: Operator-level Provisioning and Autoscaling for LLM Serving  
**arXiv:2608.13499**（约 Aug 13）

- **一句话总结**：把 LLM serving 的扩缩容粒度从整模型下沉到 operator 级，解决粗粒度导致的 SLO 违反或 GPU 浪费。
- **核心贡献**：
  1. 刻画 operator 异质性，暴露 operator 级弹性作为可行 primitive。
  2. 完整框架：profiling + provisioning + placement + runtime。
  3. 生产 trace 上最高节省 36% GPU / 28% 功耗，或固定成本下吞吐 +44%。
- **工程价值**：云集群成本优化直接相关，比整模型扩缩更精细，对多租户/突发流量有实际价值。
- **是否值得读**：强烈推荐  
- **Relevance Score**：5  
- **Link**：https://arxiv.org/abs/2608.13499

### 【Title】Rollplex: Cross-Phase GPU Spatial Sharing for Vision Language Model Post-Training  
**arXiv:2608.14498**（约 Aug 14）

- **一句话总结**：针对 VLM on-policy RL 的 rollout / reference / training 串行浪费，把 prefix 计算挪到 rollout decode 窗口，实现跨阶段 GPU 空间共享。
- **核心贡献**：
  1. Phase-aware memory management 按 producer-consumer 生命周期控制 HBM。
  2. Parallelism-aware weight sharing 跨不同 TP 度复用物理存储。
  3. 32×H800 上相对串行 1.23–1.30×，相对 disaggregation 1.57–2.24×，保持同步 RL 语义。
- **工程价值**：VLM/多模态 agent 后训练系统优化，直接提升 RL 吞吐与 GPU 利用率。
- **是否值得读**：可选（重点做 VLM RL 的团队）  
- **Relevance Score**：4  
- **Link**：https://arxiv.org/abs/2608.14498

### 今日趋势观察
Inference / KV 相关工作仍占主导（virtualization、attention-aware 量化、MoE 解码优化），系统级 serving 扩缩容与后训练 GPU 共享也在增加。纯 agent 系统设计或大改对齐的新论文在这 48h 窗口内相对稀少，工程落地更集中在“让现有 serving 更省内存/更快”。

### 值得跟进的潜在方向
- **Token-level 内存虚拟化 + 异步 repacking**：与现有 eviction/quantization 正交，可组合出更高内存利用率。  
- **Operator-level 弹性调度**：从整模型到算子级的资源管理，可能成为多租户 LLM 集群的新基线。  
- **Attention-aware 量化理论**（transform coding 视角）：比启发式 bit 分配更可解释，后续可扩展到动态/在线分配。
