### **Model Inference / 推理优化**

**【Title】**  
PALS: Power-Aware LLM Serving for Mixture-of-Experts Models (arXiv:2605.21427)

- **一句话总结**：将GPU功率上限作为一等公民控制旋钮，与batch size等软件参数联合优化，实现MoE模型serving的能效提升。  
- **核心贡献**（2-3点）：1) 离线功率-性能模型 + 在线反馈控制器，动态调整功率/批处理配置以满足throughput目标；2) 在vLLM中集成，无需重训模型；3) 多GPU + dense/MoE模型上能效提升高达26.3%，QoS违规减少4-7x。  
- **工程价值**：**高**。直接针对生产serving的能耗与功率预算（数据中心关键约束），功率感知调度可无缝集成现有inference引擎，支持grid-interactive AI系统；对MoE特别实用。  
- **是否值得读**：**强烈推荐**  
- **Relevance Score**：5/5  
- **Link**：https://arxiv.org/abs/2605.21427

### **LLM Agents（系统设计/落地）**

**【Title】**  
Agent JIT Compilation for Latency-Optimizing Web Agent Planning and Scheduling (arXiv:2605.21470)

- **一句话总结**：将Web代理任务编译为包含LLM调用、工具调用和并行的可执行代码，实现JIT规划+调度，大幅降低顺序fetch-screenshot-execute循环的延迟。  
- **核心贡献**（2-3点）：1) JIT-Planner生成/验证多候选代码计划并选最低成本；2) JIT-Scheduler用Monte Carlo从延迟分布估计并行策略；3) 不变性工具协议减少工具误用，5个Web app上实现10.4x speedup / +28% accuracy（Planner）和2.4x / +9%（Scheduler）。  
- **工程价值**：**高**。直接解决计算机使用代理（CUA）的latency瓶颈，提供可编译、可并行的agent执行路径，易于生产集成；对GUI/浏览器代理落地价值大。  
- **是否值得读**：**强烈推荐**  
- **Relevance Score**：5/5  
- **Link**：https://arxiv.org/abs/2605.21470

**【Title】**  
Insights Generator: Systematic Corpus-Level Trace Diagnostics for LLM Agents (arXiv:2605.21347)

- **一句话总结**：多代理系统对大规模agent执行trace语料进行系统性诊断，生成证据支撑的自然语言洞见，帮助迭代scaffold。  
- **核心贡献**（2-3点）：1) 形式化corpus-level trace diagnostics问题；2) Scout-Investigator架构跨trace提出/验证假设；3) 专家使用IG报告后scaffold性能提升30.4pp，编码agent稳定获益。  
- **工程价值**：**中高**。生产agent系统调试痛点（trace爆炸式增长），提供可扩展的自动化诊断工具，支持闭环优化；对复杂multi-turn agents的运维有实际帮助。  
- **是否值得读**：**强烈推荐**  
- **Relevance Score**：4.5/5  
- **Link**：https://arxiv.org/abs/2605.21347
