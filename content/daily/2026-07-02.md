### 1. LLM Agents / RL方向

**【Title】**  
QVal: Cheaply Evaluating Dense Supervision Signals for Long-Horizon LLM Agents (arXiv:2606.32034)

- **一句话总结**：提出训练前评估长时序LLM Agent密集监督信号（dense supervision）的训练-free基准QVal，直接对齐Q-value排序，避免昂贵下游训练混淆。  
- **核心贡献**（2-3点）：(1) QVal-v1.0基准覆盖21种方法、4环境、6骨干模型，1.2K+实验；(2) 发现简单prompting baseline常优于近期复杂dense方法，家族内聚性强；(3) 支持快速迭代新信号，无需完整RL训练。  
- **工程价值**：极高。对长时序Agent RL训练（稀疏reward问题）提供标准化评估管道，降低实验成本，可直接用于SFT/RLHF pipeline调试和信号选择；便于系统级优化trajectory采样和credit assignment。  
- **是否值得读**：**强烈推荐**（Agent RL工程师必看）。  
- **Relevance Score**：5/5  
- **Link**：https://arxiv.org/abs/2606.32034 (代码/数据提及，便于复现)。

**【Title】**  
ECHO: Prune to act, trace to learn with selective turn memory in agentic RL (arXiv:2606.31650)

- **一句话总结**：针对长时序Agent上下文爆炸问题，提出selective turn-memory框架ECHO，通过prune+trace实现高效历史管理与可追溯RL credit assignment。  
- **核心贡献**（2-3点）：(1) 压缩turn为memory record，选择性重建上下文并路由credit到源证据；(2) 在BrowseComp-Plus上达43.4%准确率，优于GRPO/SUPO，同时降低turn数和trajectory volume；(3) 零样本泛化到多任务（QA、code gen等）。  
- **工程价值**：高。直接解决Agentic RL中context window与traceability痛点，支持生产级长horizon tool-use部署；memory管理+RL结合，有系统优化潜力（如KV-like selective caching）。  
- **是否值得读**：**强烈推荐**。  
- **Relevance Score**：5/5  
- **Link**：https://arxiv.org/abs/2606.31650

**【Title】**  
Generative Skill Composition for LLM Agents (arXiv:2606.32025)

- **一句话总结**：形式化Agent技能组合为结构化预测问题（subset+count+order），提出SkillComposer用constrained autoregressive decoder联合生成可执行技能计划。  
- **核心贡献**（2-3点）：(1) 超越top-3 retrieval，在SkillsBench上显著提升pass rate（+18~23pp），接近gold upper bound且token成本更低；(2) 从真实human-curated技能库构建训练数据；(3) 捕捉技能间依赖。  
- **工程价值**：高。技能库管理是Agent落地核心瓶颈，此方法提供可扩展的composition系统，可集成到multi-agent或tool-use框架中，提升可复用性和效率。  
- **是否值得读**：**强烈推荐**（生产Agent工程师）。  
- **Relevance Score**：4.5/5  
- **Link**：https://arxiv.org/abs/2606.32025

### 2. RL / Alignment方向

**【Title】**  
TRIAGE: Role-Typed Credit Assignment for Agentic Reinforcement Learning (arXiv:2606.32016相关，参见recent列表)

- **一句话总结**：针对Agentic RL的多角色credit assignment提出TRIAGE，通过role-typed机制提升长horizon决策中的归因准确性。  
- **核心贡献**：引入角色感知credit，提升多agent或multi-turn场景下的RL稳定性（实验支撑）。  
- **工程价值**：中高。直接服务Agent RL训练，减少credit collapse问题，可与ECHO等结合用于系统优化。  
- **是否值得读**：**可选**（与QVal/ECHO互补）。  
- **Relevance Score**：4/5  
- **Link**：https://arxiv.org/abs/2606.32016 (或搜索TRIAGE)
