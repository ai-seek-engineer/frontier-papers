### Inference / Speculative Decoding & KV Cache（优先级1）

**【Title】** A Practical Investigation of Training-free Relaxed Speculative Decoding (arXiv:2607.08690)

- **一句话总结**：系统调研并统一训练-free 放松版 speculative decoding，在当代 LLM 上基准测试，提炼实际工程权衡。
- **核心贡献**（2-3点）：统一现有放松技术框架；大规模当代 benchmark（能力-速度 tradeoff）；明确 takeaway（如放松需强 drafter，不适合轻量 MTP drafter；能力评估不可少）。
- **工程价值**：直接可用于推理加速部署。放松版能进一步提升 throughput（损失可控），指导生产中 drafter 选择、验证策略和 tradeoff 决策，避开常见坑。
- **是否值得读**：**强烈推荐**（实践导向强）。
- **Relevance Score**：5
- **Link**：https://arxiv.org/abs/2607.08690

**【Title】** Towards Efficient Large Language Model Serving: A Survey on System-Aware KV Cache Optimization (arXiv:2607.08057)

- **一句话总结**：系统视角梳理 KV cache 在 LLM serving 中的优化，从 temporal/spatial/structural 三维组织近期工作并分析 co-design。
- **核心贡献**（2-3点）：行为视角重构 KV infra（执行调度、放置迁移、表示保留）；跨维度 affinity 分析；未来方向洞见。
- **工程价值**：极高。直接指导 serving 系统 KV eviction、offloading、compression、scheduling 设计，解决 memory/throughput 瓶颈，可立即用于 vLLM/TGI 等框架迭代。
- **是否值得读**：**强烈推荐**（系统工程师必看综述）。
- **Relevance Score**：5
- **Link**：https://arxiv.org/abs/2607.08057

### LLM Agents / Multi-Agent Systems（优先级3）

**【Title】** From Prompts to Contracts: Harness Engineering for Auditable Enterprise LLM Agents (arXiv:2607.08028)

- **一句话总结**：提出 harness-engineering 方法，将 prompt-based 原型转为带确定性代码边界、可审计合约的 enterprise LLM agent 架构。
- **核心贡献**（2-3点）：可替换 composition boundary + 验证 artifacts；模型替换/故障注入实验验证合约保持；代码-owned enforcement 优于纯 prompt 或外部 guardrail（安全+utility 双保）。
- **工程价值**：高落地性。解决生产中 agent 不可控、可审计、traceability 痛点，提供 GitHub 参考实现，适合企业从原型到可运维系统的转型。
- **是否值得读**：**强烈推荐**（系统设计导向）。
- **Relevance Score**：4.5
- **Link**：https://arxiv.org/abs/2607.08028

**【Title】** WebSwarm: Recursive Multi-Agent Orchestration for Deep-and-Wide Web Search (arXiv:2607.08662)

- **一句话总结**：递归委托多代理框架，支持动态任务分解、深度/广度搜索协作，在复杂 web 任务上超越单/多代理 baseline。
- **核心贡献**（2-3点）：progressive recursive delegation + search mode；过程经验复用 + web 结构 probing；多 benchmark（BrowseComp-Plus 等）验证深度-广度能力。
- **工程价值**：实用 agent 系统设计，可扩展到研究/信息检索 agent；动态 orchestration 减少 context 爆炸，适合生产工具集成。
- **是否值得读**：**强烈推荐**（有实际任务 benchmark）。
- **Relevance Score**：4
- **Link**：https://arxiv.org/abs/2607.08662
