### Model Inference / 推理优化
**【Title】** EnerInfer: Energy-Aware On-Device LLM Inference (arXiv ~2606.23001)

- **一句话总结**：针对移动/边缘设备LLM推理的能耗和热管理框架，通过模型结构感知的预测和在线反馈实现联合优化。
- **核心贡献**（2-3点）：
  - 取代传统per-model profiling，用disaggregated、结构感知预测+ranking-driven反馈管理能量/吞吐/热量。
  - 在真实设备（手机、笔记本、开发板）上验证，能量效率提升高达65%/12%/24%，不牺牲QoE。
  - 实用serving路径优化，适用于隐私/成本敏感部署。
- **工程价值**：直接用于on-device推理优化，降低部署能耗/热限制，是KV cache/量化之外的系统级补充；可集成到现有引擎中，提升实际生产效率。
- **是否值得读**：**强烈推荐**（系统优化+真实硬件数据）。
- **Relevance Score**：5
- **Link**：arXiv搜索 EnerInfer 或相关ID。

**【Title】** SiFAR: Synchronization-Free All-Reduce for Low-Latency LLM Inference (arXiv ~2607.08973)

- **一句话总结**：针对多GPU推理中All-Reduce同步开销的优化，通过无同步All-Reduce减少latency，尤其适合reasoning/agentic workloads。
- **核心贡献**（2-3点）：
  - 移除All-Reduce同步，提升Llama-3.1-8B在8 H200上的token throughput 43%。
  - SiFAR变体减少All-Reduce latency高达52%，端到端throughput提升18.6%（8B）和13.1%（更大模型）。
  - 理论分析+实际benchmark。
- **工程价值**：直接针对分布式推理的通信瓶颈，适用于高并发低延迟场景；易集成到现有TP系统。
- **是否值得读**：**强烈推荐**。
- **Relevance Score**：5
- **Link**：arXiv SiFAR。

**【Title】** RoPE-Aware Bit Allocation for KV-Cache Quantization (Block-GTQ, ~2606.24033)

- **一句话总结**：RoPE感知的KV cache量化，通过block-level能量分数和greedy bit分配，显著提升长上下文保真度。
- **核心贡献**：RoPE block能量评分+greedy分配；NIAH/LongBench大幅提升（e.g., K2V2下NIAH 70.6→97.4）；packed serving路径实现3.24x压缩+速度提升。
- **工程价值**：推理优化核心（KV cache是瓶颈），支持更长上下文/更高吞吐，packed路径实用。
- **是否值得读**：**强烈推荐**。
- **Relevance Score**：5

### AI Infra / 分布式 / 系统优化
**【Title】** Contextra: Hierarchical Context Caching for Long Context LLM Serving (Stanford, OSDI 2026)

- **一句话总结**：分层上下文缓存框架，解决长上下文KV cache的I/O碎片和加载延迟，通过GPU-assisted I/O和cache-aware调度实现高效serving。
- **核心贡献**：GPU-assisted I/O解耦布局；cache-aware调度重叠stalls；SGLang实现，TTFT降低5x vs vLLM+LMCache，3.75x vs TensorRT-LLM。
- **工程价值**：生产级长上下文serving优化，直接缓解内存/带宽压力，兼容现有引擎。
- **是否值得读**：**强烈推荐**。
- **Relevance Score**：5

**【Title】** SpectrumKV: Per-Token Mixed-Precision KV Cache Transfer for PD Disaggregated Serving (~2606.08635)

- **一句话总结**：预填充-解码分离serving中，按token重要性混合精度传输KV cache，平衡带宽和质量。
- **核心贡献**：3-tier（FP16/INT8/INT4）自适应策略；perplexity/NIAH更好，TTFT降低50-62%。
- **工程价值**：分布式serving通信优化，减少KV传输开销。
- **是否值得读**：**强烈推荐**（系统视角强）。
- **Relevance Score**：4-5
