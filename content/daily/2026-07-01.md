### 【Model Inference / 推理优化】

**【Title】** Predict, Reuse, and Repair: Accelerating Dynamic Sparse Attention for Long-Context LLM Decoding (PRR)  
- **一句话总结**：针对动态稀疏注意力（DSA）在长上下文解码中“选择-计算”串行瓶颈，提出预测-复用-修复运行时，通过时序局部性预测KV块并推测计算，事后修复。  
- **核心贡献**（2-3点）：(1) EMA轻量预测器+profile-guided推测预算，将推测工作移出关键路径；(2) FlashAttention-based修复内核，利用online-softmax增量融合遗漏块；(3) 在多种DSA方法和长上下文基准上，单token解码延迟降低至40%，准确性保留。  
- **工程价值**：直接针对生产长上下文推理（尤其是RAG/Agent长会话），可集成到vLLM/SGLang等serving框架，降低decode latency而非仅prefill；代码可用（GitHub链接），易于benchmark和部署。  
- **是否值得读**：**强烈推荐**（Inference工程师必看）。  
- **Relevance Score**：5/5  
- **Link**：https://arxiv.org/abs/2606.30389

**【Title】** When Is a Draft Accepted? A Theory of Acceptance in Speculative Decoding  
- **一句话总结**：为speculative decoding提供接受概率的理论框架，分析draft acceptance条件、rejection region及最坏情况tie-breaking，提升理解和优化空间。  
- **核心贡献**（2-3点）：(1) 形式化draft acceptance的q-value/top-m条件；(2) 推导rejection region边界；(3) 为adaptive/tree-structured speculative提供理论支撑。  
- **工程价值**：帮助工程师更好设计drafter（e.g., tree structure、adaptive budget）、量化acceptance rate tradeoff，提升speculative在生产中的稳定性与吞吐；理论+实践指导，可用于现有框架调优。  
- **是否值得读**：**强烈推荐**（Speculative decoding核心优化）。  
- **Relevance Score**：5/5  
- **Link**：https://arxiv.org/abs/2606.30265

### 【AI Infra / 分布式训练 / 系统优化】

**【Title】** One-Step Gradient Delay is Not a Barrier for Large-Scale Asynchronous Pipeline Parallel LLM Pretraining  
- **一句话总结**：挑战异步pipeline parallelism（PipeDream-2BW）中one-step gradient delay的“unstable”刻板印象，通过optimizer选择（Muon）和Error Feedback修正，实现接近同步性能的大规模预训练。  
- **核心贡献**（2-3点）：(1) 实证证明AdamW敏感但Muon鲁棒；(2) 引入optimizer-agnostic修正+理论收敛分析；(3) 10B规模模型实验验证性能差距弥合。  
- **工程价值**：显著提升分布式训练GPU利用率（消除bubbles），适用于大规模pretraining infra；对现有Megatron/DeepSpeed pipeline的异步改造有直接指导价值。  
- **是否值得读**：**强烈推荐**（Infra/训练工程师）。  
- **Relevance Score**：4/5  
- **Link**：https://arxiv.org/abs/2606.30634

### 【LLM Agents（有实际落地或系统设计）】

**【Title】** Self-Evolving World Models for LLM Agent Planning (WorldEvolver)  
- **一句话总结**：为长时序LLM Agent引入自进化world model（部署时context修订，无需更新下游Agent/参数），通过episodic/semantic memory + selective foresight提升预测与规划。  
- **核心贡献**（2-3点）：(1) Episodic Memory检索真实transition模拟；(2) Semantic Memory提取mismatch heuristic rules；(3) ALFWorld/ScienceWorld上提升world model准确性和Agent success rate。  
- **工程价值**：解决Agent长期规划中world model不可靠问题，可作为plug-in模块集成到Agent框架（e.g., LangGraph/LangChain），test-time adaptation降低训练开销；代码/数据支持复现。  
- **是否值得读**：**强烈推荐**（Agent系统设计师）。  
- **Relevance Score**：4/5  
- **Link**：https://arxiv.org/abs/2606.30639

**额外：TraceLab（https://arxiv.org/abs/2606.30560）** 提供真实coding agent workloads trace（~4300 sessions），对serving优化（tool calling、prefix cache、KV管理）有高参考价值，但更偏characterization而非新方法，列为可选补充。
