**【Title】** CacheRoute: Planned Prefix-Affinity Routing for Large-Scale LLM Serving  
- 一句话总结：用周期性路由规划 + 前缀亲和性，在大规模LLM serving中大幅提升KV cache hit rate与吞吐，同时控制负载倾斜。  
- 核心贡献（2-3点）：  
  1. 周期性生成路由计划，将高流量key稳定分配到warm set，按预期负载放置。  
  2. 支持hot key多目的地（主实验多为单目的地），兼顾affinity与负载均衡。  
  3. 在Llama-3.3-70B fp8、60×H100上达到176 QPS（3.5s p99 SLO），是最强baseline的2.3×；hit rate从64%提升到93%。  
- 工程价值：直接可落地于生产serving系统（vLLM类），解决cache-blind balancing导致的命中率低问题；有明确的shadow replay部署建议。  
- 是否值得读：强烈推荐  
- Relevance Score：5  
- Link：https://arxiv.org/abs/2608.19677  

**【Title】** FleetSieve: Decision-Critical Profiling for SLO-Aware LLM Fleet Configuration  
- 一句话总结：面向SLO的LLM集群配置（TP degree + replica数）智能profiling，只测对最终决策有影响的配置，显著减少测量成本。  
- 核心贡献（2-3点）：  
  1. 联合建模capacity与tail latency，用conservative/optimistic allocation差距作为停止条件。  
  2. 在31B模型H100网格上，比随机profiling节省约5-7% GPU-seconds，且避免选中违反SLO的配置。  
  3. 错误sparse-profile可导致最高1.93 req/s损失。  
- 工程价值：直接用于生产fleet sizing与autoscaling决策，降低profiling开销，避免SLO违规。  
- 是否值得读：强烈推荐  
- Relevance Score：5  
- Link：https://arxiv.org/abs/2608.19659  

**【Title】** From LLM Inference to Agentic Workloads: Characterization and Implications for Serving Systems  
- 一句话总结：系统级刻画agentic工作负载与传统LLM inference的本质差异，并给出可落地的serving优化。  
- 核心贡献（2-3点）：  
  1. AgentSysBench + 统一instrumentation，总结6大特性（非LLM组件主导延迟、异构资源亲和、状态空闲时间长、跨请求冗余等）。  
  2. 设计探索：task-aware serving降延迟29-40%，通信感知placement最高4.5×，state offloading降内存4.6×，tool-result caching省35%冗余搜索。  
  3. 生产trace验证跨请求冗余与缓存机会。  
- 工程价值：agent serving从“套用inference假设”转向专用系统设计；对KV管理、调度、状态卸载有直接指导意义。  
- 是否值得读：强烈推荐  
- Relevance Score：5  
- Link：https://arxiv.org/abs/2608.15127  

**【Title】** KV-Rescue: Recovering Reasoning Language Model KV Eviction Loss via Stepwise Interleaving  
- 一句话总结：训练-free框架，用轻量全上下文helper与主模型交叉推理步骤，恢复激进KV eviction造成的推理精度损失。  
- 核心贡献（2-3点）：  
  1. 将eviction损失主要归因于信息缺口而非能力缺口；7B-evicted + 1.5B-full互补，oracle可恢复79%差距。  
  2. 在线entropy+compressibility检测，提前终止退化生成。  
  3. 在Qwen2.5-Math 7B/72B五个数学benchmark上，B=64时平均恢复87%精度损失，同时减少43%无效token生成。  
- 工程价值：可直接叠加在现有KV eviction/compression方案上，特别适合长推理trace场景，几乎无额外训练成本。  
- 是否值得读：强烈推荐  
- Relevance Score：4  
- Link：https://arxiv.org/abs/2608.15797  

**【Title】** Pre-Compiled Pipeline Shards for Distributed LLM Inference on Intel AI PC Fleets  
- 一句话总结：在普通网络连接的Intel AI PC集群上，用预编译pipeline shard + speculative decoding实现超单机内存的大模型serving。  
- 核心贡献（2-3点）：  
  1. 注入beam_idx Gather触发OpenVINO IndirectKVCache fusion，恢复单机性能。  
  2. 状态式OpenVINO + speculative decoding + micro-batching支持多用户。  
  3. 两节点Llama-3.1-8B INT4达到单机1.79×吞吐；四节点可跑70B。  
- 工程价值：边缘/消费级硬件集群化推理的实用路径，有完整代码与复现脚本。  
- 是否值得读：可选  
- Relevance Score：3  
- Link：https://arxiv.org/abs/2608.19147
