**【Title】** Cross-Model KV Cache Transfer in LLM Families: A Closed-Form Linear Mapping for Prefill Reuse  
**arXiv:2608.03893**（2026-08-04）

- 一句话总结：同系列不同尺寸模型之间，通过闭式线性映射直接复用源模型 KV cache，跳过目标模型 prefill。
- 核心贡献：
  1. 发现 matched-KV 对（同 head 数/维度）存在显著线性结构，单层可解释 56%/32% key/value 方差，多层提升到 79%/65%。
  2. 设计 per-head ridge mapper（去 RoPE + top-k 源层拼接 + 小校准集），闭式求解，无需训练大模型。
  3. 多系列 6 对实验：4 对保留 73-98% 独立 prefill 精度，映射速度 2.7-25× 快于 re-prefill，多轮 handoff 稳定。
- 工程价值：生产级 cost-quality cascading、路由、会话中途切模型场景直接可用。大幅降低切换时的 TTFT 和计算浪费，是 inference 系统中“模型家族共享 KV”的实用路径。
- 是否值得读：强烈推荐
- Relevance Score：5
- Link：https://arxiv.org/abs/2608.03893

**【Title】** Fewer Tokens, Smaller Cache: Reward-Coordinated Efficient Reasoning  
**arXiv:2608.04771**（2026-08-05）

- 一句话总结：用过程奖励动态协调 KV 压缩力度与生成冗余，同时减少 token 数和 cache 占用。
- 核心贡献：
  1. 观察到推理轨迹上不同 step 对 context loss 的容忍度与 process reward 强相关。
  2. ReCo 框架：reward-adaptive KV 压缩 + 反射 token 惩罚 + 置信度 early-stop。
  3. 三模型六 benchmark：生成 token ↓37-65%，端到端延迟 2.08-2.35×，精度基本保持。
- 工程价值：直接针对 long-CoT 推理模型的 overthinking 瓶颈。KV 压缩与生成侧协同，避免“压 cache 反而生成更长”的反效果，适合推理服务和 agent 长轨迹场景。
- 是否值得读：强烈推荐
- Relevance Score：5
- Link：https://arxiv.org/abs/2608.04771

**【Title】** Practical Online KV Cache Compaction for LLM Agents: An Empirical Study  
**arXiv:2608.00902**（2026-08-02）

- 一句话总结：针对 agent 长轨迹的在线 KV 压缩，系统对比 token eviction 与 attention matching，并验证 proxy query 策略。
- 核心贡献：
  1. 明确 agent 场景必须在线压缩（未来 query 未知），对比多种廉价 proxy。
  2. 延迟压缩（等未来 query）显著优于立即压缩；token eviction 在 imperfect proxy 下更鲁棒。
  3. 多模型：80% KV 减少，精度大部分保留，部分场景吞吐提升。
- 工程价值：agent serving 的 KV 管理直接可落地参考。生产中最实用的是“何时压 + 用什么 proxy”的设计选择，而非再发明压缩算法。
- 是否值得读：强烈推荐
- Relevance Score：4.5
- Link：https://arxiv.org/abs/2608.00902

**【Title】** A Two-Tier Perspective on Inference-Time Parallelism in Multi-Agent LLM Systems  
**arXiv:2608.05791**（2026-08-06，ICML 2026）

- 一句话总结：将 multi-agent 推理时并行统一为 Replica Parallelism（任务级多路径）与 Structural Parallelism（路径内分解并发），并提出可控执行框架 TIPEX。

- 工程价值：multi-agent serving 的并行策略设计有明确指导。对 latency-accuracy-cost 三角有量化认识，避免盲目“多开几条路径”。
- 是否值得读：可选
- Relevance Score：4
- Link：https://arxiv.org/abs/2608.05791

### 1. 今日最值得读 Top 3

1. **Cross-Model KV Cache Transfer (2608.03893)**  
   闭式线性映射 + 生产级切换场景，直接解决模型家族路由/级联时的 prefill 重复计算，工程 ROI 极高。

2. **Reward-Coordinated Efficient Reasoning (2608.04771)**  
   把 process reward 同时驱动“压 cache”和“少生成”，是 long-CoT 推理成本控制的关键协同思路。

3. **Practical Online KV Cache Compaction for Agents (2608.00902)**  
   针对 agent 真实在线轨迹的系统实证，给出可立即落地的 proxy 与延迟策略，比再出一篇压缩算法更有用。

### 2. 今日趋势观察

- **Inference / KV 管理** 仍是绝对主线：跨模型复用、reward 协调压缩、agent 在线 compaction 同时出现，说明“KV 不再是静态前缀缓存，而是动态、跨模型、轨迹感知的共享状态”已成为共识。
- **Agent 系统设计** 明显升温：优化器本身被做成 agent、并行语义分层、工具调用接口的 bitter lesson，均指向“把系统决策内化进 agent + 可量化执行框架”。
- RL/Alignment 方向在近 48h 窗口内没有出现同等工程冲击力的新作（更多是之前窗口的延续）。

### 3. 值得跟进的潜在方向

- **跨模型 / 跨会话 KV 语义共享与映射**：线性闭式解已经可用，下一步是非线性、MoE、异构 head 配置的泛化，以及与 prefix caching / disaggregated serving 的深度结合。
- **过程奖励驱动的联合压缩-生成控制**：把 reward 同时作用在 cache 保留策略和 token 生成策略上，是 long-reasoning 与 agent 长轨迹的自然统一点。
- **Agent 执行时的可控并行语义**：Replica vs Structural 的分层与预算分配，可能成为 multi-agent serving 的标准调度抽象。
