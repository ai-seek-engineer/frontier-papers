### Inference / 系统优化方向

**【Title】**  
LedgerAgent: Structured State for Policy-Adherent Tool-Calling Agents (arXiv:2606.20529)

- **一句话总结**：通过独立 Ledger 维护任务状态 + 策略检查，实现工具调用代理的显式状态管理和策略合规，提升多轮客服场景可靠性。
- **核心贡献**（2-3点）：
  - 将隐式 prompt-based 状态管理转为显式 Ledger 结构，减少 stale/missing 信息导致的决策错误。
  - 执行环境改变工具调用前进行状态依赖策略检查，主动阻挡违规。
  - 多领域、多模型实验显示 pass@k 提升，尤其在严格一致性指标下显著。
- **工程价值**：直接针对 LLM Agents 实际落地痛点（状态漂移、策略违规），inference-time 方法，低开销、可集成到现有 serving 系统；对多轮交互 inference 有优化潜力。
- **是否值得读**：**强烈推荐**（Agent 系统设计实用）。
- **Relevance Score**：5/5
- **Link**：https://arxiv.org/abs/2606.20529

**【Title】**  
Threshold-Based Exclusive Batching for LLM Inference (arXiv:2606.00516, ICML 2026)

- **一句话总结**：针对混合批处理（MB）在带宽受限 GPU 上的瓶颈，提出阈值驱动的 Exclusive Batching (EB) 切换机制 + 混合调度器 EB+，显著提升吞吐。
- **核心贡献**（2-3点）：
  - 推导 MB/EB 性能交叉的闭式条件，依赖带宽、模型大小和工作负载组成（H200 高带宽 vs RTX PRO 低带宽阈值差异大）。
  - 渐近最优相切换阈值 + 内存安全批大小；EB+ 在线动态切换。
  - 带宽受限硬件上吞吐提升高达 41.9%，非平稳流量下优于 MB 达 36.4%。
- **工程价值**：高度实用推理优化，直接影响 vLLM 等 serving 系统调度；在 edge/成本敏感部署中价值极大，有代码实现。
- **是否值得读**：**强烈推荐**（系统优化核心）。
- **Relevance Score**：5/5
- **Link**：https://arxiv.org/abs/2606.00516

**【Title】**  
Automating SKILL.md Generation for Computer-Using Agents via Interaction Trajectory Mining (arXiv:2606.20363)

- **一句话总结**：从 GUI 交互轨迹中挖掘可读技能集群，用于构建显式 skill library 并训练 skill-aware 策略，但转移效果有限（诊断性研究）。
- **核心贡献**（2-3点）：
  - 三阶段 pipeline：轨迹分段、聚类技能、训练策略。
  - 集群在基准上可读性高（纯度 0.95+），但 GRPO 等提升有限，暴露当前边界检测/表示/奖励模型不足。
- **工程价值**：对 LLM Agents 的 skill library 构建有启发，可辅助工具/计算机使用代理的模块化设计；代码/轨迹挖掘思路可复用，但非即插即用性能 boost。
- **是否值得读**：**可选**（Agent 工程参考）。
- **Relevance Score**：4/5
- **Link**：https://arxiv.org/abs/2606.20363
