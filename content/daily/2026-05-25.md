### 【Inference / 推理优化】
**【Title】** Gated DeltaNet-2: Decoupling Erase and Write in Linear Attention

- **一句话总结**：通过通道级独立erase/write门控改进线性注意力，解决DeltaNet/KDA中erase-write耦合问题，提升长上下文检索与推理效率。
- **核心贡献**（2-3点）：
  - 引入独立通道wise erase gate (b_t) 和 write gate (w_t)，兼容KDA/Gated DeltaNet。
  - 推导fast-weight更新、chunkwise WY算法及高效并行训练backward pass。
  - 1.3B模型在FineWeb-Edu上训练，在RULER长上下文needle-in-haystack等基准显著优于Mamba-2/3、KDA变体，尤其多key检索。
- **工程价值**：线性注意力固定状态替代softmax unbounded KV cache，直接降低解码内存到常数级；适合生产级长上下文推理优化，代码开源（NVlabs）。
- **是否值得读**：**强烈推荐**
- **Relevance Score**：5
- **Link**：https://arxiv.org/abs/2605.22791

**【Title】** LCGuard: Latent Communication Guard for Safe KV Sharing in Multi-Agent Systems

- **一句话总结**：针对多Agent KV cache共享的隐私泄露问题，提出表示级变换保护框架，通过对抗训练减少敏感信息重构同时保持任务性能。
- **核心贡献**（2-3点）：
  - 将共享KV视为latent working memory，进行学习变换。
  - 操作化定义leakage（对抗decoder重构敏感输入），端到端对抗优化。
  - 多模型/基准实验显示显著降低重构泄露与攻击成功率，任务性能接近baseline。
- **工程价值**：多Agent系统中KV共享能大幅提效（比文本通信保留更丰富状态），但需安全；LCGuard提供可部署的隐私保护层，适用于生产Agent系统。
- **是否值得读**：**强烈推荐**
- **Relevance Score**：4.5
- **Link**：https://arxiv.org/abs/2605.22786

### 【LLM Agents】
**【Title】** MOSS: Self-Evolution through Source-Level Rewriting in Autonomous Agent Systems

- **一句话总结**：突破文本层（prompt/skill）自进化限制，实现Agent系统源码级自重写，基于生产失败证据闭环迭代。
- **核心贡献**（2-3点）：
  - 源码级修改管道（coding-agent CLI + 确定性验证 + ephemeral trial + container swap rollback）。
  - OpenClaw基准单周期将4-task mean score从0.25提升到0.61，无人工干预。
  - 代码开源。
- **工程价值**：解决部署后Agent静态问题，提供真正闭环自进化系统设计；源码修改比文本更通用/确定性，对生产Agent运维极高价值。
- **是否值得读**：**强烈推荐**
- **Relevance Score**：5
- **Link**：https://arxiv.org/abs/2605.22794

**【Title】** Vector Policy Optimization: Training for Diversity Improves Test-Time Search

- **一句话总结**：VPO通过向量奖励训练策略多样性，替代标量GRPO，提升inference-time search（如pass@k、evolutionary search）表现。
- **核心贡献**（2-3点）：
  - VPO作为GRPO drop-in，训练输出针对向量奖励不同trade-off的多样解。
  - 多任务实验中匹配/超越标量baseline，尤其大search budget下gap扩大；解锁GRPO无法解决的问题。
- **工程价值**：直接服务test-time scaling与Agent搜索（如代码生成、多persona）；后训练目标从单一reward转向diversity，对推理scaling系统友好。
- **是否值得读**：**强烈推荐**
- **Relevance Score**：4.5
- **Link**：https://arxiv.org/abs/2605.22817
