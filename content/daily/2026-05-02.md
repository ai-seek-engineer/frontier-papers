**【Title】**  
SpecFed: Accelerating Federated LLM Inference with Speculative Decoding and Compressed Transmission (arXiv:2604.25777, submitted 28 Apr 2026)

- 一句话总结：将speculative decoding集成到federated LLM inference中，结合top-K压缩传输与server-side重建，实现跨设备高效协作加速。
- 核心贡献（2-3点）：(1) 并行LLM处理+speculative draft机制降低通信等待；(2) top-K压缩传输与两种重建策略平衡带宽与准确性；(3) 在federated benchmark上显著降低端到端latency与通信量，同时维持生成质量。
- 工程价值（重点分析：是否能用于推理/infra优化）：**极高**——直接解决federated/分布式multi-device inference的通信与latency瓶颈，可扩展到edge-cloud混合serving框架；与现有vLLM-style speculative结合潜力大，降低带宽占用并提升整体throughput，适合生产跨设备Agent部署；实验覆盖真实federated场景。
- 是否值得读：强烈推荐（分布式推理与federated系统工程师核心）。
- Relevance Score：5/5
- Link：https://arxiv.org/abs/2604.25777

**【Title】**  
Don't Waste Bits! Adaptive KV-Cache Quantization for Lightweight On-Device LLMs (arXiv:2604.04722, recent revision/related activity in window)

- 一句话总结：提出token-importance感知的自适应KV cache量化策略，根据learned policy动态分配bit-width，针对on-device长上下文最小化内存/延迟开销。
- 核心贡献（2-3点）：(1) 超越固定精度/启发式，采用Huffman-like variable bit分配；(2) 优化expected memory-latency tradeoff；(3) 在on-device benchmark上维持竞争力准确率同时大幅压缩cache footprint。
- 工程价值（重点分析：是否能用于推理/infra优化）：**高**——针对边缘/内存受限部署的KV量化实用创新，直接集成到on-device serving pipeline（如MLX/llama.cpp扩展），提升并发与长上下文能力；与PagedAttention或offloading叠加效果显著，代码/实现线索支持快速复现。
- 是否值得读：强烈推荐（边缘推理工程师必看）。
- Relevance Score：5/5
- Link：https://arxiv.org/abs/2604.04722

**【Title】**  
Agent Memory Below the Prompt: Persistent Q4 KV Cache for Multi-Agent LLM Inference on Edge Devices (arXiv:2603.04428, active in recent discussions)

- 一句话总结：为edge多Agent设计持久化Q4量化KV cache系统，通过disk直接reload消除re-prefill开销，支持隔离per-agent上下文。
- 核心贡献（2-3点）：(1) Q4持久化block pool + BatchQuantizedKVCache实现并发；(2) cross-phase injection避免position bias；(3) 多模型（Gemma/DeepSeek/Llama）上TTFT加速10-136x，内存容量提升4x，perplexity退化可控，开源实现。
- 工程价值（重点分析：是否能用于推理/infra优化）：**极高**——精准击中multi-agent edge部署的memory与latency痛点，可作为serving layer插件集成现有框架；直接降低re-prefill GPU/时间成本，支持生产持久化Agent workflow；开源代码门槛低，易验证。
- 是否值得读：强烈推荐（Agent + 边缘Infra工程师）。
- Relevance Score：5/5
- Link：https://arxiv.org/abs/2603.04428
