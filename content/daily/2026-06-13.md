### 1. Model Inference / 推理优化
**【Title】**  
SkillCAT: Contrastive Assessment and Topology-Aware Skill Self-Evolution for LLM Agents (arXiv:2606.13317, 11 Jun 2026)

- **一句话总结**：训练-free 框架，通过对比评估和拓扑感知将执行轨迹转化为可重用技能文档，解决 LLM Agents 技能演化中的冗余和加载开销。
- **核心贡献**（2-3点）：
  - 对比评估机制筛选高质量技能补丁，避免单轨迹合并噪声。
  - 拓扑感知技能加载，仅检索相关子图，降低推理时全量加载开销。
  - 实验验证在动态 Agent 任务中提升效率和鲁棒性。
- **工程价值**：直接适用于 Agent 推理优化（技能复用 = 减少重复 prompt/context 计算，类似 KV cache 压缩的 Agent 侧优化）。可集成到 vLLM/HF serving pipeline，提升多轮/长期 Agent 吞吐；有代码线索，易复现。
- **是否值得读**：**强烈推荐**（Agent 推理实用优化）。
- **Relevance Score**：5/5
- **Link**：https://arxiv.org/abs/2606.13317

（本方向仅此一篇高质量匹配，其他 KV/quantization 多为早期或非过去48h。）

### 2. LLM Agents（有实际落地或系统设计）
**【Title】**  
Agents-K1: Towards Agent-native Knowledge Orchestration (arXiv:2606.13669, 11 Jun 2026)

- **一句话总结**：端到端知识编排 pipeline，将科学论文转为 Agent-native KG，支持多模态实体/证据/关系提取和图检索，构建大规模 Scholar-KG。
- **核心贡献**（2-3点）：
  - 多模态解析器 + GRPO 训练的 4B IE 骨干（规则奖励），超越抽象级处理。
  - GraphAnything CLI 统一 web/图检索/跨文档遍历。
  - 处理 246 万论文，释放百万级子集 + 系统接口。
- **工程价值**：Agent 系统设计典范（RAG/知识检索 infra 升级），直接提升科学/长上下文 Agent 准确性和多跳推理；支持扩展到通用领域，可用于生产知识 Agent 后端。
- **是否值得读**：**强烈推荐**（系统完整、可落地）。
- **Relevance Score**：5/5
- **Link**：https://arxiv.org/abs/2606.13669

**【Title】**  
EvoArena: Tracking Memory Evolution for Robust LLM Agents in Dynamic Environments (arXiv:2606.13681, ~11 Jun 2026) + EvoMem 范式。

- **一句话总结**：引入动态环境基准（终端/软件/社交渐进更新）和 patch-based EvoMem 内存，解决静态 benchmark 下 Agent 失效问题。
- **核心贡献**（2-3点）：
  - EvoArena 基准量化动态适应性（当前 Agent 仅 ~39.6% 准确率）。
  - EvoMem 通过结构化更新历史跟踪演化，提升证据捕获和链级成功率。
  - 在 GAIA/LoCoMo 等标准基准也有提升。
- **工程价值**：Agent 内存/状态管理优化（类似 KV cache 的演化版），适用于生产动态 Agent（如工具/环境交互）；patch 设计便于工程集成。
- **是否值得读**：**强烈推荐**（Benchmark + 方法双击）。
- **Relevance Score**：4.5/5
- **Link**：https://arxiv.org/abs/2606.13681

### 3. SFT / Alignment / RLHF & Reinforcement Learning
**【Title】**  
MaxProof: Scaling Mathematical Proof with Generative-Verifier RL and Population-Level Test-Time Scaling (arXiv:2606.13473, 11 Jun 2026)

- **一句话总结**：结合生成-验证器 RL（低假阳性）和种群级 test-time scaling，实现 IMO/USAMO 水平数学证明。
- **核心贡献**（2-3点）：
  - 训练 proof generation/verification/critique-repair 三能力。
  - Test-time 用 generator/verifier/refiner/ranker + tournament 选择。
  - 达到 IMO 2025 35/42、USAMO 2026 36/42（超人类金牌阈值）。
- **工程价值**：RLHF/RL 训练 + inference-time scaling 实践（verifier 集成到 serving pipeline，population search 类似 speculative decoding 的扩展）；对 Alignment 和 reasoning 优化有直接借鉴。
- **是否值得读**：**强烈推荐**（强实验 + scaling 洞见）。
- **Relevance Score**：4.5/5
- **Link**：https://arxiv.org/abs/2606.13473

（其他 RL/MARL 多为特定应用或非核心工程创新，未入选。）

### 【额外输出】

1. **今日最值得读 Top 3**（工程师视角）：
   - **1. Agents-K1**：完整 Agent-native KG pipeline + 大规模数据 + 接口，知识密集 Agent 的系统蓝图，直接可落地/扩展。
   - **2. SkillCAT**：训练-free 技能演化，针对 Agent 推理瓶颈（加载/冗余），工程集成成本低、收益高。
   - **3. MaxProof**：RL + test-time scaling 实战，展示 verifier + population 如何推高 reasoning 性能，值得 infra/alignment 团队跟进。

2. **今日趋势观察**：**LLM Agents 方向明显增加**（动态环境、知识编排、技能自演化），强调**内存/状态演化**和**知识结构化**，反映从静态 benchmark 向生产动态系统演进。推理优化和 RL 仍有高价值 scaling 工作，但 Agent 系统设计热度最高。

3. **值得跟进的潜在方向**：**动态环境下的 Agent 内存演化 + 结构化技能/KG 复用**（EvoMem + SkillCAT + Agents-K1 交叉）。这可能催生下一代 Agent infra（持久化、可演化状态管理），结合 KV cache 优化，将显著提升长期/多代理部署效率。建议监控相关 benchmark 和开源实现。
