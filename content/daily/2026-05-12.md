### Model Inference / 推理优化

**【Title】**  
Reformulating KV Cache Eviction Problem for Long-Context LLM Inference (arXiv:2605.07234, ~5月8-10日)

- **一句话总结**：将KV cache eviction重构为固定预算下最小化各层attention输出偏差的优化问题，并提出LaProx算法实现高效求解。
- **核心贡献**（2-3点）：1) 数学重构eviction为层级感知优化而非简单启发式；2) LaProx求解器支持动态预算，实验覆盖多模型（Llama-3.1-8B等）和LongBench；3) 显著优于现有eviction方法，尤其长上下文。
- **工程价值**：直接可用于生产级长上下文serving系统，提升内存效率和吞吐，适用于vLLM/SGLang等框架集成；有benchmark数据支撑，易复现。
- **是否值得读**：**强烈推荐**
- **Relevance Score**：5
- **Link**：https://arxiv.org/abs/2605.07234

**【Title】**  
A Queueing-Theoretic Framework for Stability Analysis of LLM Inference with KV Cache Memory Constraints (arXiv:2605.04595, 5月6日左右)

- **一句话总结**：首次引入同时考虑计算和KV cache内存约束的排队论模型，分析LLM inference系统的稳定性与调度。
- **核心贡献**（2-3点）：1) 联合建模compute + memory（KV主导）约束；2) 推导稳定性条件和性能指标；3) 为动态batching/调度提供理论指导。
- **工程价值**：对高负载serving系统（如多租户inference集群）的资源调度和稳定性预测极有价值，能指导防止OOM或latency爆炸的策略；工程落地潜力高。
- **是否值得读**：**强烈推荐**
- **Relevance Score**：5
- **Link**：https://arxiv.org/abs/2605.04595

**【Title】**  
Federation of Experts: Communication Efficient Distributed Inference for Large Language Models (arXiv:2605.06206, ~5月7日)

- **一句话总结**：提出FoE架构，通过专家联邦方式显著降低分布式LLM inference的通信开销，同时保持质量。
- **核心贡献**（2-3点）：1) 通信高效的分布式设计；2) LongBench等基准上吞吐/TTFT/TBT提升明显（最高5.2x latency降低）；3) 单节点和多节点均有效。
- **工程价值**：直接针对分布式inference痛点（通信瓶颈），适用于多机/多GPU部署；有代码/复现潜力，性能提升量化清晰。
- **是否值得读**：**强烈推荐**
- **Relevance Score**：4.5
- **Link**：https://arxiv.org/abs/2605.06206

（其他KV相关如LightKV、LookaheadKV、Persistent Q4等为稍早论文，已有工程实现价值但不在严格24-48h窗口内，建议持续跟踪。）

### LLM Agents

**【Title】**  
The Memory Curse: How Expanded Recall Erodes Cooperative Intent in LLM Agents (arXiv:2605.08060)

- **一句话总结**：揭示LLM多agent系统中“记忆越多越不合作”的现象，并分析其机制。
- **核心贡献**（2-3点）：1) 系统性实验展示expanded recall对cooperation的负面影响；2) 机制分析（cs.CL/AI/Multiagent）；3) 对agent系统设计提供警示。
- **工程价值**：对构建可靠多agent系统（尤其是协作任务）有启发，可指导memory管理/提示设计，避免实际部署中的退化；benchmark支撑。
- **是否值得读**：**可选**（更偏现象分析而非直接优化）
- **Relevance Score**：3.5
- **Link**：https://arxiv.org/abs/2605.08060

**【Title】**  
Learning CLI Agents with Structured Action Credit under Selective Observation

- **一句话总结**：针对CLI环境下的LLM agent，提出结构化action credit和selective observation的学习方法。
- **核心贡献**：提升agent在部分可观测、结构化行动空间下的性能。
- **工程价值**：适用于工具使用/terminal agent落地；有实际系统设计元素。
- **是否值得读**：**可选**
- **Relevance Score**：3
- **Link**：arXiv近期cs.AI列表对应条目。
