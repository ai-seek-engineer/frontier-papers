### 1. Inference Optimization

**【Title】**  
Multi-Scale Dequant: Eliminating Dequantization Bottleneck via Activation Decomposition for Efficient LLM Inference (arXiv ~2605.13915, 近期新)

- **一句话总结**：通过多尺度激活分解，将 weight/KV dequant 操作移出 GEMM 关键路径，大幅降低量化推理的 dequant overhead。
- **核心贡献**（2-3点）：
  - 激活分解机制，将 dequant 与计算解耦。
  - 多尺度量化策略，平衡精度与硬件效率。
  - 实验显示显著降低 latency，无明显质量损失。
- **工程价值**：直接针对当前量化 LLM 推理瓶颈（dequant 常占 GEMM 路径显著开销），适用于生产级 serving（vLLM/SGLang 等后端易集成），对长上下文/高吞吐场景提升明显。代码线索强，可复现。
- **是否值得读**：**强烈推荐**（inference 工程师必看）。
- **Relevance Score**：5/5
- **Link**：https://arxiv.org/abs/2605.13915 (或搜索标题)

**【Title】**  
DARE: Diffusion Language Model Activation Reuse for Efficient Inference (arXiv:2605.08134)

- **一句话总结**：针对 diffusion LLM 的 token-wise redundancy，利用 DARE-KV（复用 KV activations）和 DARE-O（复用 output activations）实现高效 inference。
- **核心贡献**（2-3点）：
  - 识别 bi-directional self-attention 中的高度相关性，实现高达 87% activation reuse。
  - 结合 prefix caching 等技术提供 additive gains，无需 retraining。
  - 基准上 per-layer latency 降低至 1.20x，reasoning/code 任务 degradation 极低（~1-2%）。
- **工程价值**：扩散模型正成为 AR 替代方案，此工作直接优化其 inference 效率，KV reuse 思路可迁移到混合系统；代码可用，适合探索下一代生成架构。
- **是否值得读**：**强烈推荐**。
- **Relevance Score**：5/5
- **Link**：https://arxiv.org/abs/2605.08134

### 2. LLM Agents（系统设计）

**【Title】**  
GraphBit: A Graph-based Agentic Framework for Non-Linear Agent Orchestration (arXiv:2605.13848)

- **一句话总结**：用 Rust 引擎 + DAG 显式定义 workflow，取代 prompted orchestration，实现确定性、可审计的非线性 agent 执行。
- **核心贡献**（2-3点）：
  - 引擎级 routing/parallel/conditional control + 三层 memory 隔离（防 context bloat）。
  - GAIA benchmark 上 accuracy 67.6%（优于 6 个 baseline），零 framework hallucination，最低 overhead。
  - 强 ablation 支持各组件贡献。
- **工程价值**：解决实际 agent 系统痛点（hallucinated routing、loops、reproducibility），适合生产落地；Rust 引擎暗示高性能，memory 设计对长 pipeline 关键。
- **是否值得读**：**强烈推荐**（agent 工程师必读）。
- **Relevance Score**：5/5
- **Link**：https://arxiv.org/abs/2605.13848

**其他提及（未达顶格但值得注意）**：Persistent Q4 KV Cache for Multi-Agent（稍早，但工程性强，edge 多 agent 持久化 KV，TTFT 提升数十倍）；RLHF/Alignment 方向今日无特别强工程创新论文。
