**【Title】** PersistentKV: Page-Aware Decode Scheduling for Long-Context LLM Serving on Commodity GPUs (arXiv:2606.26666)

- **一句话总结**：针对 commodity GPU 上长上下文 serving 的 KV cache 调度痛点，提出 page-aware 的 decode attention 引擎和自适应调度策略，提升工作分配效率。
- **核心贡献**（2-3点）：1) PersistentKV 原生 block-table decode attention，支持 GQA head-group 映射和 KV tile 重用；2) 紧凑 workqueue 调度，仅执行非空任务；3) 自适应策略在不同 batch/size 下切换 kernel/调度，实现 throughput 提升。
- **工程价值**（重点分析）：**直接用于推理优化**。解决 paged-attention 在 mixed-length/long-context 下的 GPU 利用率和 fragmentation 问题，实验在 RTX 3060 等 commodity 硬件上验证，适用于 vLLM/FlashInfer 等生产栈的调度层优化，性价比高。
- **是否值得读**：**强烈推荐**（系统实现细节实用）。
- **Relevance Score**：5/5。
- **Link**：https://arxiv.org/abs/2606.26666

**【Title】** CAT-Q: Cost-efficient and Accurate Ternary Quantization for LLMs (arXiv:2606.26650)

- **一句话总结**：一种简单有效的 post-training ternary 量化方案，通过 learnable modulation 和 softened ternarization 实现高精度低成本压缩。
- **核心贡献**（2-3点）：1) LM + ST 组件优化权重分布和 ternarization 收敛；2) 仅需 512 calibration samples，支持 1.7B-235B 规模模型；3) 性能优于 BitNet 等需海量 token 训练的 baseline，量化时间极短（8-60 小时 on 8 A100）。
- **工程价值**（重点分析）：**强推理优化**。PTQ 友好、架构通用，显著降低部署显存/计算成本，代码开源，易集成到现有 serving  pipeline，是量化落地的实用方案。
- **是否值得读**：**强烈推荐**（ICML oral，实验扎实）。
- **Relevance Score**：5/5。
- **Link**：https://arxiv.org/abs/2606.26650

**【Title】** Epiphany-Aware KV Cache Eviction Without the Attention Matrix (arXiv:2606.26472)

- **一句话总结**：提出基于模型内部表征变化（epiphany score）的 KV eviction，无需 materialization attention matrix，支持 FlashAttention 栈。
- **核心贡献**（2-3点）：1) Epiphany score 直接从 forward pass 读取，噪声更低，尤其适合长 reasoning；2) 无训练、无 custom kernel；3) 在长上下文 benchmark 上优于 attention-based 方法，支持更长上下文（16x）。
- **工程价值**（重点分析）：**直接用于推理优化**（KV cache 管理）。兼容生产 fused kernels，降低长 CoT 部署瓶颈，速度提升明显（up to 2.8x）。
- **是否值得读**：**强烈推荐**。
- **Relevance Score**：5/5。
- **Link**：https://arxiv.org/abs/2606.26472

**【Title】** Information-Aware KV Cache Compression for Long Reasoning (arXiv:2606.26875)

- **一句话总结**：InfoKV 框架结合 entropy（predictive uncertainty）和 attention 进行 KV 压缩，关注 token 对未来上下文的影响。
- **核心贡献**（2-3点）：1) Forward Influence 指标捕捉远距离影响；2) 层级 entropy + attention 融合；3) 在 Llama-3.x 和 DeepSeek-R1 等模型的长上下文 reasoning benchmark 上优于纯 attention 方法。
- **工程价值**（重点分析）：**强推理优化**。针对 reasoning 模型的长 KV cache 痛点，提供信息论补充，提升压缩效果和下游性能。
- **是否值得读**：**强烈推荐**。
- **Relevance Score**：4/5。
- **Link**：https://arxiv.org/abs/2606.26875

**【Title】** HyperDFlash: MHC-Aligned Block Speculative Decoding with Gated Residual Reduction (arXiv:2606.26744)

- **一句话总结**：针对 DeepSeek-V4 MHC 架构优化的 block-parallel speculative decoding，解决 draft accuracy 退化问题。
- **核心贡献**（2-3点）：1) Pre-collapse residual + gated reducer 对齐架构；2) 针对性 KL distillation；3) 在 math/code/conv benchmark 上提升 accepted length 和 speedup。
- **工程价值**（重点分析）：**直接推理优化**（speculative decoding）。架构特定优化，但思路可泛化到新型 LLM，提升 decoding 吞吐。
- **是否值得读**：**强烈推荐**（针对新兴架构）。
- **Relevance Score**：4/5。
- **Link**：https://arxiv.org/abs/2606.26744
