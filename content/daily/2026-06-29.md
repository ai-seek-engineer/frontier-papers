### Model Inference / 推理优化
**【Title】** TOPS: First-Principles Visual Token Pruning via Constructing Token Optimal Preservation Sets for Efficient MLLM Inference

- **一句话总结**：提出训练-free、model-agnostic 的视觉 token 剪枝方法 TOPS，通过信息论三原则（任务相关性、信息覆盖、语义多样性）大幅减少 MLLM 推理中的视觉 token 开销。
- **核心贡献**（2-3点）：1) 首次从第一性原理制定 token 最优保留集问题；2) 设计可插拔剪枝模块，支持多种 MLLM backbone；3) 在 7 个 backbone + 14 个 benchmark 上验证，LLaVA-NeXT 上剪枝 77.8% token 仍保持/略超原性能，甚至缓解 hallucination。
- **工程价值**：直接适用于 MLLM 推理加速（token 量是主要瓶颈），训练-free 易集成到 vLLM/SGLang 等 serving 框架，降低 memory/compute 压力，尤其长上下文或视觉-heavy 场景。
- **是否值得读**：**强烈推荐**
- **Relevance Score**：5
- **Link**：https://arxiv.org/abs/2606.27161

**【Title】** JetSpec: Breaking the Scaling Ceiling of Speculative Decoding with Parallel Tree Drafting（HF trending 提及）

- **一句话总结**：针对传统 speculative decoding 的 scaling 瓶颈，引入并行树状 drafting 机制，进一步提升推理吞吐。
- **核心贡献**：并行化 draft 过程，突破单序列 draft 的限制；实验显示显著高于 baseline speculative 方法。
- **工程价值**：直接提升 LLM serving 吞吐，易与现有 speculative + KV cache 系统结合，适合高并发 inference 优化。
- **是否值得读**：**强烈推荐**
- **Relevance Score**：5
- **Link**：搜索 arXiv/JetSpec 或 HF papers 对应条目。

### AI Infra / 分布式训练 / 系统优化
**【Title】** DMuon: Efficient Distributed Muon Training with Near-Adam Overhead

- **一句话总结**：针对矩阵正交化优化器 Muon 在分布式训练中的高开销问题，实现高效分布式版本，使 optimizer step 时间接近 AdamW。
- **核心贡献**：1) 集成到现有 pipeline 的 drop-in 模块，无需框架大改；2) 在 embodied FM 和 LLM 训练上实现 1.48-3.01x end-to-end step speedup，optimizer step 最高 163x 加速。
- **工程价值**：Mu on 等新型优化器在 scale 时有潜力，但 infra 不匹配；DMuon 填补这一 gap，适合大规模分布式训练系统（PyTorch/DeepSpeed 等），降低训练 wall time，尤其异构或大模型场景。
- **是否值得读**：**强烈推荐**
- **Relevance Score**：5
- **Link**：https://arxiv.org/abs/2606.27153

**【Title】** RolloutPipe: Overlapping Pipelined Rollout and Training in Disaggregated On-Policy LLM Reinforcement Learning

- **一句话总结**：在 disaggregated RLVR（rollout 与 training 分离）架构中，通过 complete-group pipelining 和 frontier-group dispatch，实现 rollout-training 重叠，同时保持 on-policy 正确性。
- **核心贡献**：解决 trainer idle 问题；在 Qwen3-1.7B 等上缩短 rollout-to-train-end 时间 30-42%，大幅降低 trainer 等待比。
- **工程价值**：RLHF/RLVR 训练的关键 infra 优化，尤其 on-policy GRPO 等场景；支持异构 GPU 池，易扩展到生产级 LLM post-training 系统。
- **是否值得读**：**强烈推荐**
- **Relevance Score**：4.5
- **Link**：https://arxiv.org/abs/2606.26997

**【Title】** CHAMB-GA: A Containerized HPC Scalable Microservice-Based Framework for Genetic Algorithms（DC 相关，系统框架）

- **一句话总结**：容器化微服务框架，支持 GA + 嵌入式仿真从本地无缝扩展到 HPC/云，支持异步 manager-worker 与复杂仿真集成。
- **核心贡献**：Kubernetes 到 SLURM 迁移、水平+垂直 scaling，benchmark 达 3500+ cores 低开销。
- **工程价值**：虽非 LLM 专属，但对分布式优化/搜索任务（RL 相关 hyperparam 或进化算法）有参考价值，提供可复用 infra 模式。
- **是否值得读**：可选（若涉及进化/优化 infra）
- **Relevance Score**：3
- **Link**：https://arxiv.org/abs/2606.27217

### 额外输出

1. **今日最值得读 Top 3**（工程师视角）：
   - **1. DMuon**：分布式训练优化器 infra 突破，near-Adam 开销 + 大幅 speedup，直接可落地大规模训练。
   - **2. TOPS**：MLLM 推理 token 剪枝，训练-free、高收益，立即可用。
   - **3. RolloutPipe**：RLVR disaggregated 系统 pipeline 优化，解决实际 idle/wait 痛点，性能提升显著。

2. **今日趋势观察**：Inference 优化（token pruning、speculative）与 RL/post-training infra（disaggregated RL、优化器分布式）活跃度较高。Agent 方向有迭代效率改进，但纯系统设计的较少。分布式训练框架/overlap 技术明显增加，反映 scale 时 resource utilization 是核心痛点。

3. **值得跟进的潜在方向**：Disaggregated + pipelined RLVR 系统（rollout/training 重叠 + on-policy 保证）；视觉 token 高效处理（MLLM inference 瓶颈）；新型优化器（如 Muon）的分布式适配。这些方向结合 KV cache / batching / quantization 将有复合收益，值得持续追踪 infra 实现。 

整体今日高质量工程论文数量适中，聚焦系统瓶颈解决，值得重点跟进 inference 和 RL training 链路优化。
