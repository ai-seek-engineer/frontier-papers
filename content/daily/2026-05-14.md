### 1. Model Inference / 推理优化
**【Title】**  
KV-Fold: One-Step KV-Cache Recurrence for Long-Context Inference (arXiv近期相关，提及于最新列表)

- **一句话总结**：通过KV Cache的一步循环（recurrence）机制大幅降低长上下文推理的内存和计算开销。
- **核心贡献**（2-3点）：1) 提出KV-Fold实现one-step recurrence，避免传统KV cache线性增长；2) 针对长上下文场景优化，实验显示显著降低峰值内存；3) 与现有分页/压缩方法兼容。
- **工程价值**：**高**。直接针对KV cache瓶颈（推理serving核心痛点），适用于生产长上下文部署，可降低GPU内存压力，提升并发。易集成到vLLM/SGLang等引擎。
- **是否值得读**：**强烈推荐**（系统工程师必看）。
- **Relevance Score**：5/5
- **Link**：arXiv搜索 KV-Fold（最新列表提及）。

**【Title】**  
LEAP: Unlocking dLLM Parallelism via Lookahead Early-Convergence Token Detection (2605.10980)

- **一句话总结**：针对Diffusion LLM (dLLM)的并行解码优化，通过lookahead检测早收敛token，大幅减少denoising steps。
- **核心贡献**：1) 发现标准confidence threshold过于保守，早收敛token占比高；2) 提出training-free LEAP + multi-sequence superposition；3) GSM8K等benchmark上steps减少~30%，tokens/step达7.2。
- **工程价值**：**高**。dLLM并行潜力大，此方法plug-and-play，降低latency，适合追求高吞吐的serving系统。
- **是否值得读**：**强烈推荐**。
- **Relevance Score**：4.5/5
- **Link**：https://arxiv.org/abs/2605.10980

### 3. LLM Agents
**【Title】**  
EVOCHAMBER: Test-Time Co-evolution of Multi-Agent System at Individual, Team, and Population Scales (2605.11136)

- **一句话总结**：训练-free多代理test-time co-evolution框架，通过CODREAM等机制实现个体/团队/种群级演化，涌现专业化。
- **核心贡献**：1) 非对称知识路由+团队组装+种群lifecycle算子；2) 在math/code/reasoning基准上显著超越baseline（math +32%相对）；3) 代码开源。
- **工程价值**：**中高**。适用于落地多代理系统（工具调用、协作任务），test-time适应性强，低开销，可直接部署提升可靠性。
- **是否值得读**：**强烈推荐**（Agent系统设计者）。
- **Relevance Score**：4.5/5
- **Link**：https://arxiv.org/abs/2605.11136

**【Title】**  
OLIVIA: Online Learning via Inference-time Action Adaptation for Decision Making in LLM ReAct Agents (2605.11169)

- **一句话总结**：为ReAct代理引入inference-time contextual linear bandit，实现在线action-level适应。
- **核心贡献**：1) 将action selection建模为bandit，利用UCB探索；2) 保留底层reasoning，仅适配决策层；3) 多基准一致优于prompt/retrieval baseline。
- **工程价值**：**高**。部署中在线改进代理（减少tool waste、提升成功率），计算开销低，适合生产环境持续优化。
- **是否值得读**：**强烈推荐**。
- **Relevance Score**：4.5/5
- **Link**：https://arxiv.org/abs/2605.11169

### 4. SFT / Alignment / RLHF & Reinforcement Learning
**【Title】**  
RankQ: Offline-to-Online Reinforcement Learning via Self-Supervised Action Ranking (2605.11151)

- **一句话总结**：Offline-to-online RL通过self-supervised action ranking提升critic准确性，缓解OOD overestimation。
- **核心贡献**：1) 多term ranking loss塑造Q-function梯度；2) D4RL及vision-based robot基准SOTA或竞争；3) 低数据sim-to-real转移强（cube stacking 43%→84.7%）。
- **工程价值**：**高**。RLHF/RL post-training关键（小模型/机器人），提供稳定online fine-tuning路径，适用于资源受限场景。
- **是否值得读**：**强烈推荐**。
- **Relevance Score**：4/5
- **Link**：https://arxiv.org/abs/2605.11151

**【Title】**  
The Many Faces of On-Policy Distillation: Pitfalls, Mechanisms, and Fixes (2605.11182)

- **一句话总结**：系统分析on-policy distillation (OPD/OPSD)在math reasoning和prompt internalization中的失效机制并提出修复。
- **核心贡献**：1) 识别distribution mismatch、gradient bias、PI-free policy等问题；2) 提出stop-gradient TopK、RLVR teachers等mitigation；3) 实证不同场景适用性。
- **工程价值**：**中高**。SFT/RLHF后训练实用指南，避免常见坑，提升稳定性，有代码线索。
- **是否值得读**：**可选**（针对做distillation的团队）。
- **Relevance Score**：4/5
- **Link**：https://arxiv.org/abs/2605.11182

**【Title】**  
Rotation-Preserving Supervised Fine-Tuning (RPSFT) (2605.10973)

- **一句话总结**：通过保留pretrained singular subspaces的projected rotations，提升SFT的OOD泛化并为下游RL提供更好初始化。
- **核心贡献**：penalize不必要rotation，math reasoning等多family实验验证trade-off改善。
- **工程价值**：**中**。SFT/Alignment管道优化，简单实现，利于后续RLHF稳定性。
- **是否值得读**：**可选**。
- **Relevance Score**：3.5/5
- **Link**：https://arxiv.org/abs/2605.10973
