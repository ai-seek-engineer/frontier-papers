### 1. Model Inference / 推理优化

**【Title】**  
HCRMap: Pressure-Aware Hot-Expert Residency Mapping for 3.5D MoE Chiplet Inference

- **一句话总结**：针对MoE模型在3.5D chiplet系统上的hot-expert skew问题，提出动态hot-expert replica residency mapping框架，联合优化通信、内存和队列压力。
- **核心贡献**（2-3点）：
  - 基于hotness、加载成本、迁移开销和运行时压力的动态promote/retain/demote/evict策略。
  - Token group到resident replica的pressure-aware映射。
  - 在prefill/decode阶段相对强baseline（Hydra、MoEntwine、PIMoE）降低34-46%端到端延迟。
- **工程价值**：**高**。直接针对生产级MoE推理的系统瓶颈（异构芯片、内存分层、通信），提供可部署的动态调度机制，适用于大规模serving优化。
- **是否值得读**：**强烈推荐**
- **Relevance Score**：5
- **Link**：https://arxiv.org/abs/2607.11586

**【Title】**  
Calibrated e-CUSUM Decoding for Quantized Reasoning Models: Why Token Log-Probability Is the Wrong Observable for Decoding Monitors

- **一句话总结**：揭示量化小模型CoT退化中token log-prob的局限，提出融合不确定性和重复检测的calibrated e-CUSUM监控器，用于可靠解码干预。
- **核心贡献**（2-3点）：
  - 分析log-prob作为martingale的失效场景（重复/自信生成）。
  - Training-free degeneration-aware alarm + calibrated sequential detector。
  - 在INT4 DeepSeek-R1-Distill上改善退化检测，选择性干预下准确率有提升（统计显著性待确认），token开销可控。
- **工程价值**：**高**。量化部署中CoT可靠性的实际监控/干预方案，尤其适合edge/低bit推理场景，可集成到现有serving pipeline。
- **是否值得读**：**强烈推荐**
- **Relevance Score**：4.5
- **Link**：https://arxiv.org/abs/2607.11317

### 3. LLM Agents（有实际落地或系统设计）

**【Title】**  
StructAgent: Harness Long-horizon Digital Agents with Unified Causal Structure

- **一句话总结**：为长时序计算机使用代理引入unified causal state表示和verifier-backed workflow，实现checkpoint、recovery和可验证执行，大幅提升OSWorld等benchmark成功率。
- **核心贡献**（2-3点）：
  - State-centered框架：compact verifiable progress + structured transitions。
  - 支持explicit checkpointing、evidence-driven completion、targeted recovery。
  - 在Qwen系列上成功率提升显著（9B: +19.9pp，27B: +30.6pp），开源SOTA达78.9%，并泛化到Minecraft。
- **工程价值**：**高**。解决真实长horizon agent的state管理与可靠性问题，提供可工程化的causal structure设计，适合生产级digital agent部署。
- **是否值得读**：**强烈推荐**
- **Relevance Score**：5
- **Link**：https://arxiv.org/abs/2607.11388

**【Title】**  
Compile, Then Page: Executable SOP Programs and a Capability-Gated Runtime for Procedural LLM Agents

- **一句话总结**：将SOP编译为executable pseudo-code，结合program-guided stack machine（active-frame paging）和capability-gated runtime，提升企业级procedural agent的long-horizon可靠性。
- **核心贡献**（2-3点）：
  - SOP编译 + PG runtime分离表示与执行。
  - Capability-gated设计（强模型受益，弱模型避免伤害），cursor ablation验证state discipline重要性。
  - 在SOPBench/Bank任务上显著提升成功率和refusal正确性。
- **工程价值**：**高**。企业SOP agent的实用工程方案，强调编译时结构化和运行时控制，易于集成到现有LLM agent框架。
- **是否值得读**：**强烈推荐**
- **Relevance Score**：4.5
- **Link**：https://arxiv.org/abs/2607.11346

**【Title】**  
OpsMem: Dual-Memory Reasoning with Cross-Memory Resonance for Failure Diagnosis

- **一句话总结**：双内存（short-term diagnostic state + long-term operational experience）+ cross-resonance机制，提升LLM-based微服务故障诊断的迭代推理能力。
- **核心贡献**（2-3点）：
  - 跨内存激活与多agent条件推理。
  - 从解决incident中consolidate经验回long-term memory。
  - 在真实Huawei数据集上显著优于agentic/knowledge-augmented baselines（Match +46.88%）。
- **工程价值**：**中高**。Ops领域的实际agent系统优化，memory管理机制对SRE/诊断agent有直接借鉴价值。
- **是否值得读**：**推荐**
- **Relevance Score**：4
- **Link**：https://arxiv.org/abs/2607.11357

### 5. Reinforcement Learning

**【Title】**  
Learning Residual Kinematic Corrections for Continuous Neural Decoding via Reinforcement Learning

- **一句话总结**：两阶段框架：CNN-LSTM基础解码 + offline RL残差运动校正，提升EEG-based BCI连续运动解码准确性。
- **核心贡献**（2-3点）：
  - RL agent仅基于预测轨迹进行residual correction，无需额外EEG输入。
  - 2D/VR场景下correlation提升21-41%，RMSE降低38-40%。
  - Scalable offline训练，适用于neurorehab/prosthetics。
- **工程价值**：**中**。RL在连续控制/校正中的实用应用，对BCI系统工程有参考，但领域较niche。
- **是否值得读**：**可选**（若涉及RL+控制）
- **Relevance Score**：3.5
- **Link**：https://arxiv.org/abs/2607.11530
