### Inference / KV Cache / Quantization

**【Title】**  
GSRQ: Gain-Shape Residual Quantization for Sub-1-bit KV Cache

- **一句话总结**：针对RQ在高维下的centroid shrinkage问题，提出Gain-Shape K-means改进残差量化，实现sub-1-bit KV cache有效压缩，同时大幅提升长上下文任务准确率。
- **核心贡献（2-3点）**：1) GSKM替代标准K-means，提升方向保真度（angular alignment）；2) 集成到RQ pipeline，支持加权扩展；3) 在LLaMA-3-8B + LongBench上，1-bit下平均准确率从11.34%提升到33.54%（+22.2 pts vs VQLLM baseline）。
- **工程价值**：直接用于生产推理引擎的KV cache压缩，显著降低长上下文内存占用，同时缓解量化导致的性能崩坏；易集成到vLLM/HF等框架，有代码潜力（ICML 2026）。
- **是否值得读**：**强烈推荐**（高实用性）。
- **Relevance Score**：5/5
- **Link**：https://arxiv.org/abs/2607.01065

**【Title】**  
MosaicKV: Serving Long-Context LLM with Dynamic Two-D KV Cache Compression（相关近期提交）

- **一句话总结**：动态二维KV cache压缩策略，支持长上下文服务。
- **核心贡献**：动态压缩机制，平衡内存与准确性。
- **工程价值**：生产serving优化，长上下文部署关键；系统级调度价值高。
- **是否值得读**：**强烈推荐**。
- **Relevance Score**：4.5/5
- **Link**：arXiv搜索MosaicKV（近期cs.LG）。

### AI Infra / Distributed / RLHF

**【Title】**  
Staleness-Learning Rate Scaling Laws for Asynchronous RLHF

- **一句话总结**：针对异步GRPO训练中的staleness问题，建立local理论框架和scaling laws，指导学习率调整以维持训练稳定性。
- **核心贡献**：1) Staleness-LR交互理论分析；2) Scaling laws支持异步大规模训练；3) 实验验证在分布式RLHF中的有效性。
- **工程价值**：直接提升分布式训练效率和稳定性，尤其多GPU/异步设置下的RLHF/SFT pipeline；对infra调度和通信优化有指导意义。
- **是否值得读**：**强烈推荐**。
- **Relevance Score**：4.5/5
- **Link**：https://arxiv.org/abs/2607.01083

**【Title】**  
Is One Layer Enough? Training A Single Transformer Layer Can Match Full-Parameter RL Training

- **一句话总结**：通过层级消融发现RL后训练收益高度集中在少数（甚至单）中间层，训练单层即可接近全参数效果。
- **核心贡献**：1) 系统层贡献度量化；2) 跨模型/算法/任务的稳定模式验证（中间层主导）；3) 实验覆盖Qwen系列、GRPO等。
- **工程价值**：极大降低RL/SFT/RLHF的训练成本（参数更新、内存、时间）；可用于selective layer tuning、混合精度infra优化，生产部署高ROI。
- **是否值得读**：**强烈推荐**（ paradigm shift级别洞见）。
- **Relevance Score**：5/5
- **Link**：https://arxiv.org/abs/2607.01232

### LLM Agents / RL

**【Title】**  
Self-GC: Self-Governing Context for Long-Horizon LLM Agents

- **一句话总结**：为长时序Agent设计自治理上下文机制，像GC一样管理token/工具/技能生命周期，支持长horizon规划。
- **核心贡献**：将上下文转为可索引对象 + side-channel planner进行fold/mask/prune；显著提升长horizon稳定性。
- **工程价值**：直接解决Agent实际落地中的上下文爆炸和漂移问题；适用于生产Agent系统（工具调用、multi-step），系统设计强。
- **是否值得读**：**强烈推荐**。
- **Relevance Score**：4.5/5
- **Link**：https://arxiv.org/abs/2607.00692
