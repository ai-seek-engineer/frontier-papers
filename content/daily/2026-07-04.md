### Model Inference / 推理优化（KV cache 等）
**【Title】** GSRQ: Gain–Shape Residual Quantization for Sub-1-bit KV Cache (arXiv:2607.01065)

- **一句话总结**：针对KV cache 亚1-bit量化，提出Gain-Shape K-means改进残差量化，显著提升长上下文LLM推理的内存效率和精度。
- **核心贡献**：(1) GSKM替换标准K-means，解决高维质心收缩问题，提升方向保真度；(2) 集成到RQ pipeline，形成GSRQ；(3) 在LLaMA-3-8B上，LongBench平均准确率从11.34提升至33.54（1-bit下）。
- **工程价值**：直接适用于生产级长上下文推理部署，降低KV cache 内存占用，支持更大batch/上下文，同时有实验benchmark和ICML 2026接受，复现性高（标准量化 pipeline）。
- **是否值得读**：**强烈推荐**
- **Relevance Score**：5
- **Link**：https://arxiv.org/abs/2607.01065

**【Title】** MosaicKV: Serving Long-Context LLM with Dynamic Two-D KV Cache Compression (arXiv:2607.00760)

- **一句话总结**：动态二维（序列+通道）KV cache压缩系统，利用非均匀重要性动态分段压缩，兼顾内存和计算效率。
- **核心贡献**：(1) 动态two-D压缩 + 重要性感知分段选择；(2) 压缩KV cache管理，利用CPU/GPU异构加速attention；(3) H800上实现3x内存节省、16x attention speedup、4.8x decode latency降低，LongBench/RULER仅1.76%损失。
- **工程价值**：生产serving强相关，解决长上下文（百万token）下的内存瓶颈和throughput问题，可直接集成到vLLM/HF serving栈。
- **是否值得读**：**强烈推荐**
- **Relevance Score**：5
- **Link**：https://arxiv.org/abs/2607.00760

**【Title】** The risk of KV cache compression (arXiv:2607.01520)

- **一句话总结**：从minimax risk理论视角分析KV cache压缩的可行性，提供因果掩码下的最优设计原则和实用算法。
- **核心贡献**：理论刻画cache内在可压缩性；提出pre-fill/decode适配的最优压缩算法；在LongBench上有实证支持。
- **工程价值**：为KV cache压缩提供理论指导，避免盲目经验调优；适用于长序列serving的稳定性分析。
- **是否值得读**：**强烈推荐**（理论+实践结合）
- **Relevance Score**：4
- **Link**：https://arxiv.org/abs/2607.01520

### LLM Agents / RL
**【Title】** Next-Generation Agentic Reinforcement Learning Systems Enable Self-Evolving Agents (arXiv:2607.01120)

- **一句话总结**：针对企业级agent在线RL系统痛点，提出标准化轨迹协议、数据proxy和演化控制平面，支持自进化agent部署。
- **核心贡献**：(1) 识别当前agentic RL系统在轨迹数据、observability、控制平面上的不足；(2) 设计AReaL2.0等架构实例；(3) 强调从部署负载中在线学习而非离线fine-tune。
- **工程价值**：直接指向生产agent系统的可扩展演化（coding/support/research agents），解决静态部署后的迭代难题，有系统设计和case studies。
- **是否值得读**：**强烈推荐**
- **Relevance Score**：5
- **Link**：https://arxiv.org/abs/2607.01120

**【Title】** AgenticSTS: A Bounded-Memory Testbed for Long-Horizon LLM Agents (arXiv:2607.02255)

- **一句话总结**：引入有界内存契约（typed retrieval而非全历史append）的long-horizon agent测试床，在Slay the Spire 2上验证内存层影响。
- **核心贡献**：(1) Bounded prompt设计，便于ablating单个memory/skill层；(2) 发布298条轨迹数据集和分析工具；(3) 展示strategic skill层带来的win rate提升。
- **工程价值**：为long-horizon agent提供可复现的系统评估框架，助力内存/状态管理优化（生产中关键）。
- **是否值得读**：**强烈推荐**（工程测试床价值高）
- **Relevance Score**：4
- **Link**：https://arxiv.org/abs/2607.02255

**【Title】** Visually Grounded Self-Reflection for Vision-Language Models via Reinforcement Learning (arXiv:2607.02490)

- **一句话总结**：VRRL框架通过masked trajectory和experience replay强化VLM的自反射，改善OOD视觉 grounding。
- **核心贡献**：RL训练技巧提升视觉-grounded correction；多benchmark上显著优于标准RL/反射fine-tune。
- **工程价值**：适用于多模态agent的推理稳定性（reflection是agent loop核心），RLHF-like训练方法可迁移。
- **是否值得读**：**可选**（偏VLM，但RL方法有借鉴）
- **Relevance Score**：3
- **Link**：https://arxiv.org/abs/2607.02490

**【Title】** ReContext: Recursive Evidence Replay as LLM Harness for Long-Context Reasoning (arXiv:2607.02509)

- **一句话总结**：无训练inference方法，通过递归evidence replay提升长上下文证据利用率。
- **核心贡献**：基于模型内部信号构建query-conditioned pool并replay；理论关联记忆分析；多backbone上SOTA-like提升。
- **工程价值**：serving端即插即用优化长上下文agent推理，无需retrain。
- **是否值得读**：**可选**
- **Relevance Score**：4
- **Link**：https://arxiv.org/abs/2607.02509
