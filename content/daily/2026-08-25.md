### 1. Model Inference / 推理优化

**【Title】** OasisKV: Scaling In-Decode KV Cache Beyond HBM with Lookahead Sparse Prefetching  
- 一句话总结：利用 speculative decoding 的 lookahead token 预测未来重要 KV block，从 host/remote memory 异步 prefetch 到 HBM，实现 decode 阶段稀疏 attention。  
- 核心贡献：  
  1. 将 full KV 与 HBM 解耦，只保留相关 token 的 KV 在 HBM。  
  2. 复用 SD draft tokens 做训练免费的未来访问预测 + 后台 pipeline。  
  3. 基于 vLLM 实现，准确率损失 ≤0.7 点（2k KV budget）。  
- 工程价值：直接可落地于现有 serving（vLLM），长上下文 + 大 batch 下 1.69×（reasoning）~2.1×（multi-GPU）吞吐提升；PD disaggregation 下显著降低 per-request KV 传输与 decode 节点 host memory。对 HBM 瓶颈场景极实用。  
- 是否值得读：强烈推荐  
- Relevance Score：5  
- Link：https://arxiv.org/abs/2608.08097  

**【Title】** Self-Pruned Key-Value Attention: Learning When to Write by Predicting Future Utility  
- 一句话总结：端到端训练轻量 utility predictor，动态决定哪些 KV 写入 persistent cache（sparse-write），而非固定压缩比。  
- 核心贡献：  
  1. 联合 next-token loss 训练 LLM + predictor，无需额外监督。  
  2. 动态 sparsification（通常 3–10× 压缩，长序列更可压）。  
  3. 揭示 layer/head 级结构化稀疏模式，可指导 hybrid local-global attention 设计。  
- 工程价值：内存与带宽双降，解码加速明显；从预训练 checkpoint 适配，对长上下文 serving 有直接增益，但需要模型侧改动（非纯系统层）。  
- 是否值得读：可选（系统工程师可跳过细节，关注稀疏模式洞察）  
- Relevance Score：4  
- Link：https://arxiv.org/abs/2605.14037  

### 2. AI Infra / 系统优化

**【Title】** From LLM Inference to Agentic Workloads: Characterization and Implications for Serving Systems  
- 一句话总结：系统级刻画 agentic 工作负载（工具调用、环境交互、持久状态）与传统 LLM inference 的差异，并给出可行动的 serving 优化。  
- 核心贡献：  
  1. 识别 6 大特性（非 LLM 组件主导延迟、异构资源亲和、瓶颈动态迁移、高状态内存等）。  
  2. AgentSysBench + 生产 trace 测量。  
  3. 验证 task-aware serving（29–40% 延迟降）、communication-aware placement（最高 4.5×）、state offloading（4.6× 内存）、tool-result caching。  
- 工程价值：极高。Agent 从 “单次 inference” 转向 “长运行 stateful 工作负载”，现有 vLLM/SGLang 等假设失效。对调度、placement、缓存、disaggregation 设计有直接指导。  
- 是否值得读：强烈推荐  
- Relevance Score：5  
- Link：https://arxiv.org/abs/2608.15127  

**【Title】** Efficient Speculative Decoding for Llama at Scale: Challenges and Solutions  
- 一句话总结：大规模（到 405B 级）Llama 上部署 speculative decoding 的工程挑战与系统解法。  
- 核心贡献：  
  1. 分析 batch size / 模型规模对 SD speedup 的非单调影响（小模型大 batch 反而更好）。  
  2. 生产级实现细节与 benchmark。  
- 工程价值：SD 已成标准加速手段，大规模真实部署经验（尤其与 continuous batching、长上下文交互）对 infra 团队有参考价值。  
- 是否值得读：可选  
- Relevance Score：3.5  
- Link：https://arxiv.org/html/2508.08192  

### 3. LLM Agents（系统设计 / 落地向）

**【Title】** Scaling Test-time Compute for LLM Agents  
- 一句话总结：系统探索 test-time scaling（并行采样、序列修订、verifier/merge、多样化 rollout）在 language agents 上的效果与设计要点。  
- 核心贡献：  
  1. 首次较完整 ablation TTS 在 agent 场景的影响。  
  2. 关键：知道何时 reflect 很重要；list-wise merge 最好；多样化 rollout 正向。  
- 工程价值：Agent 推理成本与延迟控制直接相关。对 production agent harness 的采样策略、verifier 设计有实用参考。  
- 是否值得读：可选（有代码线索）  
- Relevance Score：4  
- Link：https://arxiv.org/abs/2506.12928  

**【Title】** What Does It Take to Be a Good AI Research Agent? Studying the Role of Ideation Diversity  
- 一句话总结：大规模分析（~11k trajectories）ML research agents 的 ideation diversity 对性能的影响，并做控制实验。  
- 核心贡献：  
  1. 量化/控制 ideation diversity 的方法。  
  2. 更高 diversity → 更强性能；跨 scaffold 与 backbone 验证。  
- 工程价值：对 research-agent / coding-agent 的探索策略设计有指导；偏分析，落地需额外工程。  
- 是否值得读：可选  
- Relevance Score：3.5  
- Link：https://arxiv.org/html/2511.15593v1  

### 4. SFT / Alignment / RLHF & 5. RL（合并筛选）

**【Title】** SWEET-RL: Training Multi-Turn LLM Agents on Collaborative Reasoning Tasks  
- 一句话总结：针对 multi-turn collaborative agent 的 step-wise credit assignment RL 算法 + 新 benchmark ColBench。  
- 核心贡献：

- 工程价值：multi-turn agent 训练的核心痛点（credit assignment）有实际提升，适合 agent post-training pipeline。  
- 是否值得读：可选  
- Relevance Score：3.5

### 【额外输出】

**1. 今日最值得读 Top 3**  
1. **OasisKV** — 直接解决当前最痛的 HBM + 长上下文 decode 瓶颈，vLLM 集成 + 明确吞吐数字，工程可复现性高。  
2. **From LLM Inference to Agentic Workloads** — 首次系统刻画 agentic 工作负载特性，并给出可落地的 serving 改动，对 2026 下半年 infra 方向有风向标意义。  
3. **Self-Pruned KV / Scaling TTS for Agents**（并列） — 前者给出模型侧稀疏新范式，后者给 agent 侧 test-time 工程 knobs。

**2. 今日趋势观察**  
Inference 优化（尤其 KV cache 管理 + speculative decoding 协同）继续占主导，且从纯量化/压缩转向 **system-aware + 与 SD 深度耦合** 的方向。Agent 相关论文明显增多，但高质量“系统设计 + 测量”类仍稀缺；纯算法 agent 论文仍占多数。

**3. 值得跟进的潜在方向**  
- **Agentic serving 特性驱动的调度与缓存**：非 LLM 组件延迟主导 + 异构资源 + 高状态内存 → 需要新的 continuous batching / placement / offload 策略（已有初步证据）。  
- **SD-guided sparse KV prefetch / eviction**：把 speculative draft 当成免费的未来访问 oracle，可能成为下一代长上下文 serving 标准组件。  
- **Harness-level control（而非纯模型 RL）**：把 prompt/tool/memory/verifier 当作可学习的小动作空间，用轻量 RL 在线优化，更适合 black-box API + 生产可审计性。
