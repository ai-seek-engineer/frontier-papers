## 1. Inference

【Title】AceSpec: An Asymmetric Edge-Cloud Collaborative Framework for Communication-Efficient LLM Inference  
- 一句话总结：把边云 speculative decoding 的拒绝回滚，从全链路 flush 变成端侧 O(1) 状态缓存查找，弱网也能接近峰值吞吐。  
- 核心贡献：  
  1. 用不饱和的边缘算力预建概率状态 cache，拒绝不再触发全网 pipeline stall。  
  2. 非对称协议：上行只传主链 index，下行传稀疏分布。  
  3. 网络感知的拉格朗日资源分配，动态抬本地 cache hit。  
- 工程价值：直接可落地到 edge-cloud serving；50 Kbps WAN 下仍接近峰值，最高 **3.52×** 吞吐。比拆模型/纯压缩更贴真实 WAN。无公开代码。  
- 是否值得读：强烈推荐  
- Relevance Score：5  
- Link：https://arxiv.org/abs/2609.02514

【Title】Language Models Can Control Their Own Attention  
- 一句话总结：让模型在 CoT 里声明 `<global>/<focus>/<local>`，推理引擎当 tool call 解析，跳过大部分 KV 读。  
- 核心贡献：  
  1. Declarative Attention：稀疏注意力由模型自己声明，而不是每步 O(N) proxy score。  
  2. 现成模型零样本可用（Gemma-4-31B、Qwen-3.6-27B）。  
  3. 15 个长上下文任务：attended tokens 降 **52.0% / 31.1%**，准确率掉 1.27 / 2.75 pp，大模型掉得更少。  
- 工程价值：给长上下文 decode 一条新轴——不必改注意力核，只要引擎能 parse 声明并裁 KV 扫描。训练对齐后潜力更大；现在还缺生产级 kernel 集成。  
- 是否值得读：强烈推荐  
- Relevance Score：5  
- Link：https://arxiv.org/abs/2609.02737

## 2. AI Infra / 分布式

【Title】AInfer-PD: Communication-Safe In-Place Prefill-Decode Multiplexing for Distributed MoE Rollouts  
- 一句话总结：Agentic RL 的 rollout 里 P/D 长期共存；给分布式 MoE 的 in-place P/D 补上通信隔离，避免拆池子搬 KV。  
- 核心贡献：  
  1. 跨 rank 协调 P/D collective 顺序，DeepEP P/D 路径独立通信状态。  
  2. 同卡共享权重和 KV，不做 P/D disaggregation。  
  3. 相对同引擎关 multiplexing：**7–22%**（单节点）/ **18–35%**（两节点）缩短 rollout；相对 SGLang **~25–33%**；细粒度边界再挤 **8–20%**。  
- 工程价值：verl/SGLang/DeepEP 栈上的真痛点。Agentic RL 多轮环境交互会持续插入 prefill，P/D 拆分成本高，这篇是可直接跟进的系统补丁。  
- 是否值得读：强烈推荐  
- Relevance Score：5  
- Link：https://arxiv.org/abs/2609.00993

【Title】UE5M3 FP4 Block Scaling for Stable Language Model Pretraining  
- 一句话总结：用 UE5M3 block scale + E2M1 payload 做 FP4 预训练，去掉 TE NVFP4 的 RHT 和 BF16 末层豁免，更稳也更快。  
- 核心贡献：  
  1. 更宽的 unsigned E5M3 scale 允许周期性 tensor scaling，不必 current-tensor + RHT。  
  2. 反向梯度选择性随机舍入；内部 linear 全走 FP4。  
  3. Nemotron-H 8B、~190B token：最终窗 loss / 验证 NLL 优于 TE NVFP4；去掉 RHT+BF16 豁免后 body 吞吐 **+21.2%**。  
- 工程价值：训练侧量化配方，指向硬件/TE 应原生支持 UE block scaling。对推理栈是间接价值（更干净的 FP4 权重路径）。  
- 是否值得读：可选（做预训练/低精度训练必读）  
- Relevance Score：4  
- Link：https://arxiv.org/abs/2609.02846

## 3. LLM Agents

【Title】EarlyEval: Cheaper Agent Evaluation via Early Outcome Prediction  
- 一句话总结：用轻量分类器从中间行为预测成败，提前停评测 run，砍评测账单而不是砍题集。  
- 核心贡献：  
  1. 行为 + 文本 + reference 特征，一对 LightGBM success/fail，校准阈值停跑。  
  2. SWE-bench Verified / TerminalBench / Toolathlon：步数 **-13%~-26%**，input token 最高 **-44.1%**，output **-29.4%**，准确率 89–97%。  
  3. 各 agent resolve rate 平均只偏 1–2 pp。有代码。  
- 工程价值：评测 infra 立刻能用。开发迭代里同一套 bench 要跑很多遍，这比蒸馏题集更正交。  
- 是否值得读：强烈推荐  
- Relevance Score：4  
- Link：https://arxiv.org/abs/2609.02783  
- Code：https://github.com/inphotoo/earlyeval

【Title】Coverage, Not Targeting: A Structural Regime in Multi-Turn Agent Credit Assignment  
- 一句话总结：终端可验证奖励下，按“关键 turn”打分往往是错轴；缺的是覆盖整条因果链，不是更准的 targeting。  
- 核心贡献：  
  1. 定义 verifier 信息密度 \(V_d=k/C\)；终端 verifier 实测 \(V_d\sim0.15\)（tau²-bench）、\(\sim0.4\)（BFCL）。  
  2. 同 rollout 对照：均匀稠密奖励赢；把同样优势打到 progress turn 或随机 turn 一样有害。  
  3. 提出 targeting 论文必须过的 matched-concentration shuffled control。  
- 工程价值：别急着上复杂 process RM / turn-level credit。先把奖励铺到整条 tool chain。改 agent RL 奖励设计比改调度更前置。  
- 是否值得读：强烈推荐（做 agent RL 必看）  
- Relevance Score：5  
- Link：https://arxiv.org/abs/2609.02417

## 4. SFT / Alignment / RLHF + RL

【Title】Cliff: Learning Process Rewards from the First Mistake  
- 一句话总结：用现成 teacher 标出 rollout 第一次出错位置，正确前缀正优势、之后负优势，给 RLVR 细粒度监督。  
- 核心贡献：  
  1. 不训 PRM、不假设师生推理同构。  
  2. 12 场景：相对 GRPO **+7%**，相对 on-policy distillation **+15%**；弱 teacher 也有效。  
  3. 分析了 “ground truth” 在 Cliff 里的角色和训练动态。  
- 工程价值：可挂到现有 GRPO/RLVR 流水线，多一次 teacher 扫描。比训过程奖励模型便宜。Teacher 误标第一错误点会污染优势。  
- 是否值得读：强烈推荐  
- Relevance Score：5  
- Link：https://arxiv.org/abs/2609.02817

【Title】Post-Training Language Models for Gold-Medal Performance in Coding Competitions  
- 一句话总结：大规模题库 + 合成推理 + SFT/RL + 测试时 GenCorrect，做出超人类 IOI 2026 的竞赛系统。  
- 核心贡献：  
  1. 2.2 万题；Nano-CC（30B-A3B）SFT+RL，Ultra-CC（550B-A55B）只 SFT。  
  2. GenCorrect：生成–评测–改写的测试时循环。  
  3. IOI 2025：Nano 130→291→468（金牌线 438）；IOI 2026 现场约束下 Ultra 系统 **535.4/600**，高于金牌线 361 和人类第一 498。  
- 工程价值：方法组合不新，但是完整的竞赛后训练 + TTC 工程样板（数据、评测环、提交约束）。算力门槛极高，中小团队跟流程不跟模型。  
- 是否值得读：可选  
- Relevance Score：4  
- Link：https://arxiv.org/abs/2609.02849

## 额外输出

### 1. 今日最值得读 Top 3

1. **AInfer-PD** — Agentic RL 的墙钟时间就是 rollout；P/D 在同一 MoE 集群上长期共存是生产现实，这篇把通信安全做对了，数字直接对比 SGLang。  
2. **AceSpec** — speculative decoding 从机房假设走到 WAN；拒绝回滚的系统处理比再做一个 draft 模型更有用。  
3. **Cliff + Coverage（并列第三，按你岗位二选一）**  
   - 做 RLVR/对齐：读 Cliff，奖励塑形改动小、增益清楚。  
   - 做 multi-turn agent：读 Coverage，避免在低 \(V_d\) 上堆 targeting。

### 2. 今日趋势观察

- **推理 × RL rollout 合流**：优化对象从“在线 chat serving”扩到“RL/agent rollout 的 P/D 共存、KV、通信”。AInfer-PD 是典型。  
- **稀疏注意力从启发式转向模型内建声明**：Declarative Attention 把“读哪些 KV”当成模型输出协议。  
- **Agent 工作从“更强 targeting”转向“覆盖与评测成本”**：Coverage 否定盲目 turn-level credit；EarlyEval 砍评测执行成本。  
- 纯新 KV 压缩算法今天不多；系统集成和通信协议占比更高。

### 3. 值得跟进的潜在方向

1. **In-place P/D multiplexing + 分布式 MoE 通信隔离**（DeepEP/ATP/ADP 交叉 collective）——训练集群和推理集群都会碰到。  
2. **模型声明式 KV/attention 控制**（DA 协议 + 引擎 parse）——比再训一个 evictor 更接近产品接口。  
3. **边云 speculative 的状态缓存，而不是更大 draft** ——弱网/端侧部署的正确抽象。  
4. **Agent 奖励：先提高 verifier 覆盖 \(V_d\)，再谈 targeting** ——和 Cliff 的“第一错误点”可以组合成更便宜的过程监督。  
5. **FP4 预训练配方简化（UE5M3 block scale）** ——跟硬件 vendor / TE 路线对齐，值得盯 native kernel。
