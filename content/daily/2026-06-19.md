### Model Inference / KV Cache / Quantization

**【Title】** From Tokens to Energy Flexibility: Quantization-Enabled Demand Response for Data Centers with LLM Inference Workloads (arXiv:2606.18851, 17 Jun)

- **一句话总结**：将模型量化作为灵活资源，用于数据中心 LLM 推理的电网需求响应（DR），在不减少服务 token 量前提下显著降低运营成本。
- **核心贡献**（2-3点）：
  - 构建量化-to-power 映射模型，将不同精度配置转为可调度的功率参数。
  - 两阶段 DR 模型整合实例切换、请求路由和精度选择。
  - 多园区协同优化，结合电网信号实现成本/碳优化。
- **工程价值**：高。直接针对生产环境推理负载，提供量化驱动的动态功率管理，在电网约束下优化 infra 成本；对大规模部署的能耗/成本敏感场景（如云服务）有落地潜力，实验显示 34.3% 成本降低且 token 吞吐不变。
- **是否值得读**：**强烈推荐**（系统级优化 + 真实约束）。
- **Relevance Score**：5/5
- **Link**：https://arxiv.org/abs/2606.18851

**【Title】** ARIADNE: Agnostic Routing for Inference-time Adapter DyNamic sElection (arXiv:2606.19079, ~18 Jun)

- **一句话总结**：推理时动态路由选择适配器，提升多适配器 LLM 服务的效率和灵活性。
- **核心贡献**：
  - 无关路由机制，支持动态适配器选择。
  - 针对推理时多任务/个性化场景优化。
- **工程价值**：中等-高。适用于 serving 系统中多 LoRA/适配器场景，能减少切换开销和内存压力；对生产多租户或个性化部署有直接帮助。
- **是否值得读**：**可选**（路由优化实用，但细节需看实验）。
- **Relevance Score**：4/5
- **Link**：https://arxiv.org/abs/2606.19079

### LLM Agents / RL / Alignment

**【Title】** UBP2: Uncertainty-Balanced Preference Planning for Efficient Preference-based Reinforcement Learning (arXiv:2606.19328, 18 Jun)

- **一句话总结**：不确定性平衡的偏好规划，提升基于偏好的 RL 效率，适用于 LLM 对齐/代理训练。
- **核心贡献**：
  - 平衡不确定性与偏好规划，减少样本/计算需求。
  - 实验验证在 RL 场景的稳定性和效率提升。
- **工程价值**：高。对 RLHF/SFT 后训练或代理策略优化有价值，尤其在样本昂贵或在线 RL 场景；可降低训练成本并提升稳定性。
- **是否值得读**：**强烈推荐**（偏好 RL 工程优化）。
- **Relevance Score**：4.5/5
- **Link**：https://arxiv.org/abs/2606.19328

**【Title】** RODS: Reward-Driven Online Data Synthesis for Multi-Turn Tool-Use Agents (arXiv:2606.19047, ~18 Jun)

- **一句话总结**：奖励驱动的在线数据合成，针对多轮工具使用代理的训练数据生成。
- **核心贡献**：
  - 在线合成高质量多轮交互数据。
  - 提升代理工具使用和长时序性能。
- **工程价值**：高。直接解决代理训练数据稀缺/质量问题，支持实际落地多轮 Agent 系统；与 RL 结合潜力大。
- **是否值得读**：**强烈推荐**。
- **Relevance Score**：4.5/5
- **Link**：https://arxiv.org/abs/2606.19047

**其他方向简要**：今日 RL 相关（如 STARE surprisal-guided token reweighting）有几篇，但多为算法微调，工程系统价值有限，未达入选门槛。Agent benchmark（如 CEO-Bench 长时序）较多，但偏评估而非方法创新/系统优化。

### 额外输出

**1. 今日最值得读 Top 3（按工程优先）**：
- **1. Quantization-Enabled Demand Response**：系统级 infra 优化，量化作为灵活资源直接映射到真实数据中心成本/电网约束，实验支撑强，立即可思考生产部署。
- **2. UBP2 (Preference-based RL)**：高效偏好 RL，降低训练开销，对 Alignment/Agent 训练管道有普适价值。
- **3. RODS (Online Data Synthesis for Agents)**：解决多轮 Agent 数据瓶颈，奖励驱动在线方法实用性高。

**2. 今日趋势观察**：Inference 方向（尤其是量化+系统能耗/DR）有明显实用信号；Agent 多为 benchmark/评估，少见强系统设计创新；RL 偏好规划/在线合成持续活跃，但纯算法居多。整体偏“落地约束下的优化”（能耗、在线、多轮）而非纯 scaling。

**3. 值得跟进的潜在方向**：量化驱动的“动态资源灵活性”（energy/ memory/ compute）在 inference infra 中的扩展，尤其结合分布式 serving 和 Agent 长轨迹 KV 管理；不确定性-aware 的在线 RL 数据合成 pipeline 可能成为 Agent 训练新范式。建议持续追踪数据中心级 LLM serving + RL 混合系统。
