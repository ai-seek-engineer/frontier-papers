### 【Title】TokTier: Exact Stateful Tokenization for Agentic LLM Serving
- 一句话总结：为 Agent 场景设计的精确有状态分词服务，解决长 transcript 重复分词成为 TTFT 瓶颈的问题。
- 核心贡献（2-3点）：
  - 增量修复协议：仅对 append 窗口做局部 re-tokenize + 稳定边界检查，保证与全量分词 ID 完全一致。
  - GPU 加速全量分词 + 采样 shadow verifier，覆盖 17 个 tokenizer 家族零发散。
  - 实测在真实 Agent 调用 trace 上，增量修复 0.5–1.1 ms（100K–3M 字符），相对 HF 最高 437×，配合 vLLM 中位数 TTFT 降 16–34%。
- 工程价值：Agent 工作负载（频繁短 append）下分词已占 TTFT 64%。可直接挂在 vLLM / 现有 serving 前端，显著降低 coding agent 延迟与 CPU 压力，几乎无副作用。
- 是否值得读：强烈推荐
- Relevance Score：5
- Link：https://arxiv.org/abs/2607.29678

### 【Title】SLIM: Saturation-Aware Lightweight Performance Modeling for LLM Serving
- 一句话总结：半解析性能模型 + Batching Configuration Advisor，精准刻画 decode 阶段 attention kernel 的吞吐饱和点。
- 核心贡献（2-3点）：
  - 硬件 profiling 证明饱和主因是 decode attention 的近恒定 arithmetic intensity 导致 DRAM 带宽打满，而非简单 batch size。
  - SLIM 模型从 Transformer 计算与内存流量解析公式预测吞吐/延迟，优于现有 baseline 并泛化到未见配置。
  - BCA 能在目标延迟约束下推荐最高吞吐 batch 配置，对 OPT 系列可避免最多 55 GB 显存分配且几乎无损吞吐。
- 工程价值：直接服务生产调度与容量规划。可嵌入现有 serving 系统做在线/离线配置推荐，减少过度配显存与无效大 batch。
- 是否值得读：强烈推荐
- Relevance Score：5
- Link：https://arxiv.org/abs/2607.29575

### 【Title】DeltaServe: Host-Agnostic Co-Serving of Inference and Fine-Tuning for LLMs
- 一句话总结：利用推理空闲算力做 LoRA 微调的共服务框架，严格保证推理 SLO。
- 核心贡献（2-3点）：
  - 仅需 multi-LoRA batching 支持的轻量 hook，兼容 vLLM / SGLang / S-LoRA。
  - SLO-aware 调度器 + CUDA-graph 感知延迟模型（离线校准 + 在线精炼），仅在推理有足够余量时准入微调。
  - 生产 trace 上相对 LLMStation 达到 2.9× 微调吞吐且 100% 推理 SLO 合规（对比对方 85%）。
- 工程价值：高峰预留导致的空闲 GPU 可被回收做持续 SFT/适配，无需额外硬件。对私有化/企业多租户 serving 极具实用价值。
- 是否值得读：强烈推荐
- Relevance Score：5
- Link：https://arxiv.org/abs/2607.28848

### 【Title】SmartGen: Seamless Disaggregated LLM Inference with Selective KV Cache Transfer
- 一句话总结：面向云租用实例的 prefill-decode 解耦，通过选择性 KV 传输缓解跨节点带宽瓶颈。
- 核心贡献（2-3点）：
  - 三条传输路径：profile-based 主动推送关键 KV、并行 on-demand 拉取、投机全量补齐。
  - 在 prefill 阶段准确选出关键 KV，decode 阶段高效远程+本地混合获取。
  - TTST 最高降低 4.3×，后续 decode 性能与精度基本持平。
- 工程价值：自建/租用云场景下网络带宽常是瓶颈。可直接降低解耦部署的通信成本，适合中小规模集群。
- 是否值得读：可选
- Relevance Score：4
- Link：https://arxiv.org/abs/2607.28150

### 【Title】GyRot: Leveraging Hidden Synergy between Rotation and Fine-grained Group Quantization for Low-bit LLM Inference
- 一句话总结：算法-硬件协同的 4-bit 量化框架，解决 rotation 与 group quantization 的失配。
- 核心贡献（2-3点）：
  - CoRFiG + Harmonic-Aligned Permutation，使全局 rotation 与细粒度 group scale 协同，降低 scale 精度需求。
  - 零点取整策略实现全整数 dequant。
  - 在 INT4 tensor PE 上达到 LLaMA 系列 SOTA 4-bit 精度，相对基线加速器最高 3.4× 速度 / 3.6× 能效。
- 工程价值：低比特推理的硬件友好路径清晰，适合定制加速器或边缘部署。软件侧量化思想也可迁移到现有框架。
- 是否值得读：可选
- Relevance Score：4
- Link：https://arxiv.org/abs/2607.27694

### 【Title】Rethinking AI Cloud Infrastructure for Agentic Serving Systems with the Aries Experimentation Framework
- 一句话总结：全栈实验框架 + 生产 trace 分析，揭示 Agent 服务与传统 LLM serving 的本质差异。
- 核心贡献（2-3点）：
  - Aries 分离任务语义与执行配置，重建跨组件轨迹并关联系统遥测，统一异构 sandbox 接口。
  - 实验证明 token 中心指标漏掉非推理瓶颈；额外 context 收益递减且降低容量；sandbox 呈现长空闲+短突发，快照式状态管理代价高。
  - 提出 agent-native 服务愿景：轨迹级指标、自适应 context、弹性 sandbox、最小攻击面。
- 工程价值：为构建真正支持 Agent 的 serving 系统提供系统级诊断与设计原则，避免盲目沿用 chat serving 架构。
- 是否值得读：可选
- Relevance Score：4
- Link：https://arxiv.org/abs/2607.29069

### 【Title】Adaptive FastOPD: Progress-Aware Rollout Horizon Expansion for Efficient On-Policy Distillation
- 一句话总结：根据学习进度自适应扩展 rollout horizon，大幅降低 on-policy distillation 训练成本。
- 核心贡献（2-3点）：
  - 基于四个相对 teacher-student 信号判断当前边界是否已 plateau，再决定是否扩 horizon。
  - 同时检查当前 horizon 利用率，避免少数长 response 触发无效扩容。
  - 两对 teacher-student 上平均性能最高，训练时间相对 OPD 15K 降低 49–71%。
- 工程价值：OPD 是当前高效对齐/蒸馏的主流路径之一，直接降低训练墙钟时间，对资源敏感的 SFT/RLHF 流程有实用意义。
- 是否值得读：可选
- Relevance Score：3
- Link：https://arxiv.org/abs/2607.29494
