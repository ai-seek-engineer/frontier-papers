### 【Title】psRL: Efficient Training for Agentic AI via Training-Time Prefix Sharing
- 一句话总结：Agentic RL 的瓶颈从 rollout 转到 update 后，用训练期 prefix sharing + 动态 KV 管理把更新吞吐拉高最多 5.2×。
- 核心贡献（2-3点）：
  - 针对 tree / step-wise RL 带来的样本爆炸，利用 update 阶段全局可见、数据不可变做细粒度 prefix 复用与负载均衡。
  - 新的 KV cache manager：可变 block size + 动态缓存，同时保 prefix hit 与显存利用率。
  - 生产 trace 验证，相对现有训练系统最高 5.2× throughput。
- 工程价值：直接打在 **agentic RL infra** 上，不是算法小改。任何做 GRPO/PPO multi-turn、共享 system/tool prompt 的训练栈都该看调度与 cache 设计。
- 是否值得读：强烈推荐
- Relevance Score：5
- Link：https://arxiv.org/abs/2608.25683

### 【Title】JIT-Agent: Scaling Harness Intelligence via Just-in-Time Harness Evolution
- 一句话总结：把 agent harness（memory / plan / action / tool）做成可生成、可修复、可自演化的制品，而不是手写脚手架。
- 核心贡献（2-3点）：
  - 固定四模块协议，训练一个 harness 生成模型，给任意现成 agentic LLM 现场合成 harness。
  - 带修复与 archive 蒸馏，harness 可随任务复利，而不是一次性 prompt。
  - DeepSeek-V4-Flash + JIT 在 DeepSearchQA / OdysseyBench 超过 GPT-5.6；GLM-5.2 最高 +20.2；有 GitHub / HF。
- 工程价值：落地价值在 **runtime 层**，不是再训一个更大 base。适合评估“换脚手架 vs 换模型”的 ROI。
- 是否值得读：强烈推荐
- Relevance Score：5
- Link：https://arxiv.org/abs/2608.25593 | code: https://github.com/bingreeky/JIT

### 【Title】NeuroPrefetcher: Storage-Aware Sparse LLM Inference via Delta Prefetching
- 一句话总结：模型永久大于内存时，用 MLP 神经元时序局部性做 delta 预取，把 NVMe 从被动缺页变成主动重量搬运。
- 核心贡献（2-3点）：
  - 观测：decode 时约 82–85% active neuron 跨 token 复用，只需拉增量行。
  - 单次 GPU predictor（约 2.86% 参数）预测后续 MLP 稀疏活性，应用层调度 NVMe 读。
  - 真机 unified-memory 边缘设备相对 llama.cpp **7.9–12.0×**；有代码。
- 工程价值：高。面向 **offload / 边缘推理**，思路可迁移到 expert offload、MoE 路由预取。
- 是否值得读：强烈推荐
- Relevance Score：5
- Link：https://arxiv.org/abs/2608.22643 | code: https://github.com/nobeldhar/NeuroPrefetcher

### 【Title】Minima-KV: Retention-Preserving KV Cache Compression with Mixed-Format Paged Attention
- 一句话总结：FP8 Anchor page + TQ3 老 page 的异构 paged attention，不用整份 dense shadow 就能直接 decode。
- 核心贡献（2-3点）：
  - 分格式 kernel 算 partial attention，再做全局归一化 online-softmax merge。
  - Qwen3.6-27B / 96GB Blackwell：约 18.3 KiB KV/token，相对 BF16 3.50×、相对 FP8 1.75×。
  - LongBench v2 16K/32K/64K 掉点 -0.80/-0.60/-0.40；59K 双请求 canary 吞吐 0.982× 对照。
- 工程价值：高。这是能进 serving 的 **混合精度 paged KV**，不是只报 perplexity 的量化论文。
- 是否值得读：强烈推荐（submit 8/24，略贴窗口，但系统完整度高于多数新稿）
- Relevance Score：5
- Link：https://arxiv.org/abs/2608.23834

### 【Title】Recursive Experiential-Working Memory Evolution for Long-Horizon Agent Harnesses (Recuris)
- 一句话总结：把长程失败归因到 Working / Experiential / Skill Memory，用验证门控的局部更新做有界 RSI。
- 核心贡献（2-3点）：
  - Working Memory 跟踪进度并选 skill，避免全历史淹没状态。
  - Meta-Agent 把失败证据写成 gated memory patch，形成闭环而非无限自改代码。
  - 4 benchmark × 10 模型，35/37 提升；tau-bench 上 Opus 5 到 87.9%；最长任务 +32.2；有代码。
- 工程价值：中高。可直接借鉴 **memory 分层 + 失败定位**，比“再加一层反思 prompt”可落地。
- 是否值得读：可选偏强
- Relevance Score：4
- Link：https://arxiv.org/abs/2608.24876 | code: https://github.com/Gen-Verse/Recuris

### 【Title】Beyond Scaling: KOPE — Self-Evolving LLM Agents for Hardware Kernel Optimization
- 一句话总结：用 Experience Graph 记住“决策–反馈–后续决策”，在固定 token 预算下持续优化 kernel，而不是靠更长 context。
- 核心贡献（2-3点）：
  - Experience Graph Memory 保留分支与硬件实测，而不是堆轨迹。
  - Active Context Management：pass rate 60%→84.6%，优化 token 15.9B→1.113B。
  - 相对 CANNBot，同 GLM-5.2 设定几何平均加速 1.54×。
- 工程价值：对 **kernel / compiler agent** 和“agent 如何跨任务复用实测”有方法价值；对通用 serving 间接。
- 是否值得读：可选
- Relevance Score：4
- Link：https://arxiv.org/abs/2608.25570

## 额外输出

### 1. 今日最值得读 Top 3
1. **psRL** — Agentic RL 训练栈正在换瓶颈：sample 变便宜、update 变贵。Prefix sharing 是少数能立刻改 trainer 的系统点。
2. **JIT-Agent** — 把“脚手架 > 模型”做成可训练对象，且有跨模型增益和开源产物，比再发一篇 agent prompt 论文有用。
3. **NeuroPrefetcher / Minima-KV（并列第三看场景）** — 边缘/offload 看前者；长上下文 serving 看后者。两者都有数字、路径和可实现内核形状。

### 2. 今日趋势观察
- **Inference 仍是主航道**：混合精度 paged KV、存储感知稀疏预取、精确 offload 同时出现，主题从“再压 1 bit”转到 **异构格式 + 主动数据搬运**。
- **Agent 论文明显转向 harness / memory OS**：JIT-Agent、Recuris、KOPE 都在做“模型外状态如何演化”，而不是新 planner 口号。
- **RL 论文里真正有工程含量的是训练系统（psRL）**，纯算法 RLHF/SFT 本窗口几乎没有过筛选线。

### 3. 值得跟进的潜在方向
- **Training-time KV/prefix 复用**：serving 侧 prefix cache 已成熟，训练侧（尤其 tree RL、共享 tool schema）刚开始被当成一等优化对象。
- **Harness-as-artifact**：harness 生成 + 验证门控更新，可能比继续堆 base 参数更便宜；需要盯可复现协议和失败回归。
- **Decode 稀疏的“预测下一跳权重/KV”**：NeuroPrefetcher 的 neuron locality、OasisKV 类 lookahead（稍早）说明 speculative token 不只加速生成，也可当 **prefetch oracle**。
