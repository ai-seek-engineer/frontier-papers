### 1. Cross-Model KV Cache Transfer in LLM Families: A Closed-Form Linear Mapping for Prefill Reuse
- **一句话总结**：同家族不同规模模型间用闭式线性映射直接转移 KV cache，跳过 receiver 的 prefill。
- **核心贡献**：
  - 发现匹配 KV head/dim 的同家族模型间 KV 存在显著线性结构（单层可解释 30-56% 方差，多层更高）。
  - 设计 per-head ridge mapper（去 RoPE + top-k 源层拼接 + 小校准集），训练-free。
  - 4/6 对保留 73-98% standalone-prefill 精度；映射速度 2.7-25× 快于 re-prefill，多轮稳定。
- **工程价值**：直接可用于 production 级 cost-quality cascading、mid-conversation 模型切换、路由场景。减少重复 prefill 是真实 serving 痛点，闭式解落地成本低。
- **是否值得读**：强烈推荐
- **Relevance Score**：5
- **Link**：https://arxiv.org/abs/2608.03893

### 2. Practical Online KV Cache Compaction for LLM Agents: An Empirical Study
- **一句话总结**：针对 agent 长轨迹的在线 KV 压缩（非静态上下文假设），系统比较 TE/AM + 不同 proxy query。
- **核心贡献**：
  - 明确 agent 需要 online compaction（未来 query 未知），用廉价 proxy（boundary / repeat-prefill / delayed future-generation）。
  - 立即压缩常损害性能；延迟到用未来 query 可大幅恢复；TE 在 imperfect proxy 下比 AM 更鲁棒。
  - TE 在多规模模型上保留大部分精度，KV 降 80%，吞吐可超无压缩基线。
- **工程价值**：直接可落地 agent serving。KV 是 agent 推理最大瓶颈之一，proxy 选择成为核心设计点，实验覆盖真实 agent benchmark。
- **是否值得读**：强烈推荐
- **Relevance Score**：5
- **Link**：https://arxiv.org/abs/2608.00902

### 3. Fewer Tokens, Smaller Cache: Reward-Coordinated Efficient Reasoning
- **一句话总结**：用 process reward 协调 KV 压缩强度 + 生成惩罚 + 早停，同时砍缓存和生成 token。
- **核心贡献**：
  - 观察：高 reward 步对上下文丢失更容忍；压缩会反向增加生成长度。
  - ReCo：reward-adaptive KV 压缩 + reflection token 惩罚 + confidence early-stop。
  - 3 模型 6 benchmark：生成 token ↓37-65%，e2e latency 2.08-2.35×，精度基本保持。
- **工程价值**：针对 LRM overthinking 的系统级优化，同时解决 cache 与 generation 两侧，适合长 CoT 推理 serving。
- **是否值得读**：强烈推荐
- **Relevance Score**：4.5
- **Link**：https://arxiv.org/abs/2608.04771

### 4. LLM Inference Under Bursty Workload Distribution: Modifying the WAIT Algorithm
- **一句话总结**：给 WAIT 加轻量在线到达率估计，适配真实突发流量而非 Poisson 假设。
- **核心贡献**：
  - 用观察 interarrival 做 online intensity 估计，无需先验流量知识。
  - MMPP 合成负载评估：在低到达率变化场景下吞吐高于 Sarathi-Serve / ORCA / vLLM，延迟可比。
- **工程价值**：调度层优化，针对真实 serving 的 bursty 特性，改动轻量，可直接挂现有系统。
- **是否值得读**：可选
- **Relevance Score**：3.5
- **Link**：https://arxiv.org/abs/2608.06135

### 5. The Bitter Lesson of Tool Calling
- **一句话总结**：系统对比 programmatic tool calling（代码调用）vs 原生 JSON tool calling，在 BFCL v4 上验证。
- **核心贡献**：
  - 14 模型实测：PTC 在 11/14 匹配或超过 JSON；GPT-5.6 家族 +10.6%。
  - 并行 fan-out 下 13/14 更优；context rot 下更稳定（JSON 平均掉 2.3%）。
- **工程价值**：agent 工具调用接口选择有明确实验支撑，代码式调用更自然支持链式/并行，落地成本低。
- **是否值得读**：可选
- **Relevance Score**：3.5
- **Link**：https://arxiv.org/abs/2608.06370

### 6. RRC: Unlocking Generative Reward Models in LLM Reinforcement Learning via Ranking-Based Reward Construction
- **一句话总结**：用 ranking 而非 scalar 从 generative RM 构造 RL 奖励信号，解决范式 mismatch。
- **核心贡献**：
  - 指出 generative RM 的比较本质与现有 RL 的 scalar 不匹配。
  - 自竞争 ranking + anchor-guided ranking 两策略。
  - open-ended chat + reasoning benchmark 上稳定优于现有 reward 构造方法；有代码。
- **工程价值**：提升 generative RM 在 RLHF/RL 中的可用性，减少对 discriminative RM 的依赖，直接可接入现有 RL pipeline。
- **是否值得读**：可选
- **Relevance Score**：4
- **Link**：https://arxiv.org/abs/2608.06310

**今日趋势观察**  
Inference / KV 相关工作持续密集（跨模型转移、agent 在线压缩、reward 协调压缩），明显高于纯 agent 框架或传统 RL。Agent 方向更多聚焦工具调用范式与轨迹调试，而非新框架。SFT/Alignment/RL 侧开始出现 generative RM 与 ranking 信号的衔接尝试。

**值得跟进的潜在方向**  
- **Cross-model / cross-size KV 转移与 handoff**：生产级 cascading 与多模型路由的基础设施级机会，线性映射只是起点，非线性与跨家族扩展空间大。  
- **Agent-aware online KV management**（proxy query + delayed compaction + 预测性 prefetch）：静态压缩方法在动态轨迹上失效，系统侧调度与压缩联合设计成为刚需。
