### 【Model Inference / 推理优化】

**【Title】**  
Epiphany-Aware KV Cache Eviction Without the Attention Matrix (EPIKV)

- **一句话总结**：提出基于模型内部表征变化（epiphany score）的KV cache eviction，无需计算attention matrix，支持FlashAttention等fused kernels，直接提升长推理场景下的可扩展性。
- **核心贡献**（2-3点）：
  1. 新metric：直接从forward pass读取hidden state变化作为重要性评分，避免attention噪声和matrix materialization。
  2. 无训练、无classifier、无custom kernel，兼容现有生产栈。
  3. 实验：在MATH-500/AIME等长上下文基准上匹配或超越attention-based方法（e.g., 72% vs 71%），支持16x更长上下文，速度提升显著。
- **工程价值**：**高**。直接解决生产推理中KV cache瓶颈（尤其是reasoning模型长CoT），降低内存/延迟，可无缝集成到vLLM/HF等serving系统中。推理优化首选。
- **是否值得读**：**强烈推荐**
- **Relevance Score**：5
- **Link**：https://arxiv.org/abs/2606.26472

**【Title】**  
Information-Aware KV Cache Compression for Long Reasoning (InfoKV)

- **一句话总结**：融合predictive uncertainty（entropy）和attention的混合KV压缩，针对长推理链的前瞻性token重要性评估。
- **核心贡献**（2-3点）：
  1. 引入Forward Influence度量，捕捉远距离上下文影响（attention主要捕获局部）。
  2. entropy-aware框架，结合layer-wise representation evolution。
  3. 在Llama-3.1/3.2、DeepSeek-R1等上，prefill+decode长上下文基准优于纯attention方法。
- **工程价值**：**高**。适用于长上下文推理serving，改善内存效率和质量权衡，可扩展到生产KV管理。
- **是否值得读**：**强烈推荐**
- **Relevance Score**：5
- **Link**：https://arxiv.org/abs/2606.26875

**【Title】**  
PersistentKV: Page-Aware Decode Scheduling for Long-Context LLM Serving on Commodity GPUs

- **一句话总结**：针对paged-attention的page-aware decode调度和native block-table引擎，优化KV cache移动和work assignment。
- **核心贡献**（2-3点）：
  1. PersistentKV引擎：KV-head group mapping、workqueue scheduling，仅执行非空任务。
  2. 自适应policy：根据batch/sequence特性选择kernel（FlashInfer vs custom）。
  3. 商品GPU（RTX 3060）上，bimodal/Zipf workloads吞吐提升1.06-1.4x。
- **工程价值**：**高**。直接针对serving系统KV movement瓶颈，实用调度优化，可集成到现有paged系统。
- **是否值得读**：**强烈推荐**
- **Relevance Score**：4.5
- **Link**：https://arxiv.org/abs/2606.26666

**【Title】**  
TOPS: First-Principles Visual Token Pruning for Efficient MLLM Inference

- **一句话总结**：基于信息论（Task Relevance + Coverage + Diversity）的training-free视觉token pruning，大幅减少MLLM视觉token开销。
- **核心贡献**：Token Optimal Preservation Sets框架，在LLaVA-NeXT等上移除~78% token仍保持/略超性能（减少hallucination）。
- **工程价值**：**中高**。MLLM推理优化（视觉主导瓶颈），轻量plug-in，适用于多模态部署。
- **是否值得读**：**强烈推荐**（如果做多模态）
- **Relevance Score**：4
- **Link**：https://arxiv.org/abs/2606.27161

### 【LLM Agents】

**【Title】**  
Semantic Early-Stopping for Iterative LLM Agent Loops

- **一句话总结**：基于embedding语义稳定性和质量的early-stopping，取代固定iteration cap，减少agent loop token浪费。
