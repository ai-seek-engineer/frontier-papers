### Model Inference / 推理优化

**【Title】**  
Cassandra: Enabling Reasoning LLMs at Edge via Self-Speculative Decoding

- **一句话总结**：针对边缘设备低batch推理场景，提出无需额外训练的自推测解码框架，通过精细数据选择+剪枝+KV cache mantissa截断构建高效draft模型，并配轻量硬件编解码器实现加速。

- **核心贡献（2-3点）**：
  - 训练-free draft模型构建：细粒度salient value选择（权重+KV cache），优于传统layer skipping或结构化KV压缩。
  - 硬件协同：轻量encoder-decoder模块适配商用GPU/NPU，降低格式转换开销。
  - 实测：在Llama3-8B上达2.41x speedup（vs BF16），相同内存下生成token数是Eagle-3的1.81x。

- **工程价值**：直接适用于边缘/消费级设备上的长推理任务（CoT/reasoning），显著降低decode阶段内存和延迟瓶颈，可集成到现有vLLM/SGLang等serving框架；低batch优化对手机/边缘部署特别实用。

- **是否值得读**：**强烈推荐**（ISCA 2026接收）。

- **Relevance Score**：5/5

- **Link**：https://arxiv.org/abs/2605.26558

### AI Infra / 分布式训练 / 系统优化

**【Title】**  
Understanding Inference Scaling for LLMs: Bottlenecks, Trade-offs, and Performance Principles

- **一句话总结**：系统性表征reasoning-centric LLM推理（长CoT主导），分析Data/Tensor/Pipeline并行在8B-671B规模下的瓶颈切换，为infra设计提供决策框架。

- **核心贡献（2-3点）**：
  - 识别“reasoning cliff”：KV-cache碎片化导致capacity-bound，Data Parallel在小模型高效但易throttle，大模型转向Tensor Parallel（尤其是MoE路由同步）。
  - 跨规模实验（dense vs MoE），量化interconnect/memory-bandwidth瓶颈。
  - 给出并行策略选择原则和架构启示。

- **工程价值**：对大规模分布式推理系统（集群调度、并行策略）有直接指导意义，尤其在从标准生成转向reasoning workload时，能避免次优scaling；可用于优化Mooncake/HiCache等KV存储或Disaggregated serving设计。

- **是否值得读**：**强烈推荐**（ISCA'26 Industry Track）。

- **Relevance Score**：5/5

- **Link**：https://arxiv.org/abs/2605.19775

### LLM Agents（系统设计/落地）

**【Title】**  
MUSE-Autoskill: Self-Evolving Agents via Skill Creation, Memory, Management, and Evaluation

- **一句话总结**：提出自进化代理框架，通过动态skill创建+记忆管理+评估循环，实现技能复用和系统级自优化，支持复杂任务。

- **核心贡献（2-3点）**：
  - 完整skill lifecycle（creation/memory/management/eval），避免单一prompt依赖。
  - 与现有runtime（如Codex CLI、Hermes）对比实验，展示系统设计优势。
  - 工程实现细节（Docker隔离、token telemetry等）。

- **工程价值**：提供可落地的agent系统架构，尤其适合生产环境中的持久化、多任务agent；skill作为外部可审计内存的思路，对infra（状态管理、工具集成）有借鉴。

- **是否值得读**：**强烈推荐**（有实际系统实现）。

- **Relevance Score**：4/5

- **Link**：https://arxiv.org/abs/2605.27366

**【Title】**  
SkillOpt: Executive Strategy for Self-Evolving Agent Skills (Microsoft)

- **一句话总结**：将agent skills作为外部文本状态进行系统优化训练，实现零部署推理开销的稳定更新，跨benchmark和环境显著提升性能。

- **核心贡献（2-3点）**：
  - Text-space optimizer设计，skills独立于model权重。
  - 稳定更新机制 + 零额外inference cost。
  - 多环境实证。

- **工程价值**：agent系统设计中的关键模块化思路，可直接用于生产agent框架，提升可维护性和可复用性；对SFT/Alignment pipeline也有启发。

- **是否值得读**：**强烈推荐**（代码公开）。

- **Relevance Score**：4/5

- **Link**：https://arxiv.org/abs/2605.23904 (代码：microsoft.github.io/SkillOpt)

### 今日最值得读 Top 3（理由）
1. **Cassandra** — 推理优化最硬核的工程落地，edge场景直接可用，速度/内存实测突出，优先级最高。
2. **Understanding Inference Scaling** — 系统级表征+决策框架，对infra工程师规划大规模reasoning集群极具参考价值。
3. **MUSE-Autoskill / SkillOpt** — Agent系统设计双子星，提供可复现的skill管理和自进化路径，工程落地性强。

### 今日趋势观察
Inference优化（尤其是speculative decoding + KV管理）和Agent系统设计明显增加。Reasoning workload驱动的infra瓶颈研究升温（从prefill-bound到decode/capacity-bound切换），Agent向“skill as external optimizable state”演化，减少对单model的依赖。

### 是否出现“值得跟进的潜在方向”
是的：**Reasoning-centric Inference Infrastructure**（长CoT下的KV/cache/并行优化）和**Skill-centric Agent Architectures**（外部可进化skill层）。前者直接影响下一代serving系统，后者可能成为agent生产的标准中间层，值得持续跟踪系统实现和benchmark。
