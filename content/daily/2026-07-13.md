### 【Model Inference / 推理优化】

**【Title】**  
A Practical Investigation of Training-free Relaxed Speculative Decoding (arXiv:2607.08690)

- **一句话总结**：  
  实用调研训练-free的relaxed speculative decoding（放宽无损保证），统一框架并在当代LLM上benchmark，突出capability-speed tradeoff的工程考量。

- **核心贡献（2-3点）**：  
  1. 统一现有relaxed方法框架，分析训练-free实现。  
  2. 实证benchmark显示relaxation需仔细capability评估（不同于标准lossless speculative）。  
  3. 关键洞见：许多方法依赖强drafter，不适合轻量multi-token-prediction drafter。

- **工程价值**：  
  高。直接指导生产中speculative decoding部署——可实现额外speedup，但需监控质量退化；适用于batch inference场景，降低TTFT/TPT，无需重训drafter。易集成vLLM/SGLang类serving系统。

- **是否值得读**：强烈推荐  
- **Relevance Score**：5/5  
- **Link**：https://arxiv.org/abs/2607.08690

**【Title】**  
Towards Efficient Large Language Model Serving: A Survey on System-Aware KV Cache Optimization (arXiv:2607.08057)

- **一句话总结**：  
  系统视角调研KV cache优化（sKis），按execution/scheduling、placement/migration、representation/retention三维组织，强调cross-behavior co-design。

- **核心贡献（2-3点）**：  
  1. 系统行为框架梳理近期KV工作。  
  2. 分析temporal/spatial/structural维度及affinity。  
  3. 指出未来serving infrastructure机会。

- **工程价值**：  
  极高。serving工程师必读手册，帮助设计高吞吐、低内存KV管理（paged attention、offloading、compression结合）；直接影响生产infra如disaggregated serving。

- **是否值得读**：强烈推荐  
- **Relevance Score**：5/5  
- **Link**：https://arxiv.org/abs/2607.08057

**【Title】**  
Lynx: Progressive Speculative Quantization for accelerating KV Transfer in Long-Context Inference (arXiv:2607.01831)

- **一句话总结**：  
  针对disaggregated long-context inference的KV transfer瓶颈，提出progressive split-stream量化（Anchor + Residual），支持partial use + speculative decode + verification。

- **核心贡献（2-3点）**：  
  1. 挑战“KV必须全量传输”假设，利用MSB/LSB不均等贡献。  
  2. 实现TTFT接近4-bit精度，accuracy匹配BF16。  
  3. 实证1.43x TTFT提升 + 5.1% accuracy gain。

- **工程价值**：  
  高。直接解决agentic/RAG长上下文网络传输痛点；适用于disaggregated部署，结合现有quantization pipeline即可落地，提升整体serving效率。

- **是否值得读**：强烈推荐  
- **Relevance Score**：4.5/5  
- **Link**：https://arxiv.org/abs/2607.01831

**【Title】**  
Fractal KV-Cache Archives: Lossless Symbolic Storage with In-Place Retrieval (arXiv:2607.07144)

- **一句话总结**：  
  量化后KV symbol stream的创新归档格式（fractal/iterated-map codes），支持lossless、O(1) append/random access + 内置搜索索引。

- **核心贡献（2-3点）**：  
  1. 线性时间归档 + in-place检索，无需materialize全cache。  
  2. 结合residual VQ实验（GPT-2），大幅压缩（36-54x）伴可控PPL。  
  3. 证明archive同时作为substring search index。

- **工程价值**：  
  中高。长上下文持久化/检索优化（beyond simple eviction/quant）；存储层创新，适合edge或海量context serving，可与现有KV quant结合。

- **是否值得读**：可选（代码可用）  
- **Relevance Score**：4/5  
- **Link**：https://arxiv.org/abs/2607.07144

### 【LLM Agents】

**【Title】**  
Remember When It Matters: Proactive Memory Agent for Long-Horizon Agents (arXiv:2607.08716)

- **一句话总结**：  
  针对long-horizon “behavioral state decay”，引入独立proactive memory agent（更新memory bank + 选择性inject reminder），plug-and-play。

- **核心贡献（2-3点）**：  
  1. 主动干预 vs 被动retrieval，显著提升Terminal-Bench / τ²-Bench pass@1。  
  2. Ablation验证selective injection最优。  
  3. 开源SFT+GRPO memory policy（Qwen3.5-27B）。

- **工程价值**：  
  高。实际agent系统设计（memory management），解决长任务context管理；易集成现有agent框架，提升reliability，无需改action agent。

- **是否值得读**：强烈推荐  
- **Relevance Score**：4.5/5  
- **Link**：https://arxiv.org/abs/2607.08716
