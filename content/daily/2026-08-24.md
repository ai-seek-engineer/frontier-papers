### 1. Model Inference / 推理优化

**【Title】** FlashPrefill V2: Block-Sparse Prefill Attention for Long-Context LLM Serving  
- **一句话总结**：把 block-sparse prefill 从算法原型做成可生产部署的 attention backend，支持 paged KV、continuous batching 和 FP8。  
- **核心贡献（2-3点）**：  
  1. 引入 mean correction 抑制极端稀疏下的近似误差。  
  2. 内核重写对齐 FlashAttention-3/4（PackGQA、warp specialization、pingpong pipeline），原生支持 paged KV + continuous batching。  
  3. 可直接作为 SGLang 等框架的 attention backend。  
- **工程价值**：长上下文 prefill 是当前服务瓶颈。在 H20 上 128K 上下文可达 47×（FP8）/ 27×（BF16）相对 FA2，FP8 下仍比对齐的 dense FA3/4 baseline 快 30×。直接降低 TTFT 与 GPU 成本，落地路径清晰。  
- **是否值得读**：强烈推荐  
- **Relevance Score**：5  
- **Link**：https://arxiv.org/abs/2608.19758  

**【Title】** CacheRoute: Planned Prefix-Affinity Routing for Large-Scale LLM Serving  
- **一句话总结**：周期性规划的 prefix-affinity 路由，解决 cache-blind 负载均衡与固定亲和力之间的吞吐-复用权衡。  
- **核心贡献（2-3点）**：  
  1. 高热度 key 进稳定 warm set，按期望负载放置；支持多 destination 但主实验中单 destination。  
  2. 实测 Llama-3.3-70B fp8 / 60×H100：176 QPS @ 3.5s p99 SLO，是最强 baseline 的 2.3×；KV hit rate 从 64% 提升到 93%。  
  3. 给出明确 gating 建议：必须先 shadow replay，不能只看 workload 统计。  
- **工程价值**：大规模服务里 prefix cache 命中率直接决定 prefill 成本。系统级路由方案，可直接挂在现有调度层，实测数据充分。  
- **是否值得读**：强烈推荐  
- **Relevance Score**：5  
- **Link**：https://arxiv.org/abs/2608.19677  

### 2. AI Infra / 分布式训练 / 系统优化

**【Title】** Pre-Compiled Pipeline Shards for Distributed LLM Inference on Intel AI PC Fleets  
- **一句话总结**：把模型按层切成预编译 OpenVINO shard，让闲置 AI PC 集群（统一内存）通过 pipeline parallelism 服务单机放不下的大模型。  
- **核心贡献（2-3点）**：  
  1. 注入 beam_idx Gather 触发 IndirectKVCache fusion，恢复单机性能。  
  2. 在 stateful OpenVINO 上叠加 speculative decoding + micro-batching（多用户交错）。  
  3. 2 节点 8B INT4 实现 1.79× 单用户吞吐；4 节点 Lunar Lake 可跑 70B 并保持 token 一致。  
- **工程价值**：边缘/异构闲置算力利用新思路，代码与复现脚本完整。对 on-prem / 边缘推理有直接参考价值。  
- **是否值得读**：可选  
- **Relevance Score**：4  
- **Link**：https://arxiv.org/abs/2608.19147  

### 3. LLM Agents（有实际落地或系统设计）

**【Title】** From LLM Inference to Agentic Workloads: Characterization and Implications for Serving Systems  
- **一句话总结**：系统级刻画 agentic 工作负载与传统 inference 的本质差异，并给出可落地优化。  
- **核心贡献（2-3点）**：  
  1. AgentSysBench + 统一 instrumentation，覆盖 10 个代表应用 + 生产 trace。  
  2. 总结 6 大特性：非 LLM 组件常主导延迟、异构资源亲和、瓶颈动态迁移、长空闲状态、控制平面开销、跨请求冗余。  
  3. 验证 4 类优化：task-aware serving（延迟 -29~40%）、communication-aware placement（最高 4.5×）、state offloading（内存 -4.6×）、tool-result caching（冗余搜索 -35%、延迟 -19%）。  
- **工程价值**：当前 agent serving 系统大多还在用传统 inference 假设。这篇直接给测量工具箱 + 可复现优化方向，是做 agent infra 的必读。  
- **是否值得读**：强烈推荐  
- **Relevance Score**：5  
- **Link**：https://arxiv.org/abs/2608.15127  

**【Title】** Task-CoEvolve: Efficient Harness Optimization via Adaptive Validation Task Selection  
- **一句话总结**：在 harness 优化（不改模型权重）中，让验证任务与 harness 共演化，大幅降低评估成本。  
- **核心贡献（2-3点）**：  
  1. 基于候选 harness 分歧度的 variance-weighted sampling，聚焦能力边界任务。  
  2. 用采样概率修正估计全量集分数，保证迭代间可比。  
  3. 在线文本分类 + Terminal-Bench 2.1：匹配全量搜索最终性能，评估次数减少 80%。代码已开源。  
- **工程价值**：harness 优化是当前 agent 落地最实用的杠杆之一。评估成本往往是瓶颈，此方法直接可复用。  
- **是否值得读**：强烈推荐  
- **Relevance Score**：4  
- **Link**：https://arxiv.org/abs/2608.20169
