### 【Model Inference / KV Cache 优化】

**【Title】**  
Reformulating KV Cache Eviction Problem for Long-Context LLM Inference (LaProx)

- **一句话总结**：将KV Cache eviction从传统head-wise attention权重平均重构为output-aware、layer-wise矩阵乘近似问题，实现全局token重要性评分。
- **核心贡献**（2-3点）：
  - 输出感知度量：显式建模attention map与projected value的乘性交互 + inter-head依赖。
  - 统一全局eviction策略，避免局部head-wise决策。
  - LongBench等多数据集验证，5% KV cache下优于SOTA，极端压缩场景accuracy loss降低至2x。
- **工程价值**：直接适用于长上下文推理内存/延迟优化，可集成到现有vLLM/FlashAttention流水线，计算开销低，有benchmark数据支撑落地。
- **是否值得读**：**强烈推荐**。
- **Relevance Score**：5/5。
- **Link**：https://arxiv.org/abs/2605.07234

**【Title】**  
Sparse Attention as a Range Searching Problem: Towards an Inference-Efficient Index for KV Cache (Louver)

- **一句话总结**：把sparse attention重构为halfspace range searching问题，提出硬件感知索引Louver，保证zero false negatives同时加速KV检索。
- **核心贡献**（2-3点）：
  - 理论保证：指定阈值下无漏召回，解决query/step-dependent关键token遗漏导致的error spike。
  - 轻量级实现 + CPU/GPU优化，集成友好。
  - 实验优于现有sparse方法，且快于高度优化的dense attention（如FlashAttention）。
- **工程价值**：推理时KV索引优化核心，直接提升长上下文/高吞吐场景效率与鲁棒性，理论+实践双支撑。
- **是否值得读**：**强烈推荐**。
- **Relevance Score**：5/5。
- **Link**：https://arxiv.org/abs/2605.06763

**【Title】**  
QKVShare: Quantized KV-Cache Handoff for Multi-Agent On-Device LLMs

- **一句话总结**：针对边缘多agent场景，提出量化KV Cache handoff框架（token-level mixed-precision + CacheCard），避免昂贵re-prefill。
- **核心贡献**（2-3点）：
  - 量化handoff路径 + HuggingFace兼容注入。
  - GSM8K等实验显示TTFT显著降低，尤其多hop/高budget场景优于uniform量化。
- **工程价值**：边缘设备多agent推理内存与切换延迟优化实用方案，量化感知+实际latency数据。
- **是否值得读**：**强烈推荐**（多agent方向高匹配）。
- **Relevance Score**：4.5/5。
- **Link**：https://arxiv.org/abs/2605.03884

### 【LLM Agents / 系统设计】

**【Title】**  
Shepherd: A Runtime Substrate Empowering Meta-Agents with a Formalized Execution Trace

- **一句话总结**：提出函数式编程风格meta-agent运行时基建，用Git-like typed execution trace支持fork/replay，高效prompt cache复用。
- **核心贡献**（2-3点）：
  - Lean mechanized核心操作 + 5x快于Docker的fork。
  - 应用验证：runtime intervention提升pair coding pass rate，counterfactual优化+Tree-RL均有显著收益。
  - 开源系统。
- **工程价值**：meta-agent/监督、可复现、分支探索的系统级支撑，直接提升agent可靠性与优化效率。
- **是否值得读**：**强烈推荐**。
- **Relevance Score**：5/5。
- **Link**：https://arxiv.org/abs/2605.10913

**【Title】**  
Remember the Decision, Not the Description: A Rate-Distortion Framework for Agent Memory (DeMem)

- **一句话总结**：用decision-centric rate-distortion框架重构agent memory，聚焦决策区分而非描述，提出在线DeMem学习器。
- **核心贡献**（2-3点）：

- **工程价值**：agent长期记忆压缩与管理实用方法，减少无关描述存储，直接服务runtime效率。
