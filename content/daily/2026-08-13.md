### 1. Model Inference / 推理优化

**【Title】** OasisKV: Scaling In-Decode KV Cache Beyond HBM with Lookahead Sparse Prefetching  
**Link**：https://arxiv.org/abs/2608.08097  

- **一句话总结**：利用 speculative decoding 的 lookahead token 预测未来重要 KV，把完整 KV 解耦到更高容量层级，只把稀疏相关块预取进 HBM。  
- **核心贡献**：  
  1. 观察到 decode-time attention 稀疏性 + SD draft token 可作为准确、零额外训练的未来访问预测信号。  
  2. 设计 background attention pipeline + sparse prefetch，实现 HBM 只存工作集。  
  3. 基于 vLLM 实现，支持 prefill-decode disaggregation。  
- **工程价值**：直接解决 HBM 容量瓶颈，提升 batch size 与长上下文/推理吞吐；实测 1.69×（推理 workload，精度损失 0.1）到 2.1×，disagg 场景约 2× 吞吐且 KV 传输量降 6.5–9.7×。可落地到现有 serving 框架。  
- **是否值得读**：强烈推荐  
- **Relevance Score**：5  

**【Title】** OSCAR: Offline Spectral Covariance-Aware Rotation for 2-bit KV Cache Quantization  
**Link**：https://arxiv.org/abs/2605.17757（近期系统/代码侧活跃，已有 SGLang 集成线索）  

- **一句话总结**：离线估计 attention-aware 协方差结构，推导固定旋转与 clipping，实现真正可用的 ≈2-bit KV 量化。  
- **核心贡献**：  
  1. 旋转对准 attention 实际消耗的方向，而非简单 Hadamard。  
  2. 配套 INT2 attention kernel，兼容 paged KV 与 fused pipeline。  
  3. 在 Qwen3 系列与 GLM-4.7 等推理模型上接近 BF16（4B 差距 3.78，32B/358B 几乎持平）。  
- **工程价值**：KV 内存 ≈8× 压缩，同内存预算下大 batch 吞吐最高 7×，bs=1 也可因带宽降低获 3×；已有开源与 serving 集成，实用性强于多数 2-bit 方案。  
- **是否值得读**：强烈推荐  
- **Relevance Score**：5  

### 2. AI Infra / 分布式训练 / 系统优化 + Agentic RL

**【Title】** TideRL: Boosting Agentic RL Goodput with Readiness-Aware Scheduling  
**Link**：https://arxiv.org/abs/2608.10402  

- **一句话总结**：针对 multi-turn agentic RL 中任务暂停/恢复、上下文增长、完成时间高度异构的问题，提出 readiness-aware 弹性调度系统。  
- **核心贡献**：  
  1. Continuous Task Batching 保留有用 rollout 状态。  
  2. Resource-Aware Ref-Actor Pipelining 在 ready backlog 上选择 streaming/colocated 模式。  
  3. Elastic Resource Scaling 根据 readiness 信号在 rollout 与 training 间动态迁移 rank。  
- **工程价值**：直接提升 RL training goodput（最高 5.6× 同步基线、>33% 异步基线），KV hit rate +1.58×，per-step 时间降 44%，等待时间降 77%。对真实 agentic RL pipeline 有立即系统价值。  
- **是否值得读**：强烈推荐  
- **Relevance Score**：5  

**【Title】** Scheduling Mixed RL Rollouts Beyond Prefix Locality  
**Link**：https://arxiv.org/abs/2608.11152  

- **一句话总结**：为混合 RLVR/RLHF/agentic rollout 设计路由层 admission 策略，解决异构 session 对 KV 容量的竞争。  
- **核心贡献**：  
  1. Adaptive session admission + workload-aware KV capacity allocation。  
  2. Residency-time-aware KV accounting，避免扭曲 trainer 指定的 workload 混合比例。  
  3. 在 Step3.7 / Qwen3.6-35B 上实测。  
- **工程价值**：rollout 吞吐提升 35–53%，迭代时间降 22.8%，同时保持 prefix-cache hit rate 与任务分数。对共享异步 inference 服务的混合 RL 后训练有直接工程意义。  
- **是否值得读**：强烈推荐  
- **Relevance Score**：4  

### 3. LLM Agents / Edge Serving（系统侧）

**【Title】** ImpactHO: Importance-Aware KV Cache Transfer for Multi-User Edge LLM Handover  
**Link**：https://arxiv.org/abs/2608.10545  

- **一句话总结**：边缘节点 handover 时按重要性排序传输部分 KV，把 token-level 稀疏性转化为 backhaul 节省。  
- **核心贡献**：  
  1. 用 sigmoid 拟合 partial-cache 精度曲线（R²>0.99），将多用户分配建模为凸问题。  
  2. 闭式 weighted water-filling 在线调度。  
  3. 500ms 窗口内平均精度 >93.7%（距 full-cache 仅 0.5pp）。  
- **工程价值**：解决边缘多用户移动场景下的 KV 传输瓶颈，实用性强，可直接指导 edge serving 调度。  
- **是否值得读**：可选  
- **Relevance Score**：4  

**【Title】** Efficient Speculative Decoding for Llama at Scale: Challenges and Solutions（Meta）  
**Link**：https://arxiv.org/html/2508.08192（近期 HTML/生产相关讨论活跃）  

- **一句话总结**：Meta 生产级 EAGLE speculative decoding 的训练与推理优化全集，覆盖 tree attention、multi-round 等工程挑战。  
- **核心贡献**：  
  1. GPU 高效实现 tree attention 与多轮 speculative。  
  2. 大规模 Llama（含 Llama4 Maverick）生产优化。  
  3. 大 batch 下仍保持 1.4–2.0× 加速。  
- **工程价值**：真实生产 latency（Maverick ≈4ms/token on 8×H100）与相对 vLLM 的 10–30% 提升，对大规模 serving 极具参考价值。  
- **是否值得读**：强烈推荐（生产视角）  
- **Relevance Score**：5

### 今日最值得读 Top 3

1. **OasisKV**（强烈推荐）  
   理由：直接打中当前最痛的 HBM KV 容量瓶颈，方法（SD lookahead + sparse prefetch）简洁可落地，吞吐收益明确且支持 disagg，工程闭环完整。

2. **TideRL**（强烈推荐）  
   理由：Agentic RL 正在成为主流后训练范式，本文从 goodput（而非单纯 GPU occupancy）出发做系统性调度，收益巨大，对真实 multi-turn agent pipeline 有立竿见影价值。

3. **OSCAR**（强烈推荐）  
   理由：2-bit KV 终于有了接近 BF16 且真正能进 serving（paged + fused kernel）的方案，内存与吞吐收益双高，代码已开源并有集成线索。

### 今日趋势观察

- **Inference / KV 优化** 继续占主导：稀疏 + 预测（OasisKV）、超低 bit 量化（OSCAR）、handover 传输（ImpactHO）同时出现，说明社区已从“能不能压”转向“如何在真实 serving 约束下压且不掉精度”。  
- **Agentic RL 系统** 明显升温：TideRL 与 Mixed RL Rollouts 两篇均聚焦 multi-turn / 异构 rollout 的调度与 KV 管理，反映 agentic workload 已成为 infra 的新一等公民。  
- Speculative decoding 从算法走向生产级工程细节（Meta 文）。

### 值得跟进的潜在方向

1. **SD-aware KV 管理**：把 speculative draft 同时当作未来访问预测器（OasisKV 已验证），可进一步与量化、eviction、disagg 深度结合。  
2. **Agentic RL 的 readiness / residency 感知调度**：从“前缀复用”走向“任务完成时间与 KV 生命周期异构”的精细控制，可能成为下一代 RL infra 标配。  
3. **2-bit + 系统协同设计**：旋转/量化必须与 paged attention、fused kernel、serving 调度一起设计，否则 offline 好看但线上不可用。
