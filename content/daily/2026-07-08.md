### 【Model Inference / 推理优化】

**【Title】**  
DSpark: Confidence-Scheduled Speculative Decoding with Semi-Autoregressive Generation (arXiv:2607.05147)

- **一句话总结**：结合半自回归并行生成与置信度调度验证的推测解码框架，显著提升高并发服务下的吞吐和接受率。  
- **核心贡献**：(1) 半自回归架构引入块内token依赖，缓解并行draft的suffix decay；(2) 置信度调度根据前缀存活概率和系统吞吐动态调整验证长度，避免高拒绝风险浪费batch容量；(3) 在DeepSeek-V4生产流量下验证，匹配吞吐时用户生成速度提升60-85%。  
- **工程价值**：直接针对生产级高并发推理痛点（验证浪费、batch利用率），与现有MTP等baseline集成潜力大；负载感知调度对实际serving系统（如vLLM扩展）极具参考价值，有代码/实验支撑。  
- **是否值得读**：**强烈推荐**  
- **Relevance Score**：5/5  
- **Link**：https://arxiv.org/abs/2607.05147

**【Title】**  
MosaicKV: Serving Long-Context LLM with Dynamic Two-D KV Cache Compression (arXiv:2607.00760，近期相关)

- **一句话总结**：动态二维KV cache压缩系统，针对超长上下文服务场景优化内存与计算。  
- **核心贡献**：动态调整KV压缩维度与粒度，平衡精度与内存；支持长达百万token级serving。  
- **工程价值**：直接缓解长上下文/Agent推理的KV cache内存墙，对分布式serving和边缘部署有实用优化路径，实验覆盖实际serving场景。  
- **是否值得读**：**强烈推荐**  
- **Relevance Score**：4.5/5  
- **Link**：https://arxiv.org/abs/2607.00760

### 【LLM Agents（系统设计/落地）】

**【Title】**  
MetaSkill-Evolve: Recursive Self-Improvement of LLM Agents via Two-Timescale Meta-Skill Evolution (arXiv:2607.05297)

- **一句话总结**：双时间尺度元技能进化框架，实现Agent技能的递归自我改进（task skill快循环 + meta-skill慢循环）。  
- **核心贡献**：(1) 技能与改进过程均可演化，无需额外模型/目标；(2) 单冻结backbone支撑全pipeline；(3) 在OfficeQA、SealQA、ALFWorld等基准上显著超越静态/单层进化baseline（+1.92~23.54 pts）。  
- **工程价值**：为长期运行Agent提供可持续自进化机制，减少人工技能维护；递归设计便于系统集成，实验数据充分。  
- **是否值得读**：**强烈推荐**  
- **Relevance Score**：5/5  
- **Link**：https://arxiv.org/abs/2607.05297

**【Title】**  
AgentGym2: Benchmarking Large Language Model Agents in De-Idealized Real-World Environments (arXiv:2607.05174)

- **一句话总结**：面向真实世界噪声、不确定性和工具探索的Agent基准框架，暴露当前SOTA在端到端执行上的差距。  
- **核心贡献**：引入探索发现工具、组合未见任务、鲁棒处理噪声输入等真实场景评估；15+模型测试显示Gemini/GPT-5等仍大幅落后。  
- **工程价值**：为Agent系统开发提供更严苛的评估标准，推动从玩具benchmark向生产就绪迁移；基准公开，可直接用于迭代测试。  
- **是否值得读**：**强烈推荐**（尤其是构建/评估Agent的工程师）  
- **Relevance Score**：4.5/5  
- **Link**：https://arxiv.org/abs/2607.05174

**【Title】**  
LLM-as-a-Verifier: A General-Purpose Verification Framework (arXiv:2607.05391)

- **一句话总结**：通用LLM验证器框架，利用logits期望生成连续分数，提供细粒度反馈，支持Agent任务和RL。  
- **核心贡献**：(1) 概率评分+多维度scaling（粒度、重复、分解准则）；(2) 在Terminal-Bench、SWE-Bench、RoboRewardBench等达SOTA；(3) 可作为RL密集奖励，提升样本效率；代码开源。  
- **工程价值**：为Agent验证、自我修正和RLHF-like流程提供即插即用工具；连续分数便于排序/进度追踪，适用于生产Agent pipeline。  
- **是否值得读**：**强烈推荐**  
- **Relevance Score**：4.5/5  
- **Link**：https://arxiv.org/abs/2607.05391
