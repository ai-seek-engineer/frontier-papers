### 【Title】Cross-Model KV Cache Transfer in LLM Families: A Closed-Form Linear Mapping for Prefill Reuse  
**arXiv:2608.03893**（NVIDIA，Submitted 4 Aug 2026；今日社区讨论热度高）

- **一句话总结**：同家族不同规模模型间用闭式线性映射直接转移 KV Cache，跳过目标模型 prefill，转换比重新 prefill 快 2.7–25×。
- **核心贡献**：
  1. 发现 matched-KV（同 head 数/维度）跨模型存在强线性结构（单层可解释 56% key 方差，多层组合达 79%/65%）。
  2. 设计 per-head 闭式 ridge regression mapper（含 RoPE 处理 + 跨层选择），无需训练或仅极小校准集。
  3. 6 对（Qwen3 / Llama3.1 / Ministral）中 4 对保留 73–98% 独立 prefill 精度，多轮 handoff 稳定。
- **工程价值**：直接可落地于 cost-quality cascading、中途 model switch、router。消除“换模型必须重 prefill”的硬约束，路由从“cache 失效事件”变成纯 latency/cost 优化。当前限制：同家族 + 匹配 head 配置；异构/hybrid attention 待扩展。
- **是否值得读**：强烈推荐  
- **Relevance Score**：5  
- **Link**：https://arxiv.org/abs/2608.03893

### 【Title】Practical Online KV Cache Compaction for LLM Agents: An Empirical Study  
**arXiv:2608.00902**（Submitted 2 Aug 2026）

- **一句话总结**：Agent 长轨迹场景下，在线 KV compaction（Token Eviction vs Attention Matching）+ 廉价 proxy query 的系统实证，TE 在不完美 proxy 下更鲁棒。
- **核心贡献**：
  1. 明确区分 offline（未来 query 已知）与 online compaction；immediate compaction 常伤性能，延迟到用未来 query 可大幅恢复。
  2. TE 比 AM 对 proxy 质量更 tolerant；跨规模模型 TE 可砍 80% KV 同时保住大部分精度，并提升 throughput。
  3. 系统化比较 boundary / repeat-prefill / delayed-future 等 proxy 源。
- **工程价值**：Agent 服务中 KV 膨胀是真实瓶颈。可直接指导 vLLM/SGLang 类 serving 的在线 eviction 策略与 proxy 选择，延迟 compaction 是实用开关。
- **是否值得读**：强烈推荐（尤其做 Agent serving 的人）  
- **Relevance Score**：5  
- **Link**：https://arxiv.org/abs/2608.00902

### 【Title】RestoreKV: Recovering Full-Cache Behavior Under Aggressive Query-Agnostic KV Cache Eviction  
**arXiv:2608.01247**（Submitted 2 Aug 2026）

- **一句话总结**：在 query-agnostic 激进 eviction 后，用轻量可学习 restoration 模块（仅优化 0.4% 参数）恢复接近 full-cache 行为。
- **核心贡献**：
  1. 将问题从“选哪些 KV 保留”扩展到“选 + 学如何补全丢失信息”。
  2. Parameter-efficient self-distillation，无任务特定调参。
  3. 多 backbone + 多 long-context benchmark 上显著缩小压缩带来的精度损失（例：5% budget 下 KVzip 从 38.2 → 73.2 on RULER-4K；16× 压缩仍达 86.4）。
- **工程价值**：query-agnostic 压缩（一次压缩多 query 复用）在生产更友好。RestoreKV 作为后处理插件，overhead 极低（<0.5% construction），可叠加现有 eviction 方法。
- **是否值得读**：强烈推荐  
- **Relevance Score**：4.5  
- **Link**：https://arxiv.org/abs/2608.01247

### 【Title】Argus: A General-Purpose Agentic Runtime for Long-Horizon Reasoning  
**arXiv:2608.05144**（Submitted 5 Aug 2026）

- **一句话总结**：固定模型权重 + 持久 runtime state + 控制策略的通用 Agent runtime（Manager/Planner/Engineer/Reviewer），支持长期任务中的 persist/pivot。
- **核心贡献**：
  1. 模型权重固定，进化发生在 durable project state 与 control policy；operator 只在 escalation 点介入。
  2. 多角色 bounded mission + verification-gated self-evolution。
  3. SWE-Bench Pro 约 78%（vs Direct Copilot 59%），成熟波次 token 与时间下降明显；AARRI-Bench 等也有竞争力。
- **工程价值**：真正“系统级”Agent 运行时设计，而非 prompt 堆叠。持久状态 + 验证门控对生产 long-horizon agent 有直接参考价值（尤其软件工程/研究类工作流）。
- **是否值得读**：强烈推荐（做 Agent 系统的人）  
- **Relevance Score**：4.5  
- **Link**：https://arxiv.org/abs/2608.05144

### 【Title】Fewer Tokens, Smaller Cache: Reward-Coordinated Efficient Reasoning  
**arXiv:2608.04771**（Submitted 5 Aug 2026）

- **一句话总结**：用 process reward 同时驱动 KV 压缩强度、reflection token 惩罚与 early stopping，协调“生成侧”与“缓存侧”以降低 overthinking 成本。
- **核心贡献**：
  1. 观察：不同 reasoning step 对 context 丢失的容忍度不同，且 process reward 可跟踪。
  2. ReCo 框架：reward-adaptive compression + banded penalty + confidence early-stop。
  3. 3 模型 × 6 benchmark：生成 token 降 37–65%，e2e latency 2.08–2.35×，精度基本保持。
- **工程价值**：Reasoning model 的 overthinking 是实际成本黑洞。把 reward 同时作用于 generation 与 KV 策略，比单纯 eviction 更系统；可与现有 serving 栈结合。
- **是否值得读**：可选（强推理服务场景值得）  
- **Relevance Score**：4  
- **Link**：https://arxiv.org/abs/2608.04771

### 【Title】LiveMem: Maintaining Memory State Continuity in Long-Running LLM Inference  
**arXiv:2608.02515**（Submitted 3 Aug 2026）

- **一句话总结**：给 full-attention LLM 增加与 active context 解耦的固定容量 memory state，实现 context turnover 下的状态连续性。
- **核心贡献**：
  1. 形式化 “state continuity under context turnover” 问题。
  2. LiveMem 在主 attention 保持有界 KV window 的同时，用独立 memory state 跨生命周期保留历史。
  3. 作为 continuous inference 的 complementary abstraction。
- **工程价值**：长运行 assistant/agent 的真实痛点（context 轮换导致状态丢失）。比单纯 summarization/retrieval 更接近“计算状态”延续，工程上可落地为 runtime 组件。
- **是否值得读**：可选  
- **Relevance Score**：3.5–4  
- **Link**：https://arxiv.org/abs/2608.02515
