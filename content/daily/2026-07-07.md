### 1. Model Inference / 推理优化
**【Title】**  
Lynx: Progressive Speculative Quantization for accelerating KV Transfer in Long-Context Inference (arXiv:2607.01831)

- **一句话总结**：针对 disaggregated inference 中 KV cache 网络传输瓶颈，提出 progressive speculative quantization，在传输和 decode 阶段分层量化，兼顾低延迟和高精度。  
- **核心贡献**：(1) Hierarchical progressive quantization（非单一精度），支持 speculative 提前 decode；(2) 显著降低网络暴露延迟，同时保持推理准确性；(3) 在长上下文场景下 TTFT 提升明显。  
- **工程价值**：直接针对生产 disaggregated serving 的 KV transfer 痛点，可集成到 vLLM/SGLang 等引擎中，量化 + speculative 结合降低 bandwidth 需求，适合长上下文/多 agent 部署。实验数据和 benchmark 支撑强。  
- **是否值得读**：**强烈推荐**（inference 优化核心）。  
- **Relevance Score**：5/5  
- **Link**：https://arxiv.org/abs/2607.01831

**【Title】**  
Gain–Shape Residual Quantization for Sub-1-bit KV Cache (近期相关 KV 量化工作)

- **一句话总结**：Residual Quantization (RQ) 扩展到 sub-1-bit KV cache，使用 gain-shape 编码进一步压缩。  
- **核心贡献**：极致压缩 KV 同时控制质量退化；适用于长上下文 inference。  
- **工程价值**：内存/带宽极致优化，适合 edge 或超长上下文 serving，有 CUDA 实现潜力。  
- **是否值得读**：**强烈推荐**（如果关注极致量化）。  
- **Relevance Score**：4/5  
- **Link**：arXiv 相关搜索可定位。

### 2. LLM Agents（系统设计/落地）
**【Title】**  
AgenticSTS: A Bounded-Memory Testbed for Long-Horizon LLM Agents (arXiv:2607.02255)

- **一句话总结**：提出 bounded-memory 契约（typed retrieval + 无 raw transcript 累积），构建长时序 agent 测试床，在 Slay the Spire 2 等环境中验证记忆层影响。  
- **核心贡献**：(1) 避免上下文爆炸的 memory 管理新范式；(2) 可 ablation 单层记忆/技能；(3) 公开 298 条轨迹 + 分析脚本，支持复现。  
- **工程价值**：直接解决长 horizon agent 的 memory bloat 和调试难题，适用于生产 multi-turn agent 系统；benchmark 硬（人类胜率仅16%），工程落地性高。  
- **是否值得读**：**强烈推荐**（agent 系统设计）。  
- **Relevance Score**：5/5  
- **Link**：https://arxiv.org/abs/2607.02255

**【Title】**  
Next-Generation Agentic Reinforcement Learning Systems Enable Self-Evolving Agents (arXiv:2607.01120)

- **一句话总结**：聚焦 agentic online RL 系统基础设施，重构 RL loop 支持生产级 self-evolving agents。  
- **核心贡献**：AReaL2.0 等系统实现，从部署 workload 中在线更新 policy。  
- **工程价值**：桥接 RL 与大规模 agent 部署，解决在线学习系统瓶颈，有实际落地潜力。  
- **是否值得读**：**强烈推荐**（RL + agent 结合）。  
- **Relevance Score**：4/5  
- **Link**：https://arxiv.org/abs/2607.01120

### 3. 其他相关（ReContext 长上下文 harness）
**【Title】**  
ReContext: Recursive Evidence Replay as LLM Harness for Long-Context Reasoning (arXiv:2607.02509)

- **一句话总结**：训练-free 的 recursive evidence replay，利用模型内部 relevance 信号构建 evidence pool 并 replay，提升长上下文利用率。  
- **核心贡献**：分离 evidence 组织与生成；理论分析（associative memory 视角）；多 backbone 实验（Qwen3/Llama3）一致提升。  
- **工程价值**：简单集成到 inference pipeline，无需 finetune，改善 long-context agent/reasoning 实际效果；代码公开。  
- **是否值得读**：**可选**（长上下文实用优化）。  
- **Relevance Score**：4/5  
- **Link**：https://arxiv.org/abs/2607.02509

1. **Lynx (Progressive Speculative Quantization)**：直接击中 disaggregated/long-context inference 的 KV transfer 瓶颈，量化 + speculative 结合，有明确 latency/accuracy 数据，生产部署价值最高。

### 2. 今日趋势观察
Inference 优化（尤其是 KV quantization + transfer）仍有活跃度，结合 disaggregated serving 和长上下文；**LLM Agents** 方向明显增加，重点在 long-horizon memory 管理和 bounded/testbed 系统设计，而非纯 prompting。RL/Alignment 论文较少，更多融入 agentic 系统。

### 3. 值得跟进的潜在方向
- **KV Cache 在 disaggregated/multi-agent 下的网络/存储优化**（quant + speculative + persistence），预计将成为下一波 serving 基础设施热点。
- **Bounded / Structured Memory for Agents**：从 raw context 转向 typed retrieval + replay，降低工程复杂度，提升可调试性，值得持续跟踪系统实现。
