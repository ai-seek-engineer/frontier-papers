【Title】KV-streams for Efficient Compaction in Agentic Reinforcement Learning  
- 一句话总结：把 compaction 后的 KV 往前“流”而不是 flush，让 agentic RL 长轨迹训练吞吐涨 2.6–5×。  
- 核心贡献（2-3点）：  
  - plug-and-play，兼容多种 compaction，避免每次压缩后反复 prefill。  
  - 流式 KV 可当 recurrent state，被压掉的信息仍能被 RL 利用。  
  - 控制实验：不需要额外记忆模块，RL 本身就能学到“用旧 KV”。  
- 工程价值：直接打 agent 训练墙——长 horizon + 反复 compaction 的 prefill 税。可挂到现有 post-training pipeline。  
- 是否值得读：强烈推荐  
- Relevance Score：5  
- Link：https://arxiv.org/abs/2609.35750

【Title】KVCMAS: Efficient KV cache Correction for Shared Context in Multi-Agent Systems  
- 一句话总结：多 Agent 共享上下文时，用低秩状态在线校正各 Agent 前缀导致的 KV 偏差，不必各自重 prefill。  
- 核心贡献（2-3点）：  
  - 沿 Agent workflow 链式校正，不做额外 reference prefill，首 Agent cache 保持精确。  
  - 支持动态变化的共享 context，不只是固定重复前缀。  
  - 并发 serving：相对无共享 ~2.0× TTFT；相对先前 correction 峰值显存最多降 3.7×。  
- 工程价值：MAS / 多角色同一模型是真实 serving 形态。这是 prefix cache 在“角色前缀不同”场景下的可落地补丁。  
- 是否值得读：强烈推荐  
- Relevance Score：5  
- Link：https://arxiv.org/abs/2609.34060

【Title】Nereus: Adaptive Parallelism for LLM Post-Training  
- 一句话总结：RL post-training 运行时按内存/序列/瓶颈动态改 TP/PP，而不是开跑就锁死并行方案。  
- 核心贡献（2-3点）：  
  - Elastic Model Unit + 全局 transition graph，把“换并行计划”做成有代价模型的状态迁移。  
  - 在线 TP/PP 自适应：相对固定布局 + DP 扩容，平均 step latency −27.7%。  
  - 8B PPO：相对 OpenRLHF 2.14–7.27×，相对 Verl 1.10–1.47×；1024 GPU 长跑里 6 次切换只占 0.079% 时间。  
- 工程价值：PPO/GRPO 类作业生成/推理/训练共卡，并行策略会过期。这是调度层而不是算法层的真问题。  
- 是否值得读：强烈推荐  
- Relevance Score：5  
- Link：https://arxiv.org/abs/2609.34645

【Title】Spexis: Speculative Lookahead Scheduling for LLM Inference  
- 一句话总结：把 speculative decoding 做成与正常执行并行的新并行轴，再加 lookahead 调度压无效投机和 KV 驱逐。  
- 核心贡献（2-3点）：  
  - 投机与正常执行并行，不额外涨 KV。  
  - 预测投机质量与未来内存压力，减少浪费 speculative / eviction / recompute。  
  - 基于 vLLM；相对最优 TP+PP 组合最多 +34% serving 性能；代码公开。  
- 工程价值：多卡推理里 PP bubble + KV 压力是日常问题。这是可插 vLLM 的系统工作，不是再发一篇 draft 模型。  
- 是否值得读：强烈推荐  
- Relevance Score：4  
- Link：https://arxiv.org/abs/2609.34370

【Title】Draft-KV: Learning Useful Latent Communication Between Language Models  
- 一句话总结：小模型真正“用上”大模型信息的方式不是传文本，而是传 draft 过程中的 KV，再用极小接口读。  
- 核心贡献（2-3点）：  
  - 证明很多 latent comm 增益来自接口本身，消息可被无关题替换、准确率几乎不动。  
  - Draft-KV：冻结双方，只训 1.05M 参数接口；Qwen3-8B → 0.5B 在 MMLU-Redux 从 37% 到 78%。  
  - 错配消息时准确率崩到接近单独小模型，说明接收端真在读内容。  
- 工程价值：投机/级联/异构模型协作的新接口。训练成本低，但是否进生产要看对齐与延迟。  
- 是否值得读：可选  
- Relevance Score：4  
- Link：https://arxiv.org/abs/2609.34754

【Title】Rethinking Training-Inference Mismatch in LLM Reinforcement Learning  
- 一句话总结：RLVR 里 inference engine 和 training engine 对同一 token 概率不一致，用校准重要性采样（CIS）修。  
- 核心贡献（2-3点）：  
  - 把 mismatch 刻画成近似与置信度无关的 logit 位移。  
  - CIS：按置信度收紧 importance-ratio cap，二阶矩有界。  
  - 三个 MoE + 五个数学基准上，平均分高于对比基线。  
- 工程价值：凡是 vLLM/SGLang rollout + Megatron/FSDP 反传的团队都会撞这个问题。比“再调 KL”更可操作。  
- 是否值得读：可选（偏算法，但对齐/RL infra 必看）  
- Relevance Score：4  
- Link：https://arxiv.org/abs/2609.32444

【Title】ActKV: Efficient LLM Agents through Action-Guided KV Cache Management  
- 一句话总结：按“下一步 action 需要什么”来驱逐/分配 KV，而不是通用 attention score。  
- 核心贡献（2-3点）：  
  - action 导向 eviction + 置信度自适应预算。  
  - page-aware 压缩原语 + 定制 kernel，能进 paged serving。  
  - 长轨迹：25.98% 峰值 KV 保住 98.53% FullKV 精度；token/task 吞吐约 3.6–4.0×。  
- 工程价值：Agent serving 的 KV 模式和 chatbot 不同（观察散、action 关键 token 稀）。比通用 SnapKV 更贴工作负载。提交日略早于 48h，但仍是本周最该跟的 agent-KV 之一。  
- 是否值得读：强烈推荐（若只盯 48h 可标可选）  
- Relevance Score：4  
- Link：https://arxiv.org/abs/2609.31395

【Title】An RL View of OPD: Least Square Policy Distillation for Sample-Efficient LLM Reasoning  
- 一句话总结：把 on-policy distillation 写成 KL-正则 RL，再用最小二乘 + 乐观探索提高样本效率。  
- 核心贡献（2-3点）：  
  - 给 OPD 一个干净的 RL 解释，而不是“再蒸馏一遍”。  
  - 全 off-policy 变体用前 25% rollout 批次就能接近 vanilla OPD。  
  - Pass@k 随 k 增大更稳，多样性保住更好。  
- 工程价值：推理蒸馏成本主要在 rollout。少 75% batch 仍对齐，对 SFT/对齐集群有直接预算含义。  
- 是否值得读：可选  
- Relevance Score：3  
- Link：https://arxiv.org/abs/2609.35505

### 1. 今日最值得读 Top 3
1. **KV-streams**：agent 训练被 compaction-prefill 卡住是正在发生的事；2.6–5× wall-clock 且可插拔。  
2. **KVCMAS**：多 Agent 同模不同前缀，是 prefix cache 失效的真实原因；TTFT/显存数字直接可对 serving SLA。  
3. **Nereus**：RL post-training 的并行策略会在作业中途变坏；自适应 TP/PP + 可忽略的切换开销，比再发一个算法变体更值钱。

### 2. 今日趋势观察
- **Inference / KV 仍是主航道**，但叙事从“再压 2bit”转到 **Agent/MAS 工作负载特化**：共享 context 校正、action-guided eviction、compaction 流式 KV。  
- **RL post-training infra** 明显抬头：自适应并行、train–infer 概率不一致、OPD 的 RL 化。Agent + RL 正在把训练系统重新变成一等公民。  
- 纯量化小改动明显变少，工程论文更爱挂 vLLM / OpenRLHF / Verl。

### 3. 值得跟进的潜在方向
- **KV 作为跨阶段状态，而不只是 cache**：训练里流式 KV（KV-streams）、推理里跨 Agent 低秩校正（KVCMAS）、模型间传 draft KV（Draft-KV）是同一条线——把 KV 当一等通信/记忆对象。  
- **投机从“加速 decode”升级为“并行轴 + 调度器”**（Spexis）：下一步会不会和 prefix cache、PD 分离一起进生产调度。  
- **Agent serving 的工作集规划**：同一周还有 KV working set / 容量规划类工作，说明容量不再按“最大 context × 并发”拍脑袋。``
