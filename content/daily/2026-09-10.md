【Title】Sample-Guided Exact Top-K Selection for Long-Context Sparse Attention  
[arXiv:2609.08450](https://arxiv.org/abs/2609.08450)

- 一句话总结：给长上下文 sparse attention 做**可证明 exact 的 Top-K 选择算子**，而不是再发明一种近似淘汰策略。
- 核心贡献（2-3点）：
  - 用固定步长采样先估行内阈值，再做整行校验 + FP32 精修，保证 exact Top-K。
  - 在 Hy4-Preview indexer 分数上，比已验证 exact baseline 快 1.29–1.75×（几何均值 1.55×）。
  - 代码进 Tencent HPC-Ops。
- 工程价值：sparse attention 的瓶颈经常不是“选哪些 token 的理论”，而是 **ragged score 行上的 exact Top-K kernel**。这是可以直接塞进 serving stack 的算子层工作。
- 是否值得读：强烈推荐（做 inference kernel / DSA 的人）
- Relevance Score：5
- Link：https://arxiv.org/abs/2609.08450

【Title】Online Draft Co-Training for Speculative Decoding in Large-Scale, Long-Context RL Post-Training  
[arXiv:2609.07108](https://arxiv.org/abs/2609.07108)

- 一句话总结：把 speculative decoding 的 draft **在线跟 policy 共训**，并解决长上下文 RL rollout 里 CP/PP 不支持 branch attention 的系统问题。
- 核心贡献：
  - 扩展 packed zigzag ring attention：rank-local branch attn + 主序列 causal attn 合并。
  - TapChannel 把 target 中间特征跨 PP stage 传，不打乱 pipeline schedule。
  - 到 122B、256K token 有实测 rollout / E2E 加速。
- 工程价值：**RL 成本被 rollout 吃掉**时，这是比“再买一倍 GPU”更接近生产的路径。CP+PP 细节比算法口号更有用。
- 是否值得读：强烈推荐（做 RL infra / 长上下文 serving）
- Relevance Score：5
- Link：https://arxiv.org/abs/2609.07108

【Title】Procedural Graphs: Self-Evolving Execution Structures for LLM Agents  
[arXiv:2609.09153](https://arxiv.org/abs/2609.09153)

- 一句话总结：把 agent 的“下一步该干什么”从隐式历史里抽成可演化的 **过程图**，失败轨迹用来改拓扑而不是只写 memory。
- 核心贡献：
  - (procedure, relation, procedure) 作为过程知识单元。
  - 每步用子图生成 situational guidance，不硬编码动作。
  - LLM refiner 对比成败轨迹改图，用 held-out 验证门控提交。
- 工程价值：比再堆一层 scratchpad 更接近 **可审计工作流**。适合工具顺序敏感、长 horizon 会循环调用的生产 agent。
- 是否值得读：强烈推荐（做 agent runtime / 编排）
- Relevance Score：5
- Link：https://arxiv.org/abs/2609.09153

【Title】Co-Evolving Harnesses and Models: On-Policy Correction Helps Weaker Models Catch Up Where Imitation Fails  
[arXiv:2609.09134](https://arxiv.org/abs/2609.09134)

- 一句话总结：先进化弱模型的 harness，再用 **只改失败那一轮的 on-policy expert 修正**，不要整条专家轨迹 SFT。
- 核心贡献：
  - 7 个企业 agent 任务：在已进化 harness 上模仿专家整轨迹会掉 4–30 分。
  - 定位弱模型自己 rollout 的失败 turn，专家只改这一 turn。
  - harness 进化 + 轻量适配可叠加，纯模仿会互相踩。
- 工程价值：这是当前最值钱的 agent 训练教训之一——**harness 变了，专家轨迹分布就偏了**。直接指导“小模型 + 好脚手架”的落地配方。
- 是否值得读：强烈推荐
- Relevance Score：5
- Link：https://arxiv.org/abs/2609.09134

### 1. 今日最值得读 Top 3

1. **2609.08450 Top-K 算子** — 少见的“能进推理引擎”的精确工作；有开源算子库，不是又一篇 eviction heuristic。  
2. **2609.07108 Online Draft Co-Training** — 同时打中 speculative decoding 和 RL rollout 两条最贵路径，并且正面处理 CP/PP，这是系统论文该有的样子。  
3. **2609.09134 Co-Evolving Harnesses** — 负结果极硬：进化后的 harness 上做专家轨迹模仿会全面回退。这对正在“蒸馏 agent 轨迹”的团队是立刻能改训练配方的信号。

### 2. 今日趋势观察

- **Inference / KV / sparse attention 仍是最大流量**，但新稿正从“再设计打分函数”转向 **exact kernel、speculative 与量化/RL 的耦合、以及 prefix cache 的可复现性**。  
- **Agent 论文从 prompt/memory 转向 harness 工程**：过程图、harness 与权重共进化、多 harness RL 的 credit 边界（后者略早于窗口）。  
- **RLVR / TTRL / OPD-then-RL** 继续替代“单阶段混信号”故事；冷启动选数据和阶段切换成为主矛盾，而不是再发明一个 advantage estimator。  
- 纯分布式训练新方法今天偏 **benchmark / overlap 调度 / 压缩通信**，大一统并行策略论文偏少。

### 3. 值得跟进的潜在方向

- **Serving 确定性 vs 量化 + prefix cache**：同请求不同答，4-bit 下轨迹分叉可到 75%。这对 agent 评测和回归测试会变成一等公民问题。  
- **RL rollout 专用 speculative + 超长 CP**：draft 必须在线跟上变化的 policy，标准 SD 栈不够。  
- **Harness 与模型的耦合训练**：先改脚手架再模仿专家是反模式；on-policy 局部修正更可能成为小模型 agent 的默认配方。  
- **Sparse attention 的算子层标准化**：算法论文过剩，生产差距在 exact Top-K / ragged layout / 与现有 paging 的对接。
