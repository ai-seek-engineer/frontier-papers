### Inference / 推理优化

**【Title】**  
Sparse Prefix Caching for Hybrid and Recurrent LLM Serving (arXiv:2605.05219)

- **一句话总结**：针对 SSM/混合架构提出稀疏前缀缓存，仅在关键检查点存储 recurrent state，动态恢复 suffix，平衡内存与精确性。
- **核心贡献**（2-3点）：
  1. 形式化稀疏缓存作为 overlap 分布下的 checkpoint 放置问题，并给出 O(NM) DP 最优解。
  2. 在共享长前缀但非完全相同请求场景下，显著优于 block caching 等启发式，特别在低预算 checkpoint 时收益大。
  3. 与现有 KV 压缩正交，可精确恢复输出，无需新 kernel。
- **工程价值**：高。对 recurrent/hybrid 模型 serving 直接适用，能大幅降低 prefix 缓存内存占用，同时保持 throughput；易集成到 vLLM/SGLang 类系统，适合长文档 QA 等场景。
- **是否值得读**：**强烈推荐**（系统工程师必看）。
- **Relevance Score**：5/5
- **Link**：https://arxiv.org/abs/2605.05219

**【Title】**  
QKVShare: Quantized KV-Cache Handoff for Multi-Agent On-Device LLMs (arXiv:2605.03884)

- **一句话总结**：针对边缘多 agent 系统，提出量化 KV-cache 高效 handoff 机制（token-level mixed-precision + CacheCard），避免昂贵 re-prefill。
- **核心贡献**（2-3点）：
  1. 混合精度分配 + 自包含缓存表示，支持 agent 间上下文传递。
  2. HuggingFace 兼容注入路径，实用性强。
- **工程价值**：高。直接解决 on-device 多 agent 上下文切换内存/延迟痛点，量化降低传输成本，适合移动/边缘部署场景。
- **是否值得读**：**强烈推荐**。
- **Relevance Score**：5/5
- **Link**：https://arxiv.org/abs/2605.03884

**【Title】**  
WindowQuant: Mixed-Precision KV Cache Quantization based on Window-Level Similarity for VLMs Inference Optimization (arXiv ~2605.02262)

- **一句话总结**：VLM KV cache 窗口级相似度驱动的混合精度量化，解决 token 粒度搜索慢和硬件不友好问题。
- **核心贡献**：窗口自适应搜索 + 重排序计算，提升搜索效率和 kernel 友好度，实验优于 SOTA。
- **工程价值**：中高。对视觉语言模型 inference 内存优化实用，尤其长序列视觉 token。
- **是否值得读**：**可选**（VLM 特定）。
- **Relevance Score**：4/5

### LLM Agents / RL

**【Title】**  
SAT: Sequential Agent Tuning for Coordinator Free Plug and Play Multi-LLM Training (arXiv:2605.05216)

- **一句话总结**：无协调器顺序 agent tuning，支持 plug-and-play 升级小模型团队，带单调改进和不变性理论保证。
- **核心贡献**：
  1. 块坐标更新 + sequence-aware advantage + per-agent KL，解决分布漂移。
  2. 理论保证：单调提升 + 任意 agent 升级不需重训其余，性能界改善。
  3. 实验：3×4B 团队超 Qwen3-32B，plug 8B 后进一步提升。
- **工程价值**：高。分布式/多 LLM 系统训练基础设施友好，可扩展，无中心瓶颈，代码公开。
- **是否值得读**：**强烈推荐**。
- **Relevance Score**：5/5
- **Link**：https://arxiv.org/abs/2605.05216

**【Title】**  
BALAR: A Bayesian Agentic Loop for Active Reasoning (arXiv:2605.05386)

- **一句话总结**：Bayesian 外循环 agent，通过最大化互信息选澄清问题，支持结构化多轮交互，无需 fine-tune。
- **核心贡献**：belief 维护 + 动态状态扩展，在侦探/谜题/临床基准大幅优于 baseline（+14-38%）。
- **工程价值**：中。提升 agent 主动信息获取能力，易集成到现有 LLM agent 框架。
- **是否值得读**：**可选**（agent 设计参考）。
- **Relevance Score**：4/5

### 1. 今日最值得读 Top 3（理由）
1. **Sparse Prefix Caching** — 直接解决 recurrent/hybrid serving 内存痛点，有最优 DP 算法 + Pareto 实证，系统落地潜力最大。
2. **SAT (Sequential Agent Tuning)** — 多 LLM/agent 训练的工程突破（plug-and-play + 理论保证），实验强，代码可用。
3. **QKVShare** — 边缘多 agent 实际部署瓶颈（handoff），量化 + 实用实现，立即可用性高。

### 2. 今日趋势观察
Inference 优化持续热门（KV 量化、prefix caching、speculative 变体），但多为增量；**Agent + RL** 方向活跃度上升，尤其多 agent 协调/训练（orchestration、sequential tuning、Bayesian loop），反映落地从单 agent 向团队演进。分布式训练/ infra 论文较少。

### 3. 值得跟进的潜在方向
- **Recurrent/SSM + sparse state caching**：混合架构 serving 优化空间大，可能成为下一代高效 inference 主流。
- **Plug-and-play multi-agent tuning**：降低协调成本，推动真正可扩展 agent 系统，结合 RL 痕迹优化值得关注。
- **边缘/On-device multi-agent KV handoff**：随设备侧 LLM 增长，量化上下文共享将成为瓶颈，需更多系统工作。
