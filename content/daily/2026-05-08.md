### 【Inference / 推理优化】

**【Title】**  
Parallel Prefix Verification for Speculative Generation (PARSE)  

- **一句话总结**：通过并行前缀验证（semantic/segment-level）突破传统token-by-token验证瓶颈，实现高效推测解码加速。  
- **核心贡献**（2-3点）：1) 自定义attention mask单次forward pass并行验证多个前缀，直接找max valid prefix；2) 与EAGLE-3等token-level方法正交组合；3) 跨模型/基准1.25-4.3× throughput（组合后更高），准确性损失可忽略。  
- **工程价值**：直接提升serving throughput，降低decode latency，适用于生产级长上下文/高并发场景；实现简单，可集成现有speculative框架，无需额外训练大改动。  
- **是否值得读**：**强烈推荐**  
- **Relevance Score**：5/5  
- **Link**：https://arxiv.org/abs/2605.04263

**【Title】**  
QKVShare: Quantized KV-Cache Handoff for Multi-Agent On-Device LLMs  

- **一句话总结**：针对边缘多Agent上下文切换，提出量化KV cache handoff框架（token-level mixed-precision + CacheCard），避免昂贵re-prefill。  
- **核心贡献**（2-3点）：1) 自包含CacheCard表示+HF兼容注入路径；2) 自适应量化，在多hop handoff下优于uniform量化；3) 显著降低TTFT（e.g., 8K上下文下~60%+改善）。  
- **工程价值**：边缘/多Agent部署关键痛点解决，降低内存/延迟开销；对on-device compound AI系统有直接落地价值，尤其多轮tool-use场景。  
- **是否值得读**：**强烈推荐**  
- **Relevance Score**：5/5  
- **Link**：https://arxiv.org/abs/2605.03884

### 【AI Infra / 系统优化】

**【Title】**  
A Queueing-Theoretic Framework for Stability Analysis of LLM Inference with KV Cache Memory Constraints  

- **一句话总结**：首个显式建模compute + KV cache内存双约束的排队论框架，提供LLM serving稳定性条件与集群 sizing指导。  
- **核心贡献**（2-3点）：1) 推导rigorous stability/instability条件；2) 实验验证偏差<10%；3) 直接用于避免over/under-provisioning。  
- **工程价值**：生产部署核心工具，帮助准确估算GPU需求、控制SLO，尤其KV-bound长上下文场景；理论+实证结合强。  
- **是否值得读**：**强烈推荐**  
- **Relevance Score**：5/5  
- **Link**：https://arxiv.org/abs/2605.04595

**【Title】**  
Design Conductor 2.0: An agent builds a TurboQuant inference accelerator in 80 hours  

- **一句话总结**：多Agent系统自主从论文生成硬件加速器（VerTQ，支持TurboQuant的240-cycle pipeline FPGA设计）。  
- **核心贡献**（2-3点）：1) 显著提升Agent设计能力（80x更大任务）；2) 端到端硬件生成示例（compute-heavy，TSMC面积/频率数据）；3) 分析token使用与局限。  
- **工程价值**：展示Agent-driven hardware co-design潜力，对custom inference accelerator开发有启发；虽非通用serving优化，但指向未来自动化infra方向。
