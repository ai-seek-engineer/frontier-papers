### 【Model Inference / KV Cache 优化】

**【Title】** Leyline: KV Cache Directives for Agentic Inference (arXiv:2606.01065)

- **一句话总结**：针对 Agentic 工作流（非纯 append-only）的 KV cache 编辑原语，支持策略驱动的 splice/trim 操作，避免全 re-prefill。
- **核心贡献**（2-3点）：1) 声明式 4-tuple directive（what to edit + mode），与 kernel 解耦；2) RoPE-rotation 闭式修正保持位置正确性；3) 实验显示 splice 提升 cache-hit +11.2pp，latency 降至 241ms，agent solve rate +14.3pp（debug-gym）。
- **工程价值**：**高**。直接解决多轮 Agent 中 tool-fail retry / trajectory pivot 的 cache 失效问题，可集成到 vLLM/SGLang 等 serving 系统，减少内存压力和 recompute 开销，适用于生产级 agent 部署。
- **是否值得读**：**强烈推荐**（系统设计 + 实际 benchmark）。
- **Relevance Score**：5/5
- **Link**：https://arxiv.org/abs/2606.01065

**【Title】** MomentKV: Closing the Directional Gap in KV Cache Eviction for Long-Context Inference (arXiv:2606.01563)

- **一句话总结**：改进 KV eviction，解决传统方法中“方向性偏差”（仅考虑过去/未来单一方向），提升长上下文保留质量。
- **核心贡献**：双向/多时刻重要性评估 + eviction 策略，减少信息丢失。
- **工程价值**：**高**。长上下文 inference（>32k）下的内存优化，直接降低峰值 KV footprint，支持更长序列或更高并发，易与现有 PagedAttention 结合。
- **是否值得读**：**强烈推荐**。
- **Relevance Score**：4.5/5
- **Link**：https://arxiv.org/abs/2606.01563

### 【LLM Agents（系统设计）】

**【Title】** SparseX: Efficient Segment-Level KV Cache Sharing for Interleaved LLM Serving (arXiv:2606.01751)

- **一句话总结**：段级 KV 共享机制，支持多轮/跨 Agent/RAG 的非前缀重复内容复用，集成 Sparse-KV 重计算。
- **核心贡献**：1) 段级缓存查找 + RoPE 对齐；2) Full-sparse 混合 attention（早期层 full，后期 sparse）；3) vLLM 实现，训练-free。
- **工程价值**：**高**。Agent 场景下 interleaved serving 常见，显著提升 cache 命中率和 throughput，兼容现有 infra。
- **是否值得读**：**强烈推荐**。
- **Relevance Score**：5/5
- **Link**：https://arxiv.org/abs/2606.01751 (或相关)

**【Title】** Exploring Agentic Tool-Calling Decisions via Uncertainty-Aligned Reinforcement Learning (arXiv:2606.06976)

- **一句话总结**：用 uncertainty-aligned RL 优化 Agent tool-calling 决策，提升可靠性。
- **核心贡献**：RL 框架对 tool 选择建模 uncertainty，减少 hallucinated calls。
- **工程价值**：**中高**。Agent 系统落地关键痛点（tool misuse），可作为 policy 模块集成到 multi-agent serving 中。
- **是否值得读**：**可选**（偏 RL，但有系统集成潜力）。
- **Relevance Score**：4/5
- **Link**：https://arxiv.org/abs/2606.06976
