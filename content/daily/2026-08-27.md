### 1. Model Inference / 推理优化

**【Title】** More GPUs or a Smaller Cache? Tensor Parallelism versus KV Compression for Memory-Bound LLM Serving  
**arXiv:2608.23962**（2026-08-25）

- 一句话总结：在 memory-bound serving 场景下，系统性地对比 Tensor Parallelism（TP）与 KV compression，量化两者在 cost/latency 上的真实权衡。
- 核心贡献（2-3点）：
  - 用 profiled simulator（校准 A100/A40/H100）把 TP（1–8）和 KV 压缩（16/8/4-bit，keep-ratio 低至 0.25）放在统一 cost-normalized 轴上比较。
  - 结论：压缩在 capacity/$ 上始终更优（1.2–2×），TP 只在 latency 上有优势；约 36B 参数是 80GB 卡上的策略分界点。
  - 量化了压缩带来的 per-token latency 恶化（8–93%）与 batching 争用。
- 工程价值：直接可指导生产决策——何时该加卡做 TP、何时该上 KV 压缩/量化。对 vLLM/SGLang 类系统的 capacity planning 和 cost 模型有强参考。
- 是否值得读：强烈推荐
- Relevance Score：5
- Link：https://arxiv.org/abs/2608.23962

**【Title】** Minima-KV: Retention-Preserving KV Cache Compression with Mixed-Format Paged Attention  
**arXiv:2608.23834**（2026-08-24）

- 一句话总结：混合精度 paged attention（最近/保护页 FP8 + 旧页 TQ3），在无 dense shadow 的情况下实现高压缩且质量几乎无损。
- 核心贡献：
  - 格式特异 kernel + online-softmax merge，支持异构直接 decode。
  - 实测 18.3 KiB/token（相对 BF16 3.5×，相对 FP8 1.75×）；LongBench v2 质量损失 ≤0.8pp；单 pair 59k 上下文吞吐接近 baseline。
- 工程价值：可落地的 mixed-format paged KV 设计，对长上下文 serving 的 HBM 压力缓解有直接价值，kernel 级实现细节值得参考。
- 是否值得读：强烈推荐
- Relevance Score：5
- Link：https://arxiv.org/abs/2608.23834

### 2. LLM Agents（系统设计 + 推理）

**【Title】** AgentSpec: Speculative Decoding for Batch Inference of LLM Agents  
**arXiv:2608.24004**（2026-08-25）

- 一句话总结：针对 LLM Agent 的 batch 推理，提出结构隔离 drafting + 冗余感知 budget 分配，解决现有 speculative decoding 在大 batch 下加速崩塌的问题。
- 核心贡献：
  - 分析了 Agent 场景下高 rejection rate 与动态 token budget 未充分利用两大瓶颈。
  - Structure-isolated drafting 把 speculation 限制在语义连贯 segment，大幅降低无用 draft。
  - 在 vLLM 上实现，覆盖 5 个 workload、4 个模型家族，显著改善大 batch 加速。
- 工程价值：Agent serving 的实际痛点（多工具调用、结构化输出、长 horizon）直接相关；可直接集成到现有 speculative 框架。
- 是否值得读：强烈推荐
- Relevance Score：5
- Link：https://arxiv.org/abs/2608.24004

### 【额外输出】

**1. 今日最值得读 Top 3**
1. **More GPUs or a Smaller Cache?** — 把 TP vs KV compression 的成本/延迟权衡量化到可决策层面，是当前 serving 最痛的决策之一。
2. **Minima-KV** — mixed-format paged attention 的工程实现完整，质量-压缩 Pareto 漂亮，可直接指导生产 KV 系统。
3. **AgentSpec** — 第一次系统解决 Agent batch + speculative 的加速崩塌问题，对 agent serving 栈价值极高。

**2. 今日趋势观察**
- **Inference / KV 方向明显集中**：过去 48 小时 KV compression、paged mixed-format、TP vs compression 对比、sparse prefetch 密集出现，说明 HBM 压力与长上下文仍是第一工程瓶颈。
- Agent 相关 speculative 开始出现专门设计（不再是通用 speculative 直接套用），说明 agent serving 已进入系统优化阶段。
- 纯 RLHF/Alignment 新作偏少，更多是 agentic RL 与 harness 控制，但落地密度仍低于 inference。

**3. 值得跟进的潜在方向**
- **Agent-aware speculative decoding + structure isolation**：AgentSpec 只是起点，后续可结合 tool-call 边界、memory 状态、verification loop 做更细粒度 budget 与 draft 控制。
- **Cost-normalized multi-strategy KV 决策**（TP / 量化 / eviction / offload）：把“加卡还是压缩”做成 runtime 可配置的 cost model，是生产系统下一步必然需求。
- **Mixed-format / hierarchical KV + 无 dense shadow 的 kernel 路径**：Minima-KV 的方向若能标准化到 vLLM/FlashAttention 生态，会显著降低长上下文部署成本。
