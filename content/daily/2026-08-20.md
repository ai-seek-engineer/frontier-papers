### 1. Model Inference / 推理优化

**【Title】** KV Cache Compression Through the Lens of Transform Coding  
**arXiv:2608.14191**（2026-08-14）

- **一句话总结**：用经典 transform coding + reverse water-filling 从 attention 感知失真出发分配比特，实现近无损 5.8× KV 压缩。  
- **核心贡献**：  
  1. 证明 white-noise 量化模型下 attention-aware 失真可分解为 key/value 的 token+channel 可加贡献。  
  2. 提出 AATC，在校准集上做率失真最优比特分配，而非传统 reconstruction error。  
  3. 在 LongBench / RULER / GSM8K / MMLU-Pro / MATH-500 上对 Llama-3.1-8B 与 Qwen-2.5-7B 保持近无损。  
- **工程价值**：直接可落地于现有量化 serving 路径（vLLM/SGLang 等），比现有 KIVI / KVQuant 等更 prioritizes attention 而非 cache MSE，对长上下文 + 多 batch 场景的 HBM 压力缓解明确。  
- **是否值得读**：强烈推荐  
- **Relevance Score**：5  
- **Link**：https://arxiv.org/abs/2608.14191

**【Title】** Aborted but Not Forgotten: KV-Cache Retention Breaks Rollback Consistency in Language Agents  
**arXiv:2608.15939**（2026-08-16）

- **一句话总结**：揭示 agent 逻辑 rollback 与 serving 层 KV 保留之间的跨层一致性漏洞，并提出 transaction-local 修复。  
- **核心贡献**：  
  1. 形式化 “rollback consistency”：完整 abort 必须恢复 model 实际 attend 的状态，而非仅 transcript。  
  2. 设计 same-token/different-cache audit，跨 7 个开源模型族（3.8B–36B）证明保留 KV 单独即可翻转受保护行为（25/63 cells）。  
  3. 在 HF Transformers 默认 cache-reuse、LangGraph time-travel 中复现，并给出无需全局 flush 的修复。  
- **工程价值**：对 agent 系统（尤其带分支/回滚的 LangGraph / 自定义 session）是硬 bug，直接影响正确性与安全；修复成本低，可直接改 serving session 管理。  
- **是否值得读**：强烈推荐（系统安全视角）  
- **Relevance Score**：5  
- **Link**：https://arxiv.org/abs/2608.15939

### 2. AI Infra / 分布式训练 / 系统优化

**【Title】** OpScale: Operator-level Provisioning and Autoscaling for LLM Serving  
**arXiv:2608.13499**（2026-08-13）

- **一句话总结**：把 autoscaling 粒度从整个模型下沉到 operator 级，显著降低 GPU/功耗同时保 SLO。  
- **核心贡献**：  
  1. 刻画 operator 异构性，证明 operator-level elasticity 可行。  
  2. 完整框架：profiling → provisioning → placement → runtime，解决细粒度带来的空间爆炸问题。  
  3. 生产 trace + 40×A100 / 24×GB200：同等 SLO 下最多少用 36.3% GPU、28% 功耗，或固定成本下吞吐 +44%。  
- **工程价值**：直接解决 cloud LLM serving 的成本-SLO 矛盾，比 monolithic 模型级 scaling 更细粒度，适合生产集群调度器集成。  
- **是否值得读**：强烈推荐  
- **Relevance Score**：5  
- **Link**：https://arxiv.org/abs/2608.13499

**【Title】** From LLM Inference to Agentic Workloads: Characterization and Implications for Serving Systems  
**arXiv:2608.15127**（2026-08-15）

- **一句话总结**：系统刻画 agentic 工作负载与传统 LLM inference 的 6 大差异，并给出可落地设计探索。  
- **核心贡献**：  
  1. 发布 AgentSysBench（10 类代表应用 + 统一系统级 instrumentation）。  
  2. 发现：非 LLM 组件主导延迟、异构资源亲和性（延迟差可达 32×）、session 空闲长达数小时、control-plane tax、跨请求冗余可缓存等。  
  3. 四个设计探索：task-aware serving（延迟 -29–40%）、communication-aware placement（最高 4.5×）、state offloading（内存 -4.6×）、tool-result caching（冗余搜索 -35%）。  
- **工程价值**：为 agent serving 系统提供真实瓶颈数据与可立即试验的优化方向，比纯 inference 假设更贴近生产。  
- **是否值得读**：强烈推荐  
- **Relevance Score**：5  
- **Link**：https://arxiv.org/abs/2608.15127

### 3. LLM Agents

**【Title】** How Do Agents Fail on AutoResearch: End-to-End Diagnostic Evaluation on 100 Real-World Frontier Research Tasks  
**arXiv:2608.14905**（2026-08-18）

- **一句话总结**：对 100 个真实前沿研究任务做端到端 agent 失败诊断，并开源 AutoResearchEval + ARFT。  
- **核心贡献**：  
  1. 真实研究工作流（而非玩具任务）上的系统性失败模式分析。  
  2. 公开 benchmark 与失败 taxonomy，便于后续 agent scaffold 改进。  
- **工程价值**：对做 research agent / AutoResearch 系统的团队直接可用，失败模式可指导 harness、memory、tool-use 设计。  
- **是否值得读**：可选（诊断价值高，但方法创新一般）  
- **Relevance Score**：4  
- **Link**：https://arxiv.org/abs/2608.14905

### 4. SFT / Alignment / RLHF

**【Title】** Policy Iteration with Human Feedback: Bringing Post-Training RL to In-context Learning  
**arXiv:2608.16831**（2026-08-17）

- **一句话总结**：把 policy iteration 搬到自然语言 policy + 固定权重 LLM 执行器上，用专家反馈迭代修订。  
- **核心贡献**：  
  1. PIHF：用 LM critic + 临床专家定位失败，修订自然语言 policy/tool set，而非改模型权重。  
  2. 在超罕见疾病诊断任务上，对 GPT-5.4 与 Qwen3.6-35B 等 Recall@1 提升 31–33 个百分点。  
- **工程价值**：对需要高可靠性、可审计、专家可干预的垂直 agent 有价值；避免每次都 fine-tune，降低部署成本。  
- **是否值得读**：可选  
- **Relevance Score**：3.5  
- **Link**：https://arxiv.org/abs/2608.16831

**2. 今日趋势观察**  
- **Inference + Agentic 交叉** 明显升温：KV cache 的正确性/一致性问题（rollback）开始被认真对待，agentic 工作负载的系统特性刻画也从“假设”转向实测。

- **Attention-aware 比特分配**：从 reconstruction 转向 attention distortion 的量化范式，有望成为下一代 KV 压缩默认思路。
