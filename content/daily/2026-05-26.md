### 【Model Inference / 推理优化】

**【Title】** PRESERVE: Prefetching Model Weights and KV-Cache in Distributed LLM Serving (arXiv:2501.08192v2, 更新/相关讨论近期)

- **一句话总结**：在分布式LLM serving中，通过在collective communication（如allreduce）期间异步prefetch model weights和KV-cache到on-chip cache（L2/L3），隐藏HBM内存访问延迟。
- **核心贡献**（2-3点）：
  1. 利用现代AI加速器日益增长的on-chip cache容量，实现compute-communication-memory overlap。
  2. 在tensor-parallel设置下提供显著端到端加速（实验达1.6x），并通过设计空间探索优化cache大小以提升perf/cost。
  3. 与现有TP/通信优化正交，适用于大规模集群。
- **工程价值**：**高**。直接针对分布式推理的memory bandwidth和communication bottleneck，能集成到vLLM/SGLang等引擎中，提升H100/GB200等硬件利用率，尤其适合长上下文或高吞吐场景。代码/实现线索强（性能模型+实验）。
- **是否值得读**：**强烈推荐**（系统工程师必看）。
- **Relevance Score**：5/5
- **Link**：https://arxiv.org/abs/2501.08192

### 【LLM Agents（系统设计/落地）】

**【Title】** Parallel Context Compaction for Long-Horizon LLM Agent Serving (arXiv:2605.23296)

- **一句话总结**：针对长时序Agent对话历史爆炸问题，提出parallel compaction机制（而非sequential summarization），实现可控、低延迟上下文压缩。
- **核心贡献**（2-3点）：
  1. 并行块级压缩，提供细粒度volume控制和prompt engineering，避免sequential阻塞与lossy不稳定。
  2. 在8B-120B模型（dense/MoE）上基准HotpotQA和LoCoMo，匹配decode volume时降低wall time、提升throughput。
  3. 量化不同backbone下的可预测性改进。
- **工程价值**：**高**。直接解决生产级长horizon Agent serving的context window与latency痛点，可集成到serving框架中，支持更长任务而无需频繁重计算KV。实验覆盖多模型，复现性好。
- **是否值得读**：**强烈推荐**。
- **Relevance Score**：5/5
- **Link**：https://arxiv.org/abs/2605.23296

**【Title】** SkillOpt: Executive Strategy for Self-Evolving Agent Skills (arXiv:2605.23904)

- **一句话总结**：将Agent skill作为“外部可训练状态”，用独立optimizer模型基于rollout反馈生成可验证的text edits，实现稳定、可复现的skill进化。
- **核心贡献**（2-3点）：
  1. 引入textual learning-rate、rejected buffer、meta-update等机制，保证skill优化像weight optimization一样稳定。
  2. 大规模benchmark（6个任务、7个模型、多种harness）中全面超越human/one-shot/现有evolving方法，平均提升19-24+点。
  3. 优化后的skill artifact支持跨模型/环境transfer。
- **工程价值**：**中高**。为Agent系统提供可落地、可维护的skill管理框架，减少手动prompt工程，适合生产迭代。零额外inference开销。
- **是否值得读**：**强烈推荐**（尤其Agent开发者）。
- **Relevance Score**：4.5/5
- **Link**：https://arxiv.org/abs/2605.23904

**【Title】** Agentic Proving for Program Verification (arXiv:2605.23772)

- **一句话总结**：评估Claude Code等agentic系统在Lean 4程序验证基准CLEVER上的表现，展示tight compiler-in-the-loop范式的高效性。
- **核心贡献**（2-3点）：
  1. 高成功率（spec生成98.8%、end-to-end 98.1%在一致前提下），并提供高质量self-feedback。
  2. 指出现有benchmark与现代agent能力不匹配，建议更rigorous评估方法。
- **工程价值**：**中**。为代码Agent/验证工具链提供实证基准，推动Agent在软件工程落地；highlight compiler-loop重要性，对系统设计有参考。
- **是否值得读**：**可选**（偏Agent+formal verification交叉）。
- **Relevance Score**：3.5/5
- **Link**：https://arxiv.org/abs/2605.23772
