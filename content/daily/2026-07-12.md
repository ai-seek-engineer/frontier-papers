### Model Inference / 推理优化

**【Title】**  
A Practical Investigation of Training-free Relaxed Speculative Decoding (arXiv:2607.08690)

- **一句话总结**：系统调研/基准training-free relaxed speculative decoding，统一框架下评估速度-能力权衡，揭示实际部署洞见。  
- **核心贡献**（2-3点）：1) 统一现有relaxed方法框架；2) 大规模benchmark当代设置（包括生产batch），量化capability-speed tradeoff；3) 关键takeaway：relaxation需仔细capability eval，许多方法依赖强drafter，不适合轻量MTP drafter。  
- **工程价值**：直接用于推理加速（speculative decoding核心），无训练开销，适合vLLM/SGLang等serving栈集成；提供实践指南，避免盲目relaxation导致质量掉坑。  
- **是否值得读**：**强烈推荐**（工程师必读的实用调查）。  
- **Relevance Score**：5/5  
- **Link**：https://arxiv.org/abs/2607.08690

**【Title】**  
Fractal KV-Cache Archives: Lossless Symbolic Storage with In-Place Retrieval for Long-Context LLM Inference (arXiv:2607.07144)

- **一句话总结**：针对量化后KV符号流，提出fractal iterated-map编码实现无损、O(1)随机访问/追加的archive，同时支持内置近似搜索。  
- **核心贡献**（2-3点）：1) Lossless符号存储+线性时间/O(1) append&access；2) GPT-2实验：结合residual VQ + small exact window，实现36-54x压缩（perplexity代价可控），keys vs values不对称量化洞见；3) Archive即search index，支持无需materialize文本的substring query。  
- **工程价值**：极高——长上下文inference内存/存储瓶颈的实用新原语，可与现有量化+eviction结合；代码开源（laptop CPU可复现），易集成serving系统。  
- **是否值得读**：**强烈推荐**。  
- **Relevance Score**：5/5  
- **Link**：https://arxiv.org/abs/2607.07144 (代码：github链接在论文中)

### AI Infra / 系统优化

**【Title】**  
Towards Efficient Large Language Model Serving: A Survey on System-Aware KV Cache Optimization (arXiv:2607.08057, ACL 2026 Findings)

- **一句话总结**：系统视角综述KV cache优化，从execution/scheduling（temporal）、placement/migration（spatial）、representation/retention（structural）三维组织，分析cross-behavior co-design。  
- **核心贡献**（2-3点）：1) 结构化现有工作，突出系统行为驱动的设计；2) 行为-目标关联分析；3) 指出未来infra机会（如分布式/动态场景）。  
- **工程价值**：serving工程师必备地图，帮助诊断KV瓶颈、选择/组合技术（paged、layer-wise、compression等），指导下一代infra构建。  
- **是否值得读**：**强烈推荐**（系统视角高密度总结）。  
- **Relevance Score**：5/5  
- **Link**：https://arxiv.org/abs/2607.08057

### LLM Agents

**【Title】**  
Remember When It Matters: Proactive Memory Agent for Long-Horizon Agents (arXiv:2607.08716)

- **一句话总结**：为长时序agent引入独立proactive memory agent，动态从轨迹更新结构化memory并选择性注入reminder，缓解behavioral state decay。  
- **核心贡献**（2-3点）：1) Plug-and-play memory模块，与现有action agent解耦；2) Terminal-Bench/τ-Bench显著提升（+6-8pp pass@1），ablation验证selective intervention优越性；3) SFT+GRPO训练memory policy，部分迁移成功。  
- **工程价值**：直接提升生产级长horizon agent可靠性（工具调用、multi-step reasoning），易集成现有framework；memory bank设计有实际落地价值。  
- **是否值得读**：**强烈推荐**。  
- **Relevance Score**：4/5  
- **Link**：https://arxiv.org/abs/2607.08716
