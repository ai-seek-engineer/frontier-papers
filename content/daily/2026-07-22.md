### 【Model Inference / 推理优化】
**【Title】**  
Mix-Quant: Quantized Prefilling, Precise Decoding for Agentic LLMs (arXiv ~2026-05, 近期相关讨论活跃)

- **一句话总结**：针对Agentic长上下文多轮prefill瓶颈，提出phase-aware量化：在prefill用NVFP4高吞吐量化，decoding保持BF16精度，平衡效率与稳定性。  
- **核心贡献**（2-3点）：1) 识别Agent workflows中prefill重计算 vs. decoding误差累积的tradeoff；2) 混合量化+硬件NVFP4支持，实现prefill ~3x加速；3) 在LongBench/Agent benchmarks上接近baseline性能，优于uniform量化。  
- **工程价值**：**高**。直接适用于Agent serving的prefill瓶颈优化，易集成vLLM/SGLang等，无需重训。量化策略+benchmark数据支持生产部署，降低长上下文Agent成本。  
- **是否值得读**：**强烈推荐**  
- **Relevance Score**：5/5  
- **Link**：arXiv:2605.20315 (及相关实现讨论)

**【Title】**  
Value-Aware Stochastic KV Cache Eviction for Reasoning Models (VaSE)

- **一句话总结**：为Reasoning模型长输出设计training-free KV eviction，优先保留大magnitude value states并引入stochasticity，提升稀疏KV下的准确性。  
- **核心贡献**（2-3点）：1) 发现value magnitude对reasoning的关键性（优于传统attention-based heuristics）；2) VaSE在4x压缩下优于SOTA eviction ~4-5%；3) GSM8K等任务显著提升，泛化到quantization。  
- **工程价值**：**高**。无需训练即可集成到现有推理引擎（vLLM等），针对CoT/Agent reasoning的KV内存瓶颈，提供可量化性能提升，适合长horizon部署。  
- **是否值得读**：**强烈推荐**  
- **Relevance Score**：5/5  
- **Link**：arXiv ~2606.03928

### 【AI Infra / 分布式训练 / 系统优化】
**【Title】**  
RolloutPipe: Overlapping Pipelined Rollout and Training in Disaggregated On-Policy LLM RL

- **一句话总结**：针对disaggregated RLVR系统，通过complete-group pipelining (CGP)和frontier-group dispatch (FGD)实现rollout与training overlap，同时保持on-policy。  
- **核心贡献**（2-3点）：1) 解决异步pipeline的stale data问题；2) Qwen3-1.7B上缩短end-to-end时间30-42%，大幅降低trainer等待；3) 跨多种rollout设置验证。  
- **工程价值**：**高**。直接优化RL post-training infra（尤其是Agentic RL），适用于分布式disaggregated setup，减少等待/提升硬件利用率，有代码级pipeline实现线索。  
- **是否值得读**：**强烈推荐**  
- **Relevance Score**：5/5  
- **Link**：arXiv:2606.26997

**【Title】**  
EfficientRollout: System-Aware Self-Speculative Decoding for RL Rollouts

- **一句话总结**：为RL rollout设计self-SD框架，使用target-induced quantized drafter + dynamic toggling + adaptive budgets，减少生成延迟。  
- **核心贡献**（2-3点）：1) 共享KV cache + quantized self-SD，无需额外drafter训练；2) rollout gen latency降~19.6%，end-to-end step ~12.7%；3) 适配veRL/vLLM等。  
- **工程价值**：**高**。针对RL训练中rollout瓶颈的系统优化，易集成现有RL infra，提升on-policy训练效率，benchmark支撑强。  
- **是否值得读**：**强烈推荐**  
- **Relevance Score**：4/5  
- **Link**：arXiv ~2606.18967

### 【LLM Agents（实际落地/系统设计）】
**【Title】**  
SmoothAgent: Efficient Long-Horizon LLM-Based Agent Serving with Lookahead Context Engineering (近期Agent serving优化)

- **一句话总结**：针对Agent多轮context transformation开销，提出lookahead execution +异步编程模型，提前处理KV无效化，降低TTFT。  
- **核心贡献**（2-3点）：1) 识别transformation作为Agent serving关键瓶颈；2) PD disagg环境下TTFT降~64.5%；3) 兼容SGLang/radix cache等。  
- **工程价值**：**高**。生产级Agent serving系统设计，直接缓解长horizon动态workflow的内存/延迟问题，有实现细节支持部署。  
- **是否值得读**：**强烈推荐**  
- **Relevance Score**：4/5  
- **Link**：arXiv ~2607.00151

### 1. 今日最值得读 Top 3（理由）
1. **Mix-Quant**：Agentic inference的phase-aware量化直接击中生产痛点（prefill瓶颈），工程集成门槛低，性能数据扎实——立即可用于优化现有Agent服务。  
2. **RolloutPipe**：RL/AI Infra的pipeline overlap创新，显著提升分布式训练效率，对Agentic RL post-training有落地价值。  
3. **VaSE**：KV eviction的value-aware + stochastic方法，training-free且针对reasoning模型，性价比高，易验证复现。

### 2. 今日趋势观察
Inference优化（尤其是KV cache管理、phase/quantization-aware for Agents）和Agentic RL Infra（rollout/training overlap、serving）明显活跃。Agent workflows的长上下文+多轮特性正驱动系统级创新，从纯token优化转向端到端pipeline/动态管理，分布式disagg + speculative技巧融合增多。

### 3. 是否出现“值得跟进的潜在方向”
**是**：**Phase-aware / Service-aware KV与Agent serving的深度融合**（prefill/decoding分离 + dynamic eviction/prediction-based reuse）。这正从通用inference向Agent-specific infra演进，结合RL rollout优化，可能催生下一代高效长horizon Agent系统。建议跟踪disagg + lookahead KV的交叉工作，潜在高工程回报。
