### 【Model Inference / KV Cache 优化】

**【Title】**  
PRESERVE: Prefetching Model Weights and KV-Cache in Distributed LLM Serving

- **一句话总结**：在 tensor-parallel 分布式推理中，通过将 HBM 到 on-chip cache 的 prefetch 与 collective communication 操作重叠，隐藏内存访问延迟。
- **核心贡献（2-3点）**：
  1. 提出训练-free 的 prefetch 框架，同时处理 model weights 和 KV-cache。
  2. 与 allreduce 等通信并行执行，显著降低有效 latency。
  3. 在多设备集群上验证了随设备数增加的 speedup 趋势。
- **工程价值**：**高**。直接针对生产级分布式 LLM serving 的 memory bandwidth bottleneck，可集成到 vLLM/HF 等 serving 框架中，提升 throughput，尤其适合长上下文或高并发场景。实测有明显 latency 隐藏效果。
- **是否值得读**：**强烈推荐**
- **Relevance Score**：5/5
- **Link**：https://arxiv.org/abs/2501.08192 (v2 更新)

**【Title】**  
R-KV: Redundancy-aware KV Cache Compression for Training-Free Reasoning Models Acceleration

- **一句话总结**：针对 reasoning 模型中 token 冗余特性，提出 training-free 的 redundancy-aware KV eviction 策略，使用 max pooling 等技巧提升鲁棒性。
- **核心贡献（2-3点）**：
  1. 专为 reasoning rollout 设计，识别并压缩冗余 token。
  2. training-free + model-agnostic，可直接用于 RL rollout 和 serving。
  3. 提供内存节省与性能 trade-off 实验。
- **工程价值**：**高**。Reasoning 模型（如 o1-style）KV cache 爆炸是当前痛点，此方法可直接降低内存占用，提升 throughput，尤其适合 inference-time scaling。
- **是否值得读**：**强烈推荐**
- **Relevance Score**：4.5/5
- **Link**：https://arxiv.org/abs/2505.24133

### 【AI Infra / 分布式系统】

**【Title】**  
KVDirect: Distributed Disaggregated LLM Inference (近期相关更新讨论)

- **一句话总结**：优化 KV cache 在 disaggregated（计算-存储分离）架构下的传输效率，解决跨节点 KV 移动开销。
- **核心贡献（2-3点）**：
  1. 针对 disaggregated setup 的 KV transfer 优化。
  2. 平衡 bandwidth 和 latency，支持更大规模 serving。
  3. 与传统 colocated 部署对比的系统实验。
- **工程价值**：**中高**。对追求资源利用率和弹性 scaling 的云 infra 团队有直接参考价值，可降低 GPU 碎片化问题。
- **是否值得读**：**可选**（若你在做 disaggregated serving）
- **Relevance Score**：4/5
- **Link**：https://arxiv.org/abs/2501.14743

### 【LLM Agents】

**【Title】**  
LRAgent: Efficient KV Cache Sharing for Multi-LoRA LLM Agents

- **一句话总结**：针对 multi-LoRA agent 场景，设计 KV cache 共享机制，减少重复 prefill 开销。
- **核心贡献（2-3点）**：
  1. BaseLRShared 等共享策略，在 qv/qkvo 配置下平衡 accuracy 与 throughput。
  2. 针对 agent 多步交互的 TTFT（time-to-first-token）优化。
  3. 与 DroidSpeak 等 baseline 的实证对比。
- **工程价值**：**中高**。多 agent 或 multi-LoRA 生产部署中，cache 复用是关键 bottleneck，此工作提供实用共享方案。
- **是否值得读**：**强烈推荐**（若涉及 agent serving）
- **Relevance Score**：4.5/5
- **Link**：https://arxiv.org/abs/2602.01053
