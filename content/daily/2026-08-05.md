### 1. InferScale: GPU-Native KV Injection for Personalized LLM Serving
- **一句话总结**：把个性化memory事实的KV预计算并存GPU，serving时直接注入vLLM paged cache，彻底摆脱重复prefill。
- **核心贡献**：
  - Chunked RoPE + Context-Window Encoding，解决动态组装memory下的位置编码与跨fact上下文丢失。
  - 通过vLLM KV-connector实现，零引擎改动、零模型微调。
  - LoCoMo上k=50时TTFT降72-79%（3.6-4.8×），吞吐提升3.7-4.5×，精度接近Mem0。
- **工程价值**：直接可落地到生产personalized serving / long-context agent memory路径；解决“检索预算越大，TTFT越差”的系统痛点。
- **是否值得读**：强烈推荐
- **Relevance Score**：5
- **Link**：https://arxiv.org/abs/2607.27090

### 2. PrefixPlace: Provable Prefix Key-Value Placement for Large Language Model Serving under Heterogeneous Compute and Transfer Costs
- **一句话总结**：异构环境下prefix KV放置的可证明规划器，超越简单hit-rate启发式。
- **核心贡献**：
  - 把问题建模为带源依赖成本的monotone facility-location + rooted-tree子问题，O(nk)精确求解，固定1/2近似。
  - 覆盖T4/L4/A100不同成本体制；50k节点规模12s内可重规划。
  - RAG replay上materialization-cost saving比vLLM-APC高40%+。
- **工程价值**：多节点/异构集群prefix caching的实际调度优化，可直接指导vLLM/SGLang类系统的placement策略。
- **是否值得读**：强烈推荐
- **Relevance Score**：5
- **Link**：https://arxiv.org/abs/2608.01655

### 3. Compute Globally, Materialize Locally: The Memory Contract of Sparse Event-KV
- **一句话总结**：稀疏event-KV作为agent长期记忆时，下游缓存行可独立承载“已消失输入”的语义计算结果（semantic materialization）。
- **核心贡献**：
  - 严格实验证明：省略源观察后，敏感问题的答案仍强烈跟随被省略值。
  - 主动构造answer-free event可把donor对齐率从6%抬到51%；被动harvest几乎无效。
  - 给出可操作的“写什么、写在哪、源消失后还剩什么”的memory contract。
- **工程价值**：直接影响agent memory eviction / sparse KV设计；“没掉精度≠源不必要”是关键警示。
- **是否值得读**：强烈推荐（系统设计视角）
- **Relevance Score**：4
- **Link**：https://arxiv.org/abs/2607.23693

### 4. Stage-Replay Divergence Follows the KV Cache: Fixed-Prefix Precision Controls and Bidirectional Cache Transplantation
- **一句话总结**：stage-replay时“新鲜prefill vs 保留live cache”的分歧主要由边界KV决定，精度（BF16 vs FP32）调制行为表现。
- **核心贡献**：
  - 200-item匹配实验 + 双向全层KV移植证明：KV是因果充分载体。
  - BF16下大量suffix/正确性分歧，FP32几乎消失。
  - 提供完整可复现artifact。
- **工程价值**：对reasoning stage边界的cache管理、reproducibility、以及任何依赖“replay from intermediate state”的系统（含某些agent/RL rollout）有直接启示。
- **是否值得读**：可选（诊断/理解深度高）
- **Relevance Score**：4
- **Link**：https://arxiv.org/abs/2607.28495

### 5. From Scoring to Acting: Outcome-Verified Comparative Self-Distillation for LLM Agents
- **一句话总结**：用环境outcome验证的teacher continuation + 局部对比学习，把agent技能内化，显著优于现有self-distillation/RL。
- **核心贡献**：
  - 失败student轨迹建prefix tree → 自适应调skill-conditioned teacher → 只保留outcome-verified成功后缀。
  - ALFWorld最高+29.7、WebShop+5.4绝对成功率，额外privileged交互<3%。
- **工程价值**：agent post-training路径更干净、更可落地；减少对外部retrieval的依赖。
- **是否值得读**：可选（agent系统方向）
- **Relevance Score**：4
- **Link**：https://arxiv.org/abs/2607.27937

### 6. ThunderAgent: A Simple, Fast and Program-Aware Agentic Inference System（ICML 2026 Spotlight，近期社区热度高）
- **一句话总结**：把agent workflow抽象为LLM Program，统一调度KV cache + tool资源，专门解决agentic inference的KV thrashing。
- **核心贡献**：
  - program-aware scheduler + tool resource manager，最大化cache命中、缓解内存不平衡、异步环境准备。
  - 单节点吞吐1.5-3.6×，RL rollout 1.8-3.9×，磁盘节省最高4.2×；已集成NVIDIA Dynamo / SkyRL。
- **工程价值**：当前最高工程相关度的agentic serving系统工作；直接可替换vLLM/SGLang在高并发agent场景下的调度层。
- **是否值得读**：强烈推荐
- **Relevance Score**：5
- **Link**：https://arxiv.org/abs/2602.13692
