### Model Inference / 推理优化
**【Title】**  
Fractal KV-Cache Archives: Lossless Symbolic Storage with In-Place Retrieval for Long-Context LLM Inference (arXiv:2607.07144)

- **一句话总结**：将量化后的KV符号流用分形结构存档，实现无损压缩 + 原地检索，大幅降低长上下文推理内存占用。
- **核心贡献**（2-3点）：
  - 提出分形归档结构，对量化码本索引流进行高效符号存储，支持快速原地检索。
  - 超越传统量化/驱逐/卸载，存储层主动参与计算而非纯被动。
  - 实验显示在长上下文场景下显著降低内存，同时保持推理正确性。
- **工程价值**：直接针对KV cache内存瓶颈（长上下文推理核心痛点），可集成到vLLM/SGLang等serving系统中，实现更高吞吐和更长上下文支持；有代码线索潜力，适合生产优化。
- **是否值得读**：**强烈推荐**（Inference方向高优先）。
- **Relevance Score**：5
- **Link**：https://arxiv.org/abs/2607.07144

**【Title】**  
TriRoute: Unified Learned Routing for Joint Adaptive Attention, Experts, and KV-Cache Allocation (arXiv:2607.06601)

- **一句话总结**：单一轻量控制器联合决策attention模式、MoE专家选择和KV cache位宽，实现跨轴条件计算优化。
- **核心贡献**（2-3点）：
  - 端到端训练的TriRoute控制器，处理attention skip/local/full、专家路由和KV量化位宽的耦合决策。
  - 解决联合训练中的路由坍塌问题（per-axis normalization + 耦合损失）。
  - 在160M-1.3B模型上Pareto优于独立MoD+MoE+KV-quant组合，保留稀有token鲁棒性。
- **工程价值**：高度实用，可直接提升serving效率（FLOPs和内存可控），适用于生产级MoE/长上下文部署；控制器轻量，集成成本低。
- **是否值得读**：**强烈推荐**。
- **Relevance Score**：5
- **Link**：https://arxiv.org/abs/2607.06601

### LLM Agents
**【Title】**  
AgentLens: Production-Assessed Trajectory Reviews for Coding Agent Evaluation (arXiv:2607.06624)

- **一句话总结**：生产级代码Agent评估基准，不仅看最终pass/fail，还评估完整trajectory（工具使用、纠错、交互），结合形式验证和LLM评审。
- **核心贡献**（2-3点）：
  - 超越单一bit评估，提供可读trajectory解释，支持诊断和回归检测。
  - 开源基准 + 生产流水线集成。
  - 适用于交互式代码Agent的系统评估。
- **工程价值**：Agent落地核心是可靠性评估，此基准直接服务生产部署、迭代和监控；对构建可靠multi-agent系统有系统设计启发。
- **是否值得读**：**强烈推荐**（实际落地导向）。
- **Relevance Score**：4
- **Link**：https://arxiv.org/abs/2607.06624

### SFT / Alignment / RLHF & Reinforcement Learning
**【Title】**  
Selective Timestep Weighting and Advantage-Based Replay for Sample-Efficient Diffusion RLHF (arXiv:2607.07693)

- **一句话总结**：针对Diffusion RLHF的时步选择性加权 + 优势回放，提升样本效率，同时保持泛化。
- **核心贡献**（2-3点）：
  - 两种互补策略显著减少所需反馈样本。
  - 实验验证在扩散模型对齐中的效率提升。
  - 保留对人类偏好泛化能力。
- **工程价值**：RLHF训练成本高，此方法可降低样本/计算需求，适用于Alignment流水线优化；对视觉/生成模型对齐有直接工程意义。
- **是否值得读**：**可选**（RLHF方向有提升，但偏Diffusion）。
- **Relevance Score**：3
- **Link**：https://arxiv.org/abs/2607.07693
