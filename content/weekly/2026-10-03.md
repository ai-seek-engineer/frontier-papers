# Weekly AI Paper Digest

## 1. 本周趋势总结

活跃度（本周真正新的、和落地相关的）大致是：

1. **LLM Agents（最高，但水分大）**：长程 agent、skill/harness 自演化、plan–execute gap、agent 安全。数量最多，可复现系统工作少。
2. **RL / RLVR（升温）**：重点不在新目标函数，而在 rollout 成本、全失败组没有梯度、以及小时级轨迹的训练系统。
3. **Inference / serving（质量高于数量）**：论文不多，但集中在同一结论——长上下文和解码被 **KV 带宽与 CPU–GPU I/O** 卡住，而不是算力。
4. **AI Infra / 分布式**：prefill–decode 解耦在 agent 流量下失效，弹性边界和多轮增量 prefill 是主线。偏系统，不是算法。
5. **经典 SFT / RLHF（降温）**：本周可见的是 ICML 归档（distortion、reward hacking、BNRM）。新投稿已转向 RLVR、on-policy 修正和 self-play，而不是再做一个 DPO 变体。

升温信号：agent 流量下的 serving、零成功率任务上的自反馈内化、验证门控的 skill bank。降温：通用“再包一层 agent”、静态 PD 比例调参、纯偏好理论。

## 2. 重点论文（Top List）

**1. PulseInfer**（[2609.34555](https://arxiv.org/abs/2609.34555)，9/28）  
稀疏 KV offload 的瓶颈已经从 HBM 容量变成 PCIe 上碎片化的小块 recall。  
贡献：可中断的 layer-wise 调度、I/O 自适应 admission、SoloHead + gather-scatter，实现在 SGLang 上。decode 吞吐最高约 4.7× SGLang、2.6× 现有 offload，TPOT 降约 76%，近无损。  
工程价值：高，直接改 serving 栈。值得精读，并对照 SGLang radix/offload 路径读实现。

**2. ActKV**（[2609.31395](https://arxiv.org/abs/2609.31395)，9/25）  
agent 循环里 KV 该留什么，应按“下一步 action 还会访问谁”而不是通用 attention 分数。  
贡献：action-oriented eviction、confidence 驱动预算、page-aware kernel。长 trace 上约 26% KV 内存保留 98.5% FullKV 准确率，token/task 吞吐约 4× / 3.6×。  
工程价值：高，前提是你的流量是 tool loop 而不是单轮 chat。值得精读。

**3. SpecStream**（[2609.33184](https://arxiv.org/abs/2609.33184)，9/27）  
长上下文 speculative decoding 不该等整段 KV 恢复完再 verify。  
贡献：流式 verify、offload 只保留 target 已提交历史、同一 GPU 上用 KV 传输气泡做 draft。相对 offload baseline 吞吐约 1.3–1.4×，相对分卡 speculative 的每 GPU 输出吞吐约 +55%。  
工程价值：中高。值得精读调度，不急着全量复现。

**4. The KV Cache Is the New Memory Wall**（[2609.30854](https://arxiv.org/abs/2609.30854)，9/25）  
SoK：算术强度随上下文衰减，H100/B200/MI300X 上有明确的 weight-traffic 与 KV-traffic 交叉点。交叉点之前压 KV 几乎不加速。  
工程价值：用来做容量规划，不是用来上线。精读公式和 regime，跳过逐篇文献复述。

**5. QwenGyre**（[2609.33848](https://arxiv.org/abs/2609.33848)，9/27，Qwen）  
单条 agent rollout 可到近 1M token、数百次环境交互，colocate/async 都会把 GPU 卡死。  
贡献：rollout 与 training 之间弹性挪 GPU 且不打断在途执行；轨迹处理器做分支重建、部分进度打分、去重。2.4T 上 700K token/rollout，NL2RepoBench 52.5%→58.5%（48 step）；相对 Colocate/Async 最高约 1.85× / 1.78×。  
工程价值：这是 agent RL 的 infra 论文，不是算法论文。集群做长程 RL 则必读。

**6. RLTL;DR**（[2609.37633](https://arxiv.org/abs/2609.37633)，9/29）  
Pass@128=0 时 GRPO 没有成功轨迹，梯度是平的。  
做法：失败后让策略自己写一条 TL;DR，下一轮条件于历史 insight，并把 task→insight 反传进权重。Qwen3.5-9B 上从 0–1% Pass@1 到训练时 14–31%、去掉 insight 后仍 12–13%。SFTL;DR（只训 task, insight）是关键消融。  
工程价值：中。难任务自举值得试，但是研究配方，不是 serving。值得精读方法节。

**7. VALVE**（[2609.32990](https://arxiv.org/abs/2609.32990)，9/26）  
in-context skill 自演化在 >1000 个 SWE 任务上会回撤和膨胀。  
贡献：验证门控的 skill 更新，有 drawdown 界。三家前沿模型平均最终 +14.9、峰值 +16.5；回撤降约 75%，skill bank 紧凑约 11×。  
工程价值：高，如果你在做 coding agent 的 skill/playbook，而不是重训权重。值得精读门控和 holdout 规模，不值得把“自演化”叙事当真。

**8. Agentic meta-reasoning**（[2609.38147](https://arxiv.org/abs/2609.38147)，9/29）  
长程控制本身是推理问题：controller 只带压缩后的 run state，在预算下选 worker。ProgramBench 上 GPT-5.5 71.5% vs Codex 58.0%。  
工程价值：中。生产 coding agent 已有类似 harness；增量在“显式预算化控制”。读设计，不必复现。

**9. Learning to Stop without Learning to Stop**（[2609.31619](https://arxiv.org/abs/2609.31619)，9/25）  
只用 600 题做自监督置信度 SFT，损失里没有长度项；推理时也不做 early stop。token 最多少约 25%，准确率持平，覆盖 Gemma/Qwen/Nemotron/GPT-OSS。  
工程价值：高且便宜。推理成本优化里本周性价比最好的训练侧杠杆。值得精读并小规模复现。

**10. Crossflow**（[2609.27085](https://arxiv.org/abs/2609.27085)，9/22，略早于窗口但和本周主线同一问题）  
agent trace 上 uncached-input/output 的小时级波动中位数约 24.5×，静态 PD 池按 P95 配会空出最多约 17% 集群。decode 节点发短期可撤销的 local-prefill lease。token 吞吐几何平均 +16–17%，高负载最高 +43%。  
工程价值：已做 PD 解耦就该读。同类还有 ICML 的 AMPD（多轮增量 prefill 的放置与调度）。

邻近但不必进 Top：GRAFT（[2609.37868](https://arxiv.org/abs/2609.37868)，跨模型交换成功轨迹，同预算 GRPO +2.1，最高 +4.5，增益可被缓存轨迹保住）；TGRL（温度分组探索，不加大 rollout 预算，NeurIPS 2026）；Planning-as-Routing（[2609.38108](https://arxiv.org/abs/2609.38108)，模式专用执行器比 Plan+ReAct 更重要，ALFWorld 0.48→0.92）。

## 3. 关键趋势判断

没有全新范式，但有一条正在变硬的分界：

- **控制面 vs 权重。** 长程能力先出现在 harness（meta-controller、validation-gated skill、plan router），再被内化进权重（RLTL;DR 的 insight、Harness-Zero 一类蒸馏）。只堆 agent 框架、不把稳定行为写回策略或写进可验证 skill，部署后会漂。
- **研究到工程的信号很具体。** 论文开始报 SGLang 集成、PCIe 传输形态、PD lease、rollout/train GPU 弹性、每 GPU 输出吞吐，而不是只报 pass@1。agent 流量被当成 serving 的一等公民：多轮增量 prefill、action-critical KV、小时级相位比抖动。
- **未来 1–3 个月更可能爆发的是系统，不是新 loss。**  
  (1) agent-aware KV（evict/offload/speculate 按 action 而不是 token salience）；  
  (2) 长程 RL 的弹性 rollout 集群（QwenGyre 这类，否则 1M-token 轨迹训不动）；  
  (3) 零成功率区间的信用分配（insight 内化、跨策略轨迹交换），因为 GRPO 在 Pass@k=0 上已经明确撞墙。  
  置信度驱动的短推理会很快进后训练配方，因为它只要几百题。

## 4. 工程师行动建议（重点）

假设你做推理优化 / AI Infra / 分布式，本周值得投入的三个方向：

1. **KV 的 I/O 路径，而不是再压一次 attention。** 先用 Memory Wall 的交叉长度判断自己是否已经进入 KV-bound。若是，优先看 PulseInfer（offload 的 PCIe 碎片）和 ActKV（agent trace 的保留集）。SpecStream 是 speculative 和 offload 叠在一起时的调度问题，不要单独上。
2. **agent 负载下的 PD 弹性。** 静态 prefill/decode 比例在 agent 流量上是错的。读 Crossflow 的 lease 和 AMPD 的多轮增量 prefill 放置。你的 trace 若是 tool loop，容量模型必须用 uncached-input/output 的分钟级峰值，而不是日均 token 比。
3. **长程 RL 的资源面，外加一个便宜的解码长度杠杆。** 若你要支撑 agent RL，QwenGyre 的弹性 GPU 和轨迹去重比再调 GRPO 重要。解码侧先试 Learning to Stop：600 题、无推理时控制器，最多约 25% token。这是训练和 serving 的接口，不是另一个 sampler。

值得复现 / 读源码：

- PulseInfer：对照 SGLang offload 路径，看 gather-scatter 和 layer 调度是否真躲过小 PCIe。
- ActKV：用自己的 agent trace 验证“action 访问集”是否稳定；不稳定就不要上。
- Learning to Stop：成本最低的对照实验，先在内部数学/代码集上看 token/准确率曲线。
- QwenGyre：读弹性迁移和 partial-progress 打分；2.4T 数字不可复现，机制可迁移到小集群。
- VALVE：若已有 skill bank，只复现门控和 holdout 规模，不复现整条自演化。

短期内不值得投入：

- 再写一个通用 agent benchmark 或 Plan+ReAct 包装。本周证据是执行器结构 > 计划声明。
- 经典 RLHF 的 distortion / Bayesian reward 变体。对 serving 和分布式没有动作项。
- 无验证门控的 agent self-evolution。SEABench（[2609.35596](https://arxiv.org/abs/2609.35596)）说明局部有用的 harness 更新会在后续任务上变成内生不对齐。
- 多 LLM Stackelberg/Elo 对齐游戏。分数有，系统接口没有。
- 交叉长度之前的 KV 压缩。SoK 已经把这个 regime 说死了。

## 5. 风险与噪音分析

**最大噪音：agent 框架论文。** 数量最多，多数是换一个 router/memory/auditor，不改 KV、不改调度、不改 rollout 成本。Planning-as-Routing 自己也显示，声明了计划却执行不了。SEABench 则说明自演化会在完成率上升的同时引入基线没有的安全失败。没有门控、没有成本、没有失败模式的 agent 论文，本周可以整类跳过。

**论文少但潜力最大：I/O-centric、负载自适应的推理数据面。** PulseInfer、SpecStream、ActKV、Crossflow 加起来仍然少于 agent 包装文，但它们指向同一块钱：长上下文和 agent loop 的瓶颈是 KV 的放置、召回和相位弹性，不是再一个 sampler。谁先把 action 访问模式、PD lease 和 offload I/O 做成同一套调度，谁就能吃掉下个季度的 agent serving 成本。QwenGyre 是这条线在训练侧的对应物，论文更少，集群价值更高。
