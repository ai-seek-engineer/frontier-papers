**# Weekly AI Paper Digest (May 16-23, 2026)**

**过去一周arXiv cs.AI/cs.LG/CL等类别活跃度高，Agent和推理相关方向论文密集涌现。** 重点方向中，**LLM Agents** 最为活跃（多篇multi-agent、agentic workflow、benchmark论文），其次是**Inference Optimization**（线性注意力、speculative、efficiency）和**RL/RLHF变体**（GRPO、RLVR、agent RL）。AI Infra/Distributed 和 SFT/Alignment 相对稳定但有交叉（KV sharing、latent comms）。整体趋势是**从单一LLM向agentic/multi-agent系统演进**，并强调**post-training中RL变体的工程化**（verifiable rewards、group optimization）。

## 1. 本周趋势总结

- **领域活跃度**：LLM Agents 论文最多（MOSS、Claw AI Lab、Spreadsheet-RL、TerminalWorld、WorkstreamBench 等），明显升温，焦点在multi-agent协作、安全KV sharing、长期任务benchmark。Inference Optimization 稳中有升（Gated DeltaNet-2、IdleSpec、CLORE）。RLHF/SFT/Alignment 有变体创新但非爆炸式（TI-DPO、RLVR 相关）。AI Infra/Distributed 零星出现（LCGuard latent comms）。RL 方向在agent scheduling和reasoning中交叉活跃。**降温信号**：纯SFT/基础Alignment 少见，大多融入agent或RL框架。

- **整体判断**：Agentic 系统成为本周主旋律，许多工作试图把workflow“编译”进权重或用RL优化多步执行，体现**研究向工程落地加速**。

## 2. 重点论文（Top 6，精选工程相关）

1. **MOSS: Self-Evolution through Source-Level Rewriting in Autonomous Agent Systems** (arXiv:2605.22794)  
   **一句话总结**：Agent 通过源代码级重写实现自我进化。  
   **核心贡献**：提出源级重写机制，让agent自主修改自身代码实现迭代改进。  
   **工程价值**：高，可直接用于构建自进化agent系统，有GitHub代码。**值得精读**（落地潜力大）。

2. **Gated DeltaNet-2: Decoupling Erase and Write in Linear Attention** (arXiv:2605.22791)  
   **一句话总结**：线性注意力中分离erase/write操作，提升效率。  
   **核心贡献**：Gated 机制优化状态管理，改善长上下文线性注意力。  
   **工程价值**：很高，直接针对inference速度/内存，NV Labs背景+代码，**强烈推荐复现**。

3. **LCGuard: Latent Communication Guard for Safe KV Sharing in Multi-Agent Systems** (arXiv:2605.22786)  
   **一句话总结**：多agent系统中安全KV共享的latent guard机制。  
   **核心贡献**：保护跨agent通信隐私/安全，针对分布式agent infra。  
   **工程价值**：中高，解决multi-agent部署中的安全痛点。**值得关注**但非立即复现。

4. **Spreadsheet-RL: Advancing Large Language Model Agents on Realistic Spreadsheet Tasks via Reinforcement Learning** (arXiv:2605.22642)  
   **一句话总结**：用RL训练LLM agent处理真实表格任务。  
   **核心贡献**：现实benchmark + RL优化agent在端到端财务/表格工作流。  
   **工程价值**：高，RL在具体agent任务上的应用示范，**值得源码阅读**。

5. **Compilng Agentic Workflows into LLM Weights** (arXiv:2605.22502)  
   **一句话总结**：将agentic workflow编译进LLM权重，实现近前沿性能但成本大幅降低。  
   **核心贡献**：workflow-to-weight 压缩技术。  
   **工程价值**：极高，**从研究走向工程的强信号**，部署效率提升显著。**值得精读+尝试复现**。

6. **IdleSpec: Exploiting Idle Time via Speculative Planning for LLM Agents** (arXiv相关)  
   **一句话总结**：利用agent idle时间进行speculative planning。  
   **核心贡献**：推理时优化，减少latency。  
   **工程价值**：高，inference优化实用技术。**值得跟进**。

其他值得一提：Claw AI Lab (multi-agent research team)、TerminalWorld (terminal tasks benchmark)、CLORE (reasoning efficiency)。

## 3. 关键趋势判断

- **新研究范式**：**Agentic Workflow Compilation**（workflow → weights）和**RLVR/GRPO-style verifiable reward RL** 在agent reasoning中崛起，取代部分传统RLHF。Multi-agent orchestration traces 和 latent comms 也成新焦点。

- **从研究走向工程**：强信号明显——多篇带代码/Github、benchmark现实任务（spreadsheet、terminal）、效率优化直接可落地。**Inference scaling + agent RL** 不再是纯理论。

- **未来1-3个月爆发方向**：**Multi-Agent Systems Infra**（安全comm、orchestration）和**Inference-time Agent Optimization**（speculative、idle exploitation、compiled workflows）。RL for long-horizon agent tasks 也会持续热。

## 4. 工程师行动建议（针对推理优化 / AI Infra / 分布式系统工程师）

**本周最值得深入研究的3个方向**：
1. **Agent Inference Optimization**（IdleSpec、CLORE、Gated DeltaNet-2）：直接降低latency/内存，工程落地快。
2. **Multi-Agent Distributed Infra**（LCGuard、orchestration traces）：解决KV sharing、安全、scaling痛点。
3. **RL-driven Agent Training**（Spreadsheet-RL、workflow compilation）：用verifiable/ group RL 提升agent可靠性，取代部分重SFT工作。

**值得“复现/源码阅读”的论文**：
- Gated DeltaNet-2（线性注意力优化，NV Labs代码）。
- MOSS（self-evolution，GitHub可用）。
- Compiling Agentic Workflows（成本降低2个数量级，强工程价值）。
- Spreadsheet-RL（现实任务RL示范）。

**短期内不值得投入的方向**：纯理论SFT/传统RLHF（已被DPO/TI-DPO/RLVR替代），抽象Alignment 无具体infra或agent落地的。过多multi-agent benchmark paper 若无代码/可复现性，也可略过（噪音）。

**行动优先级**：优先复现Gated DeltaNet-2 和 workflow compilation，集成到现有inference stack；然后探索LCGuard在分布式agent部署中的应用。1-2周内可见工程收益。

## 5. 风险与噪音分析

- **最大“噪音方向”**：泛泛LLM Agents benchmark（多篇新env但缺乏可复现代码或真实infra洞见），论文多但工程价值低，容易分散注意力。

- **最有潜力但论文不多的方向**：**Workflow-to-Weights Compilation** 和 **Idle/Speculative Agent Planning**——论文少但直接击中inference cost和agent reliability，未来爆发潜力大。分布式agent安全comm（latent guard）也属此列。

**总结建议**：本周是**agent engineering化**的窗口期，作为infra工程师，重点把RL优化和inference技巧迁移到agent系统，能快速产生落地价值。避开纯benchmark噪音，抓住带代码的高工程价值工作。保持跟踪arXiv cs.AI + PapersWithCode trending。
