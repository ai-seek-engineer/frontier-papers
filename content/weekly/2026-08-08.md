## 2. 重点论文（Top List）

### 1. Practical Online KV Cache Compaction for LLM Agents  
**arXiv:2608.00902**（8 月 2 日）  
- **一句话**：Agent 轨迹是动态增长的，静态压缩假设失效；在线 token eviction + 延迟压缩可在 80% KV 削减下保持大部分精度。  
- **核心贡献**：系统对比 TE vs AM，证明 proxy query 选择是关键设计点；立即压缩有害，延迟到未来 query 出现后更稳。  
- **工程价值**：高。直接可落地到 vLLM / TensorRT-LLM / 自研 serving 的 Agent 路径。  
- **是否精读**：是（系统工程师必读）。

### 2. NVIDIA Object-Oriented Agents (NOOA)  
**arXiv:2607.20709**（7 月底，本周仍在持续发酵）  
- **一句话**：把 Agent 变成普通 Python 对象——方法=动作、字段=状态、docstring=prompt、类型注解=契约。  
- **核心贡献**：统一了 typed I/O、pass-by-refer[<35;110;32M[<35;109;31Mence、code-as-action、可编程 loop 等 6 个关键能力；SWE-bench 等 benchmark 上 token 成本显著下降。  
- **工程价值**：极高。这是“从研究框架走向生产 harness”的明确信号。  
- **是否精读**：是（读代码 > 读论文）。

### 3. Efficient RL Training for LLMs with Experience Replay  
**arXiv:2604.08706**（Meta FAIR，持续被引用与讨论）  
- **一句话**：严格 on-policy 在 generation 昂贵时并非最优；设计良好的 replay buffer 可节省最高 ~40% 推理算力且不掉点。  
- **核心贡献**：形式化 staleness–diversity–cost 三角权衡，给出可落地的 buffer 策略。  
- **工程价值**：高。任何做 GRPO / RLVR 训练系统的团队都应立刻验证。  
- **是否精读**：是。

### 4. Neglected Free Lunch from Post-training: Progress Advantage for LLM Agents  
**arXiv:2606.26080**  
- **一句话**：RL 后训练本身就能产出免费的 step-level advantage（log π_θ / π_ref），无需再训 Process Reward Model。  
- **核心贡献**：在随机 MDP 下证明 progress advantage 等价于最优 advantage；在 test-time scaling、不确定性、失败归因上均有效。  
- **工[<35;108;30M[<35;107;28M程价值**：中高。可直接用于 Agent 的 best-of-N、轨迹筛选、调试。  
- **是否精读**：值得扫一遍公式 + 实验部分。

### 5. DualDecoder: Accelerate Long Context LLM Inference by Predictive Prefetch  
**arXiv:2607.26475**  
- **一句话**：用 speculated token 预测关键 KV，实现 host memory sparse retrieval 的预取与计算重叠。  
- **核心贡献**：双 token 解码 pipeline + layer-aware 调度，吞吐最高 2.62×。  
- **工程价值**：高（长上下文 Agent / RAG 场景）。  
- **是否精读**：是（系统实现细节）。

### 6. AgentOPSD / 一系列 OPD 变体（本周多篇集中出现）  
- 代表：AgentOPSD、FutureBridge-OPD、PCSD、Relay-OPD 等。  
- **共性**：在 agentic multi-turn 场景下，用 teacher-student log-prob gap 做 turn-level / recursive credit assignment，解决稀疏 reward + prefix failure。  
- **工程价值**：中。对训练 pipeline 有启发，但离生产稳定仍有距离。  
- **是否精读**：选 1–2 篇最新的（AgentOPSD 或 FutureBridge）即可，其余可扫摘要。

### 7. Meta FAIR Code Optimization RL（DMC-Optim + [<35;107;27M改进 GRPO）  
- **一句话**：把正确性 + 执行时间同时放进 reward，打破 Pareto，pass@1 大幅提升。  
- **工程价值**：中高（对做 code agent / 编译器级优化的团队有用）。  
- **是否精读**：如果做 code RL，是；否则可跳过。

## 3. 关键趋势判断

**是否出现新范式？**  
是，且已经成型：

1. **Agent = 一等公民软件对象**（NOOA 路线）  
   不再是 prompt + tool schema + workflow graph 的四套系统，而是单一 Python 类 + 类型系统。这会推动 harness 从“研究玩具”走向“可版本控制、可测试、可重构”的工程资产。

2. **On-Policy Distillation 成为 Agentic RL 的默认增强手段**  
   纯 outcome RL 在长 horizon 上 credit assignment 太差；OPD / self-distillation 提供 dense token-level 信号，且不依赖额外环境交互。

3. **推理优化从“静态长上下文”转向“动态 Agent 轨迹在线管理”**  
   KV 压缩、prefetch、disaggregation 的新工作全部围绕“未来 query 未知”的在线约束展开。

**从研究走向工程的信号**  
- NOOA 直接开源 + NVIDIA 官方 blog + SWE-bench 数字。  
- Experience Replay 论文明确给出“可节省 40% generation 算力”的工程数字。  
- 在线 KV compaction 论文直接讨论 throu[<35;106;26M[<35;105;25Mghput 与 proxy 选择的工程 trade-off。

**未来 1–3 个月可能爆发的方向**  
1. Agent 运行时的 KV / 状态管理（在线 compaction + 跨 turn 缓存复用）  
2. 生产级 Agent harness 标准化（类型安全、pass-by-ref、loop 工程）  
3. RL 训练侧的 generation 成本优化（replay、speculative generation、异步 rollout）  
4. Prefill/Decode 解耦 + 跨机房 / 跨集群的 cache-coherent 推理网络

## 4. 工程师行动建议（重点）

假设你是 **推理优化 / AI Infra / 分布式系统** 工程师：

### 本周最值得深入研究的 3 个方向

1. **Agent 轨迹的在线 KV Cache 管理**  
   - 核心论文：2608.00902 + DualDecoder  
   - 为什么：Agent 是下一波主要 workload，现有 PagedAttention / 静态压缩全部不够。  
   - 行动：在现有 serving 框架上实现 delayed TE + proxy query，测量 80% 压缩下的 accuracy/throughput 曲线。

2. **Agent Harness 的工程化（NOOA 范式）**  
   - 核心：读 NOOA 代码 + 论文第 2、3 节。  
   - 为什么：harness 设计能带来双位数 benchmark 提升 + token 成本减半，这是系统层杠杆。  
   - 行动：评估是否把现有 agent 框架迁移到“对象 + 类型契约”模型[<35;103;23M；重点看 pass-by-reference 对 token 消耗的影响。

3. **RL 训练中的 Experience Replay 与 Generation 成本削减**  
   - 核心：Meta Experience Replay 论文。  
   - 为什么：RL post-training 的 generation 已占 80%+ GPU 时间，这是最直接的成本杠杆。  
   - 行动：在现有 GRPO / RLVR pipeline 上加可控 staleness 的 replay buffer，做 wall-clock 对比。

### 值得复现 / 源码阅读的论文

- **NOOA**（代码优先）：直接决定你是否改 agent 运行时架构。  
- **Online KV Compaction for Agents**：实现难度中等，收益可量化。  
- **Experience Replay**：实现简单，立刻能在训练集群上看到 GPU 小时下降。  
- **Progress Advantage**：实现极简（只需 log-prob 差），可作为 Agent 调试与 test-time scaling 的免费工具。

### 短期内不值得投入的方向

- 新的 Preference Optimization 变体 / 纯 Alignment 算法（边际收益低，已进入工程饱和）。  
- 复杂的新 Process Reward Model 训练 pipeline（Progress Advantage 已经证明很多场景不需要）。  
- 再造一套完整的分布式训练框架（Megatron / DeepSpeed 系已经够用，除非你有特定硬件）。  
- 纯学术的“更好 credit ass[<35;102;22Mignment 公式”而不给出可落地的 buffer / 调度设计。

## 5. 风险与噪音分析

**本周最大噪音方向**  
- **Agentic RL 的各种 OPD / Self-Distillation 变体**。论文数量多、名字花哨，但绝大多数是同一思路的局部改进（window、persistence、future bridge、relay…）。真正可生产化的只有少数几篇给出了清晰的实现约束与算力数字。建议：只精读 1–2 篇最新 + 开源的，其余当参考文献。

**本周最有潜力但论文不多的方向**  
- **跨集群 / 跨地域的 cache-coherent 推理网络**（Dynamo 类工作 + 全局 KV 路由）。目前公开论文极少，但工业界已经在推。这是真正能拉开大规模服务成本差距的地方。  
- **Agent 专用的 speculative decoding / 工具调用预测**（把 next-tool 预测与 agent 自身统一到一个模型）。信号出现但系统性工作还很少。
